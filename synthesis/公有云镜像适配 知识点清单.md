# 公有云镜像适配 知识点清单

> **与学习路径的分工**：[[synthesis/公有云镜像适配 学习路径]] 回答"**去哪儿看、按什么顺序**"；
> 本页回答"**具体要掌握哪些点、掌握了没**"。清单可直接在本页勾选（Obsidian 支持点击复选框）。

## 怎么用

1. **先答自测**：每层末尾的自测题答得上，就整层跳过（每项出处都指向页内的自测节）。
2. **按等级读**：【必会】直接影响镜像能不能起、能不能交付，必须掌握；【了解】能解释"为什么"、排障要用；【深潜】源码/协议细节，有余力再看。
3. **勾到底部**：最后的「可执行验收项」是**动手做过**的证明——只有那一节勾满了才算真的会了。

## L0 基础锚点（你已有可跳，先看自测）

- [ ] **【必会】** 一次 `write()` 到云盘的完整路径：VFS → 文件系统 → 块层 blk-mq → 驱动 → virtqueue / NVMe 队列 → host 侧后端　`存储栈与io_uring` §1、`CPU 虚拟化与IO穿透`
- [ ] **【必会】** PCIe 设备枚举、BDF、配置空间、BAR；virtio 与 NVMe 控制器在 guest 里都是 PCIe 设备　`PCIe 子系统` §1–§3
- [ ] **【了解】** bio → request → 硬件队列；io scheduler 选型（NVMe 场景常用 `none`）　`存储栈与io_uring` §1.2
- [ ] **【了解】** NVMe per-CPU 队列与中断亲和　`存储栈与io_uring` §2
- [ ] **【了解】** VT-x/VT-d、IOMMU、SR-IOV、VFIO 各自的角色分工　`CPU 虚拟化与IO穿透` §1–§3

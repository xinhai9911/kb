# CrewAI

## 概述

CrewAI 是一个专注于多智能体协作的 Python 框架。通过角色定义和任务委派实现 Agent 团队协作。

## 核心概念

- **Agent**：具有角色、目标、背景故事的智能体
- **Task**：分配给 Agent 的任务
- **Crew**：Agent 团队的定义
- **Process**：执行流程（顺序、层级）

## 特色

- 简单易用的 API 设计
- 内置角色化协作模式
- 支持工具集成
- 逐步执行与结果追踪

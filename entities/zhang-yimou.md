# 张艺谋 (Zhang Yimou)

## 基本信息

| 项目 | 内容 |
|------|------|
| 出生 | 1951-11-14 |
| 国籍 | 中国 |
| 代表时期 | 1987-至今（持续创作中） |
| 所属运动 | 中国第五代导演（同代：陈凯歌、田壮壮） |
| 关键标签 | 色彩交响 / 仪式感 / 宏大场面 / 集体与个体 / 视觉至上 |
| 代表作 | 《红高粱》(1987)、《活着》(1994)、《一个都不能少》(1999)、《我的父亲母亲》(1999)、《英雄》(2002)、《十面埋伏》(2004)、《满城尽带黄金甲》(2006)、《金陵十三钗》(2011)、《归来》(2014)、《影》(2018)、《一秒钟》(2020)、《满江红》(2023) |

## 风格签名

### 1. 色彩交响

张艺谋和 [[entities/kurosawa-akira|黑泽明]] 一样，是电影史上最懂得使用色彩的导演——但策略截然不同。

- **单色主导**：每部电影有独立的色彩编码——红（《红高粱》《英雄》的红色篇）、绿/蓝/白/黄（《英雄》分色篇章）、水墨灰（《影》）、青绿/白（《满江红》的蓝调+红色的暴力）
- **色彩的文化含义**：张艺谋的色彩不是"漂亮"而是"象征"——红 = 生命力/革命/爱/激情/危险；黄 = 皇权/土地/衰老；灰 = 无根/分裂/内在冲突
- **色彩叙事弧线**：在《英雄》中，每种颜色代表一个故事的不同版本——红色是激情的版本，蓝色是冷静的版本，白色是最终"真相"的版本
- → 参见 [[concepts/color-psychology-in-film]]

### 2. 仪式感与宏大场面

- 张艺谋出生于摄影系（北京电影学院摄影系 78 级）——他的导演眼睛首先是摄影机的眼睛
- **大场面不是"花钱"而是"组织"**：数千人的整齐动作、几何化排列——来自张艺谋对"集体美学"的迷恋（这是他的早期经历和 2008 年奥运会开幕式的延续）
- **仪式化动作**：在张艺谋电影中，倒酒、鞠躬、击鼓、行走——这些动作被拉伸、美化为仪式。《红高粱》中的颠轿是最初的样本
- → 参见 [[concepts/composition-techniques]] 中的画面组织

### 3. 空间作为叙事工具

- **色彩房间**：《大红灯笼高高挂》(1991) 的乔家大院——封闭的、层次清晰的空间结构 = 封建礼教的空间化
- **通道与门**：张艺谋电影中"穿过门/长廊"是常见的视觉母题——从一个空间到另一个空间 = 从一个状态到另一个状态
- **对称的人工感**：张艺谋的对称是"人工制造的"——不是自然对称，是"强制平衡" → 与朴赞郁的对称形成有趣的对比（[[entities/park-chan-wook]]）

### 4. 摄影师的导演

作为北京电影学院摄影系出身的导演，张艺谋对光/色/构图的敏感度超过剧本。

- 他常被批评为"视觉大于叙事"——《英雄》的视觉杰作与叙事空洞的对比是常常被提及的讨论
- 张艺谋的策略：视觉不是服务于叙事——**视觉就是叙事**。但当视觉成为唯一叙事工具时，剧本的"薄弱"就容易被放大
- 对比：[[entities/ang-lee|李安]] 的视觉是"叙事驱动"的——镜头为故事服务。张艺谋的视觉有时是"独立于叙事"的

### 5. 集体 vs 个体

张艺谋的核心主题之一：

- 《红高粱》：个体生命力的爆发 vs 传统秩序
- 《活着》：个体在宏大历史中的挣扎——"活着本身就是胜利"
- 《英雄》：个体的牺牲 vs 天下的统一——最有争议的作品
- 《归来》：个体记忆 vs 历史的抹除
- 《影》：替身（影子）的个体意识觉醒——集体的存在 vs 个体的身份

| 《红高粱》 | 1987 | 第五代开山之作——色彩的情感化 + 颠轿的仪式感 | 视觉冲击力可以替代叙事说明 |
| 《活着》 | 1994 | 朴素叙事 + 历史悲剧的个体视角 + 葛优戛纳影帝 | "安静的力量"——克制比炫耀更持久 |
| 《英雄》 | 2002 | 色彩分章叙事 + 武术的身体几何化 + 中国商业大片起点 | 色彩作为叙事结构的框架——色彩不是装饰，是骨架 |
| 《十面埋伏》 | 2004 | 竹海追逐 + 牡丹坊"击鼓"——张艺谋视觉的巅峰 | 纯视觉叙事的可能性与极限 |

## 张艺谋的文化角色

- **中国商业大片的开创者**：《英雄》是中国电影的转折点——它是第一部"中国式大片"，国内票房 2.5 亿人民币（2002 年的记录），也是第一部在北美大规模发行的中国电影（连续两周北美票房冠军）
- **2008 年北京奥运会开幕式导演**：将他的视觉美学从电影延伸到大型活动——"大场面"的能力在全球展示
- **国家与艺术家的关系**：张艺谋始终在与体制的张力中工作——他的"妥协"与"坚持"一直是国际评论家讨论的焦点
- **两面的张艺谋**："体制内艺术家" vs "第五代叛逆者"——他的全部作品可以被解读为在这两极间的摆动

## 技术特点

### 摄影

- 早期 DP：顾长卫（北京电影学院同班同学），贡献了《红高粱》《活着》等经典视觉
- 后期 DP：赵小丁——延续了张艺谋的"色彩至上"美学
- 张艺谋的摄影偏好：广角用于展示空间，标准焦段用于人物，色彩饱和度极高（除《影》外的所有电影）

### 美术与服装

- 美术指导是张艺谋的第二"眼睛"——他的电影需要极其精确的场景/服装色彩控制
- 《影》的服装设计是最极端的案例——全片使用同一种"中国水墨"配色方案，通过材质的变化而非颜色的变化来创造视觉层次

### 声音

- 赵季平的配乐是张艺谋早期作品的声音灵魂——陕西民歌元素、唢呐、大鼓的"中国性"
- 后来的配乐转向更加国际化的作曲家（陈其钢 Qigang Chen）——但核心的"节奏来自运动"不变

## 张艺谋 vs 其他中国导演

- [[entities/jia-zhangke]]：第六代 vs 第五代——贾樟柯关注边缘人和社会变迁（写实），张艺谋关注视觉和中国性（风格化）
- [[entities/hou-hsiao-hsien]]：台湾 vs 大陆——侯孝贤是长镜头诗意的，张艺谋是短镜头雕刻的
- [[entities/ang-lee]]：文化跨界者 vs 中国本土者——李安在东西方之间工作，张艺谋始终从中国文化内部出发
- 张艺谋 vs [[entities/kurosawa-akira]]：两位"视觉大师"的对比——黑泽明的画面是"运动的、动态的"，张艺谋的画面是"静止的、仪式的"

## 作为导演的学习点

- **摄影师出身的导演看到的是"画面"而不是"故事"**——这是最大的优势也是最大的风险。学会"为故事调整视觉"而非"为视觉调整故事"
- **色彩可以替代对话**：在《英雄》中，观众不问"这是好人还是坏人？"，而问"这是红色的版本还是蓝色的版本？"——色彩已经承担了叙事的角色
- **限制创造风格**：《满江红》发生在一个大宅中，张艺谋通过"人快速在院子里走"来创造节奏——空间限制激发了"Mise-en-Scene" 层面的创造力
- **如果只有一个情感目标，确保视觉服务于它**：张艺谋最好的作品都有清晰的"单一情感目标"——《红高粱》的"生命的野性"、《活着》的"活着的重量" ——但最弱（如《十面埋伏》）时，视觉不再是情感的仆人，而是自己成了皇帝

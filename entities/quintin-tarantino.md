# 昆汀·塔伦蒂诺

## 基本信息

- 国籍：美国
- 活跃年代：1992-
- 代表作：《落水狗》（1992）、《低俗小说》（1994）、《杀死比尔》（2003-2004）、《无耻混蛋》（2009）、《被解救的姜戈》（2012）、《好莱坞往事》（2019）
- 奥斯卡：最佳原创剧本 x2、最佳导演 x2、《低俗小说》金棕榈

## 核心风格

### 对白至上

塔伦蒂诺的对白风格独一无二：
- **日常琐碎的漫谈**：角色在讨论超级汉堡或流行音乐时将其提升为艺术
- **长镜头对白**：一场戏可以是一个两人对话的长镜，完全不切
- **多语言混用**：德语、法语、日语在影片中自然流淌
- **自我指涉**：角色谈论电影——塔伦蒂诺的角色都知道自己在电影里

### 暴力美学

塔伦蒂诺的暴力不是现实的，而是**风格的**：
- 过度夸张的血量——血浆的喷洒像喷泉
- 暴力的歌舞化——《杀死比尔》的暴力优雅如芭蕾
- 暴力的喜剧化——《无耻混蛋》中犹太熊的棒球棍段落
- **来源**：他暴力美学深受香港邵氏武打片和意大利通心粉西部片影响

### 非线性叙事

- 《低俗小说》的环形结构——打破了时间线的叙事
- 《落水狗》以结果开场，再回溯原因
- 《杀死比尔》在章节间跳跃
- 非线性在他手中不仅是一种结构，更是一种**游戏**——让观众在拼图中获得快感

### 类型杂糅

塔伦蒂诺拒绝纯粹的类型——他的每部电影都是类型的混血：
- 《低俗小说》：黑帮片 + 喜剧 + 黑色电影
- 《无耻混蛋》：战争片 + 西部片 + 意式通心粉
- 《被解救的姜戈》：西部片 + 奴隶叙事 + 复仇片
- 《好莱坞往事》：怀旧 + 喜剧 + 修正主义历史

## 导演方法

- **无剧本写剧本**：写出来的剧本就是成品——拍摄时几乎不加修改
- **演员大聚会**：每部电影都有"塔伦蒂诺宇宙"的固定演员（Samuel L. Jackson、Uma Thurman、Christoph Waltz）
- **特写脚**：塔伦蒂诺的恋物癖——每个电影女性角色的脚部特写
- **保留"瑕疵"**：不追求零误差的完美，保留现场创作的惊喜
- **胶片主义者**：坚持使用胶片拍摄，拒绝数字

## 影响与遗产

- 1990 年代独立电影革命的旗帜人物
- 让"非线性叙事"进入主流视野
- 证明了"high concept + low culture"的商业可行性
- 影响了整整一代年轻导演如何写对白、如何混合类型

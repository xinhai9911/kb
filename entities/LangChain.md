# LangChain

## 概述

LangChain 是构建 LLM 应用最流行的开源框架，由 Harrison Chase 创建。已发展为包含 LangGraph、LangSmith 的完整生态。

## 产品家族

- **LangChain Core**：基础抽象层
- **LangGraph**：有状态 Agent 运行时
- **LangSmith**：调试与监控平台

## 核心贡献

- 定义了 LLM 应用开发的标准抽象
- 推动 Agent 框架从链式向图化编排演进
- 丰富的第三方集成生态

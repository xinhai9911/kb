# CapCut（剪映）

## 概述

CapCut（中文名**剪映**）是 ByteDance（抖音/TikTok 母公司）推出的视频剪辑工具，从移动端起家，逐步扩展到桌面版和 Web 版。凭借**免费基础 + 低门槛 + 内建 AI 功能**，CapCut 以惊人的速度侵蚀传统 NLE 的入门市场。

## 市场表现

- **SEMrush 2025 数据**：CNN 流量排名第二（视频编辑类别），市场份额 15.6%
- **桌面版月活跃**：数百万级
- **移动端安装量**：数十亿级（在中国市场为抖音生态标配）
- **Corel 分析师**：CapCut"改变市场，重新定义入门级视频编辑"
- **用户群体**：Z 世代 / 社交视频创作者 / 中小型电商营销

## 核心特性

### 免费层功能极强
- 多轨道时间线（无限制）
- 自动字幕生成（语音转文字）
- 人像分割（绿幕级）
- 自动调色 / 颜色匹配
- 海量素材库 / 模板 / 特效
- 防抖处理
- 文本转语音

### Pro 版 ($89.99/年)
- 更高级 AI 功能
- 团队协作
- 品牌工具包
- 优先渲染

### 平台覆盖
- 移动端：iOS / Android
- 桌面端：Windows / macOS
- Web 版：浏览器直接编辑

## 对传统 NLE 的冲击

- **Premiere Pro 的威胁**：CapCut 的免费 + AI 功能显著降低了入门门槛，大量新手用户不再需要付费 Premiere
- **Resolve 的威胁**：虽然 Resolve 免费功能更强，但 CapCut 的易用性和社交分享集成无可匹敌
- **市场格局变化**："免费 + AI + 移动端" 正在成为视频编辑的新基线

## 与传统 NLE 的定位差异

| 维度 | CapCut | Premiere / Resolve |
|------|--------|-------------------|
| 目标用户 | Z 世代 / 社交创作者 | 专业剪辑师 / 调色师 |
| 核心场景 | 竖屏短视频 / 社交媒体 | 长片 / 广播 / 电影 |
| AI 功能 | 内建大量 AI | 需第三方插件 |
| 工作流 | 轻量一键式 | 专业多阶段管线 |
| 成本 | 免费 / $89.99 年 | $22.99/月 ~ $299 买断 |

# 韦斯·安德森

## 概览

- **全名**：Wesley Wales Anderson
- **生卒年**：1969-
- **国籍**：美国
- **代表作品**：《瓶装火箭》《青春年少》《天才一族》《水中生活》《穿越大吉岭》《了不起的狐狸爸爸》《月升王国》《布达佩斯大饭店》《犬之岛》《法兰西特派》《小行星城》
- **核心身份**：美国独立电影最独特的视觉风格师、玩偶屋美学的创造者

## 电影风格

### 1. 对称构图（安德森签名）
- 安德森镜头几乎是"强迫症般"对称：画框的正中永远是视觉重心
- **与 [[concepts/构图 技巧]] 的关系**：将"对称"从构图选项之一提升到签名级别的执念
- **目的**：对称创造秩序感——而这种秩序感在电影中往往是被事件打破的
- **例外**：当他打破对称（突然的偏移或居中消失）时，通常意味着角色的世界失衡了

### 2. 色彩盒美学（Color Box）
- 每部电影有主导色调，但不是随意的：
  - 《天才一族》— 棕/黄/橙（70年代旧书的质感）
  - 《水中生活》— 蓝/白/红（海洋/探险/法国元素）
  - 《布达佩斯大饭店》— 粉/紫/红（浪漫的过去）vs 灰/黑（法西斯入侵）
  - 《犬之岛》— 灰/蓝（荒凉）vs 暖色（回忆）
  - 《法兰西特派》— 黑白 + 偶尔爆发彩色
- 这本质上是 [[concepts/调色 心理学 电影]] 的极致的、"品牌化"的运用

### 3. 精确的喜剧感
- 安德森的幽默不是"讲笑话"，而是来自三个层面的不匹配：
  1. **成年人的严肃 + 幼稚的行为**（Bill Murray 一本正经做蠢事）
  2. **精美的画面 + 荒谬的内容**（《布达佩斯大饭店》中的越狱追逃，画面像蛋糕一样精致）
  3. **冷漠的语调 + 强烈的情感**（角色用最平静的声音说出最疯狂的台词）
- 与 [[entities/coen brothers]] 的区别：科恩兄弟的幽默来自存在的荒谬，安德森来自形式的精确与内容的情感之间的冲突

### 4. 玩偶屋布景
- 摄影棚拍摄而非实景——安德森的世界是"人造的"，且从不假装不是
- 几乎每一部电影都有"剖面"镜头（切断的楼、打开的车、立体的房间）
- **目的**：提醒观众这是"故事"而不是"现实"——与 [[concepts/电影 理论 要点]] 中的布莱希特间离相通
- 景深感极强：他喜欢场景中有多个"层"——前景/中景/背景同时发生不同的事

### 5. 重复使用的合作班底
- **演员**：Bill Murray、Owen Wilson、Luke Wilson、Jason Schwartzman、Anjelica Huston、Adrien Brody、Tilda Swinton、Jeff Goldblum——安德森的"剧团"
- **作曲**：Mark Mothersbaugh（早期）→ Alexandre Desplat（后期）
- **DP**：Robert Yeoman（几乎所有电影）
- **剪辑**：Andrew Weisblum

### 6. 对白风格
- **"报告式"对白**：角色对白像是在"朗读"一份经过精心编辑的文字
- 每个人都过于有表达力、过于精确——这不是"自然的"说话方式，是文学化的
- 情感通过文字的文雅与情境的残酷之间的落差来传达

## 工作方法

### 导演风格
- **极端准备**：分镜画得比实际成片还详细（他是少数自己画分镜的导演）
- **精确控制**：[[entities/stanley kubrick]] 的继承人——每个元素都被设计
- **排练习惯**：与演员做大量 table read，用"反直觉的平坦语调"读对白
- **多 take**：不是为了"找到感觉"，而是为了让表演"更精确"

### 布景设计
- 安德森高度参与布景设计，有时自己绘制剖面图
- 每件道具都是精心策划的——没有"背景噪声"
- **调色板**与美术指导一起确定（L 型色卡被用来确保每件服装/道具在同一色调范围内）

## 主要作品与风格演变

| 年份 | 作品 | 风格阶段 | 关键元素 |
|------|------|----------|----------|
| 1996 | 《瓶装火箭》 | 起步期 | 对称尚未完全形成，但幽默感已经建立 |
| 1998 | 《青春年少》 | 风格成型 | 慢镜头、配乐选歌、成人小孩喜剧 |
| 2001 | 《天才一族》 | 成熟期 | 色调统一、叙述者、家庭主题 |
| 2004 | 《水中生活》 | 探索期 | 剖面船、伪纪录片、海洋/探险 |
| 2009 | 《了不起的狐狸爸爸》 | 动画首秀 | 定格动画——安德森的完美媒介 |
| 2014 | 《布达佩斯大饭店》 | 巅峰 | 故事嵌套、粉红美学、欧洲隐喻——奥斯卡4项大奖 |
| 2021 | 《法兰西特派》 | 后期 | 杂志结构、多故事、极致风格化 |
| 2023 | 《小行星城》 | 后期 | 戏剧/电影嵌套、外星人是隐喻 |

## 对世界电影的影响

- "安德森风格"（Andersonian）成为电影风格词汇——像"希区柯克式"一样通用
- 影响了一代年轻导演和美工（尤其是广告/MV 出身导演）
- 定格动画领域的复兴贡献
- 激化了关于"形式主义是否空洞"的争论——支持者认为他是巴洛克大师，批评者认为他是"Netflix 时代的装修师"
- 在流媒体时代，他的"一切皆人造"美学成为一种反-实景纪实的宣言

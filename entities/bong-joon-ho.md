# Bong Joon-ho 导演方法

## 概述

Bong Joon-ho 是韩国电影走向全球的标志性导演。他以"类型杂糅"（Genre Blending）和"完美节奏"著称——能在同一部电影中无缝切换悬疑、喜剧、恐怖、悲剧而不显得割裂。

## 标志性风格

### 叙事特征
- **类型杂糅（Genre Blending）**：每一部电影同时是多种类型。《寄生虫》是家庭剧+悬疑+黑色喜剧+恐怖；《雪国列车》是科幻+动作+阶级斗争寓言
- **社会寓言**：个人故事永远承载社会批判（阶级、环境、资本）
- **"翻转点"（Turn）**：每部电影都有几次让观众重新理解之前所有内容的翻转
- **空间限制**：大部分故事发生在严格限定的物理空间（《寄生虫》的豪宅/地下室、《雪国列车》的火车、《杀人回忆》的小镇）

### 视觉风格
- **精确构图**：每一镜都经过精心摆放，信息量极大（对比阶级的垂直构图尤为著名）
- **场景/道具作为叙事**：《寄生虫》中楼梯是权力的物理化——上下楼梯改变阶级
- **天气作为情绪工具**：雨在《寄生虫》中成为关键情节驱动
- **节奏控制**：剪辑节奏随情绪变化，喜剧切得轻快，恐怖拖长

### 表演方向
- **ensemble 整体**：团队感强，配角也有完整弧线
- **反复与韩国演员合作**：宋康昊是 Bong 的 alter ego，出演其所有韩语作品直到《寄生虫》
- **类型化演员的颠覆**：将演员的既有形象反过来用（如《寄生虫》中通常演喜剧的角色承担黑暗功能）

## 代表作品方法对比

| 作品 | 核心类型杂糅 | 空间设定 |
|------|------------|---------|
| 《杀人回忆》 | 犯罪 + 黑色幽默 + 社会悲剧 | 小镇稻田 |
| 《汉江怪物》 | 怪物 + 家庭剧 + 政治讽刺 | 汉江边 |
| 《母亲》 | 悬疑 + 家庭悲剧 | 小镇 |
| 《雪国列车》 | 科幻 + 动作 + 阶级斗争 | 火车 |
| 《寄生虫》 | 家庭剧 + 悬疑 + 黑色喜剧 | 豪宅/地下室 |

## "完美节奏"的解剖

Martin Scorsese 评价《寄生虫》"节奏完美"——这意味着：
1. 每一段落的时长刚好让观众进入状态
2. 情绪转向（从喜剧到紧张的峰值转换）极其精准
3. 没有"废戏"——每一场都同时推进 plot + 角色 + 主题

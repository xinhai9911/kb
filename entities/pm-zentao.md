# 禅道（Zentao）

## 概述

禅道由青岛易软天创开发，是国内最主流的**开源一站式项目管理平台**，覆盖从产品概念到发布运维的全生命周期。

## 核心功能

### 产品管理
- **需求管理** — 从收集到评审到发布的完整流程
- **路线图（Roadmap）** — 版本规划与需求关联
- **产品/需求/Story 结构** — 支持需求分层分解

### 项目管理
- **项目看板** — 支持 Scrum + Kanban
- **Sprint 管理** — Backlog → Sprint Planning → 执行
- **任务分解** — WBS 层级拆解，工时填报
- **燃尽图** — 追踪 Sprint 进度
- **挣值管理** — 基础 EVM 计算

### 测试管理
- **测试用例管理** — 用例库 + 套件
- **Bug 管理** — 提 Bug → 指派 → 修复 → 验证
- **测试报告** — 按版本/模块统计
- **自动化测试** — 集成 Jenkins

### 配置与 DevOps
- **版本发布** — Release 管理与上线记录
- **CI 集成** — 与 Jenkins / GitLab CI 对接
- **文档管理** — 项目文档在线协作

## 优势与局限

| 优势 | 局限 |
|------|------|
| 开源可私有化部署 | UI 设计较陈旧 |
| 全流程闭环（产品+项目+测试） | 界面交互不够现代 |
| 国内生态，中文化好 | 大规模团队支持弱 |
| 插件市场丰富 | 移动端体验一般 |
| 性价比高（开源版免费） | 国际化支持有限 |

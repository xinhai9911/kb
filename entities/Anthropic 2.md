# Anthropic

## 概述

Anthropic 是一家 AI 安全公司，由前 OpenAI 员工于 2021 年创立。以 Claude 模型系列和 AI 安全研究闻名。

## 核心产品

- **Claude 系列**：Sonnet、Opus、Haiku、Fable 等多代模型
- **Claude Code**：基于终端的 AI 编程助手
- **Claude Desktop**：桌面端 Agent 应用

## 关键技术贡献

- Constitutional AI（宪法式 AI）
- 可解释性研究
- **MCP 协议**：[[concepts/MCP 协议|Model Context Protocol]]
- 工具使用（Tool Use）API

## 生态定位

与 OpenAI 直接竞争，差异化在于安全优先、可解释性和开放协议（MCP）。

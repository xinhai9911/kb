# 限流熔断实战

> 原理见 [[concepts/韧性设计]]。本文给可直接复用的算法骨架与接线。

## 1. 令牌桶限流（算法实现）

```python
import time

class TokenBucket:
    def __init__(self, rate, capacity):
        self.rate = rate            # 每秒补充令牌数
        self.capacity = capacity    # 桶容量（允许突发）
        self.tokens = capacity
        self.last = time.monotonic()

    def allow(self, n=1):
        now = time.monotonic()
        self.tokens = min(self.capacity,
                          self.tokens + (now - self.last) * self.rate)
        self.last = now
        if self.tokens >= n:
            self.tokens -= n
            return True             # 放行
        return False                # 限流
```
- 平均速率 = `rate`，突发上限 = `capacity`。
- 调用方超阈值返回 `429`（见 [[concepts/API 设计]] §6）。

## 2. 滑动窗口限流（更平滑）

```python
from collections import deque
import time

class SlidingWindow:
    def __init__(self, limit, window):
        self.limit, self.window = limit, window
        self.hits = deque()

    def allow(self):
        now = time.monotonic()
        while self.hits and self.hits[0] <= now - self.window:
            self.hits.popleft()
        if len(self.hits) < self.limit:
            self.hits.append(now)
            return True
        return False
```

## 3. 熔断（Circuit Breaker 三态）

```python
import time

class CircuitBreaker:
    def __init__(self, failure_threshold=0.5, window=20, cooldown=5.0):
        self.ft, self.window, self.cooldown = failure_threshold, window, cooldown
        self.calls, self.fails = [], []   # 滑动窗口记录成功/失败
        self.state = "CLOSED"
        self.opened_at = 0

    def allow(self):
        if self.state == "OPEN":
            if time.monotonic() - self.opened_at > self.cooldown:
                self.state = "HALF_OPEN"   # 冷却到，放行少量探活
                return True
            return False                    # 直接拒绝，走降级
        return True

    def record(self, ok):
        self.calls.append(ok); self.fails.append(not ok)
        if len(self.calls) > self.window: self.calls.pop(0); self.fails.pop(0)
        rate = sum(self.fails) / len(self.calls) if self.calls else 0
        if self.state == "HALF_OPEN" and ok:
            self.state = "CLOSED"           # 探活成功，恢复
        elif rate >= self.ft and len(self.calls) >= self.window:
            self.state = "OPEN"; self.opened_at = time.monotonic()  # 熔断
```
- 熔断后调用方应走**降级兜底**（[[concepts/韧性设计]] §6），不直连故障方。

## 4. 指数退避重试（必须幂等）

```python
import random, time

def call_with_retry(fn, max_attempts=3, base=0.1):
    for i in range(max_attempts):
        try:
            return fn()                      # fn 必须幂等！见 [[concepts/分布式系统基础]] §5
        except TransientError:
            if i == max_attempts - 1: raise
            sleep = base * (2 ** i) + random.uniform(0, base)   # 指数 + 抖动
            time.sleep(sleep)
```
> 非幂等操作（如「下单」）重试会重复副作用——务必带幂等键。

## 5. 网关层限流（Nginx）

```nginx
# 单 IP 每秒 10 请求，突发 20（令牌桶语义，见 [[concepts/韧性设计]] §4）
limit_req_zone $binary_remote_addr zone=perip:10m rate=10r/s;
limit_conn_zone $binary_remote_addr zone=conn:10m;

server {
    location /api/ {
        limit_req zone=perip burst=20 nodelay;
        limit_conn conn 10;
        proxy_pass http://backend;
    }
}
```
详见 [[entities/Nginx 反向代理实战]]（limit_req/limit_conn 章节）。

## 6. 组合拳（实战接线）

```
请求 → 网关限流(Nginx) → 服务内舱壁(隔离线程池) → 调用(超时)
     → 失败 → 重试(退避+幂等) → 仍失败率高 → 熔断(降级兜底)
```
每一环的状态（限流次数、错误率、熔断态）都应上报指标（[[concepts/可观测性工程]]）。

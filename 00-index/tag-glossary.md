# 标签字典（Tag Glossary）

约定的标签含义。同一概念只用一种拼写。

## 领域

- `protocol` —— 网络/数据库协议分析
- `vhd` / `vhdl` —— VHDL/FPGA
- `database` —— 数据库相关
- `influxdb` / `hbase` / `elasticsearch` / `milvus` —— 具体产品
- `npp` —— Network Processing Platform (VPP/VLIB)
- `vpp` —— VPP 框架 / VLIB 节点图
- `decoder` —— database-decoder 工作流
- `directing` —— 导演 / 影视创作
- `montage` —— 蒙太奇剪辑手法
- `shot-sizing` —— 镜头景别（远/全/中/近/特）
- `axis` —— 轴线（180° 规则）
- `storyboard` —— 分镜表
- `ffmpeg` —— ffmpeg 视频处理
- `video-editing` —— 视频剪辑
- `sources` —— 外部资料蒸馏索引（不复制原文，保留路径回查）
- `elasticsearch` / `elk` / `search` —— ES 与 ELK 栈
- `network` / `routing` / `switching` / `huawei` —— 网络路由交换
- `reverse` / `ida-pro` / `binary` —— 逆向 / IDA
- `architecture` / `design` —— 软件架构
- `intel` / `x86` / `performance` —— CPU 微架构与性能
- `centec` / `switch` / `ctc7132` / `ctc8180` / `asic` —— 盛科交换芯片
- `sdk` / `development` —— 交换芯片 SDK 开发
- `nic` / `dpdk` / `networking` —— 网卡 / DPDK
- `amd` / `epyc` / `numa` / `hpc` —— AMD EPYC 处理器
- `motorcomm` —— 裕太微交换芯片
- `h3c` / `tap` / `visibility` —— H3C TAP 流量可视化
- `opencloudos` / `linux` / `summit` / `observability` —— OpenCloudOS 大会
- `hardware` / `nsf` / `chassis` —— 硬件 / 框式机架设计

## 类型

- `note` —— 通用笔记
- `snippet` —— 代码/命令片段
- `adr` —— 架构决策记录
- `template` —— 模板
- `idea` —— 闪念、未成形
- `todo` —— 待办

## 状态

- `draft` —— 草稿
- `active` —— 在用
- `archived` —— 已归档
- `wip` —— 正在进行

## 自由标签

上面没列出的可以自由新增，但建议先看看是否已有近义标签。命名用单数（`note` 不是 `notes`）。

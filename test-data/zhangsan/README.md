# 张三 · 仿真人生数据

> **声明**:张三、其家庭成员、同事、朋友均为**虚构人物**。所有公司、学校、医院、地址、电话、银行账号、身份证号均为编造或打码处理。出现的人名、地名、品牌名若与现实重合,纯属巧合。

## 用途

本目录是 AI 测试用的**真实感合成数据集 (synthetic but realistic persona dataset)**,服务于:

1. **检索质量评测** — 配合刚入库的 [[concepts/混合 检索 bm 25 语义 融合|BM25+语义融合检索]] 概念页,作为已知答案的 query ↔ page 回归集
2. **Agent 多跳推理** — 测试"张三 2023 年为什么离开字节"、"张三的母亲目前在哪个医院"这类需要跨文档 join 的问题
3. **长上下文理解** — 跨 15 年时间线的实体追踪(谁是谁的谁、什么时候发生了什么事)
4. **RAG 幻觉检测** — 故意留一些"事实缺口",让 AI 区分"档案里有"vs"自己编的"
5. **OCR / 错别字鲁棒性** — 部分文档带手打错别字、口语化、标点不规范

## 评测 Query 样例(留给后续测试)

预期这些问题在本数据集里能找到精确或近似的答案,用来回测 BM25 通道 / 语义通道 / RRF 融合的差异:

- Q1:张三本科哪所学校?什么专业?(BM25 强,直命中)
- Q2:张三的母亲得了什么病?(语义 + BM25 都行)
- Q3:张三 2023 年为什么离开字节?(多跳:创业文档 + 朋友圈抱怨 + 朋友聊天)
- Q4:张三现在欠银行多少钱?(数值聚合,跨多份文件)
- Q5:张三的前妻做什么工作?(关系抽取,跨聊天记录)
- Q6:张三创业公司的名字叫什么?(BM25 应能命中,语义可能因抽象表达漏掉)
- Q7:张三最近一次体检有什么异常?(隐含,可能在某聊天/日记里)
- Q8:张三的高考分数是多少?(精确数字召回)
- Q9:张三 2021 年买房时房价多少?(时序+数字,需要文档包含时间戳)
- Q10:张三有没有孩子?(多文档交叉,部分文档说"无"、部分"暂无")

## 数据生成原则

1. **数字要具体**:不写"月薪两万",写"税前 28k × 16 薪,2021 年 base 涨到 35k"
2. **时间要闭环**:不写"在某年",写"2021-11-29 周一 14:30 在望京链家签合同"
3. **机构要可识别**:写"腾讯 WXG 微信支付前端组"不写"某大厂"
4. **对话要带噪声**:微信记录要有撤回、错别字、表情包代号(用 [呲牙] 这类占位)、偶尔不回复
5. **情绪要分层**:同一个人,2018 年意气风发和 2024 年疲惫说话方式应该明显不同
6. **留白要刻意**:部分细节故意不写(如张三是 P 还是 S 性格),让 AI 区分"能推"vs"硬推"

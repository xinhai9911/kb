# AI Agent 框架对比

## 框架概览

| 框架 | 开发者 | 语言 | 核心特性 |
|------|--------|------|----------|
| LangGraph | LangChain | Python | 有状态图化编排、检查点、流式 |
| CrewAI | CrewAI Inc | Python | 角色化多智能体、任务委派 |
| AutoGen | Microsoft | Python | 多 Agent 对话、代码生成 |
| Dify | Dify AI | Python | 可视化工作流、低代码 |
| OpenAI Agents SDK | OpenAI | Python | 轻量 Agent、交接、护栏 |

## LangGraph

适合复杂有状态工作流。支持循环、条件分支、并行执行。内置检查点机制支持断点续传。

## CrewAI

以角色（Role）为中心定义 Agent。支持任务委派、顺序/层级执行。适合内容创作、研究等场景。

## AutoGen

微软出品，聚焦多 Agent 对话。Agent 之间通过消息传递协作。支持代码执行沙箱。

## 选型建议

- 需要复杂状态管理 → LangGraph
- 多角色协作 → CrewAI
- 多 Agent 对话推理 → AutoGen
- 低代码/可视化 → Dify
- 简单集成 → OpenAI Agents SDK

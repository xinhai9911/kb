# Nonlinear Narrative: Definition and Structure

## 概述

非线性叙事是指不按时间先后顺序讲述故事的结构。作者有意打乱时间线，让观众主动"拼图"。

## 与三幕剧的关系

非线性叙事**不是**对三幕剧的否定，而是在三幕骨架上的时间重组。激励事件、中点、高潮仍然存在，只是它们出现在屏幕上顺序可能与时间顺序不同。

## 常见类型

### 1. Flashback Structure（闪回结构）
以一个"现在时"为主线，通过闪回逐步揭示过去：
- 最常见的形式
- 闪回通常由触发物（某种感官刺激、对话提及）引导
- 《肖申克的救赎》红在假释听证会上讲述安迪的故事

### 2. Parallel Timelines（平行时间线）
多条时间线同时推进，在第 3 幕汇合：
- 每条时间线有自己的三幕节奏
- 汇合点通常是高潮
- 《星际穿越》地球线 + 太空线同时推进

### 3. Circular / Episodic（环形/篇章式）
故事在时间上绕了一圈，结尾回到开头，但观众理解已完全不同：
- 结构本身即主题（"历史重复"、"命运循环"）
- 《本杰明·巴顿奇事》倒着走的一生

### 4. Non-Linear Fragments（碎片化）
时间完全打散，观众需要主动拼合：
- 对观众要求最高
- 高风险高回报——做得好是杰作，做不好是一团乱麻
- 《记忆碎片》用倒叙 + 黑白/彩色双时间线让观众体验主角的记忆障碍

## 什么时候用非线性叙事

1. **主题需要**：形式即内容。讲记忆障碍 -> 让观众也"记不住"（《记忆碎片》）
2. **悬念控制**：先给结果，再问过程。制造"发生了什么？"的悬念
3. **多视角真相**：不同角色在不同时间点经历的同一事件
4. **情感冲击**：通过时间重组放大情感对比

## 风险与难点

- 观众困惑 vs 观众沉浸的界限极窄
- 需要更清晰的"信号灯"（视觉风格/色调/字幕等来区分时间线）
- 非线性不是"不写三幕"——甚至要求三幕比线性叙事更清晰
- 建议先写一版线性版本，确保故事本身成立，再考虑打乱顺序

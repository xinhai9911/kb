# 摄影机选择与镜头哲学

## 概述

摄影机与镜头是导演最重要的视觉工具。选择哪台机器、哪个焦段、哪种格式，决定了电影的视觉质感、拍摄流程、后期成本，以及最重要的——观众的情绪体验。这些决定通常由导演与 DP（摄影指导）共同做出 → 参见 [[concepts/director-dp-collaboration]]。

---

## 导演如何选择摄影机

### 决策三角形

```
         画质（分辨率/动态范围/色彩科学）
                /\
               /  \
              /    \
             /______\
        工作流          预算
  （后期/存储/调色）    （机身/镜头/附件的总成本）
```

每个导演选择一台摄影机时，总是在这三角之间权衡。

### 主流摄影机类型对比

| 类别 | 代表机型 | 画质等级 | 预算区间 | 典型场景 |
|------|---------|---------|---------|---------|
| 数字电影机（高端） | ARRI Alexa 35 / LF, Sony Venice 2 | ★★★★★ | $60K-$100K+ | 院线电影/高端剧集 |
| 数字电影机（中端） | RED Komodo, Sony FX6 | ★★★★ | $10K-$30K | 独立电影/纪录片/广告 |
| 无反/微单 | Sony A7S III, Canon C70, Panasonic S1H | ★★★ | $3K-$8K | 低成本电影/纪录片/B 机 |
| 胶片摄影机 | ARRICAM, Panavision | ★★★★★ | 高昂（+胶片+冲印） | 特定美学需求的项目 |
| 手机 | iPhone Pro, Sony Xperia | ★★-★★★ | $0（如果已有） | 实验/纪录片特殊场景 |

### 选择关键因素

1. **动态范围 (Dynamic Range)** — 最能体现摄影机档次的指标。ARRI Alexa 的 14+ stops 动态范围使其在自然光/高反差场景中无可替代
2. **色彩科学 (Color Science)** — ARRI 的色彩科学被公认为行业标准——肤色还原最自然
3. **分辨率 (Resolution)** — 4K 成为行业基础标准，6K/8K 主要服务于后期裁切和"未来验证"
4. **双原生 ISO** — 在低光条件下的表现直接影响灯光预算
5. **录制编码 (Codec)** — ProRes 的普及度 vs RAW 的后期灵活性 → 详见 [[concepts/camera-raw-formats]]
6. **ND 滤镜系统** — 内置 ND 是实用性的巨大差异（Alexa 有 / RED 大部分没有）
7. **生态系统的完整性** — 可用镜头、配件、跟焦系统、稳定器的支持程度

### 预算有限时的"选机公式"

```
最终画质 ≈ 传感器质量 × 镜头质量 × 灯光质量 × DP 经验
（短板效应：每一项都会成为瓶颈）
```

- 预算低于 $10K 时：把钱花在镜头和灯光上，而非机身上
- 预算 $10K-$30K 时：可以考虑中端电影机，但确保镜头预算不低于机身的 50%
- 预算 $30K+ 时：租用（Rental）通常优于购买——Alexa Mini LF 的日常租金约 $500-$800/天

## 传感器尺寸的叙事含义

| 传感器格式 | 物理尺寸（近似） | 画幅比 | 典型机型 | 视觉效果 |
|-----------|---------------|-------|---------|---------|
| Super 35 (S35) | 24.9 x 14.0mm | 1.78:1 | ARRI Alexa Mini, RED Komodo | 行业标准 | 
| 全画幅 (FF / VV) | 36 x 24mm | 1.43-1.90:1 | Sony Venice, Alexa LF, Canon C700 FF | 更浅景深、更广视角 |
| IMAX | 70 x 48.5mm | 1.43:1 | IMAX 胶片机, Alexa 65 (54 x 25.5mm) | 极致沉浸感 |
| Micro Four Thirds (MFT) | 17.3 x 13mm | 1.33:1 | Blackmagic Pocket 4K | 更深景深、更轻便 |

### 叙事含义

- **S35 的选择**：传统电影感——足够的景深控制（配合大光圈），摄影机体积适中。Nolan 在 IMAX 出现前是 S35 用户。多数电视/流媒体内容使用 S35
- **全画幅的选择**：更浅的景深——背景的"奶油般融化"是美学选择。更大的覆盖范围——广角镜头在全画幅上更广。Villeneuve 在《沙丘》中选择 Alexa LF 和 Alexa 65 用于创造"宇宙的宏大规模感"
- **IMAX 的选择**：最高的画质和沉浸感。15-perf/65mm 的物理尺寸使画面的每一个细节都惊人。Nolan 是 IMAX 最坚定的支持者——《黑暗骑士》《星际穿越》《信条》《奥本海默》大量使用 IMAX 胶片拍摄。但 IMAX 摄影机极其庞大、噪音巨大（需要后期 ADR 对话）、胶片成本极高
- **MFT 的选择**：低成本 + 更深的景深——对纪录片中的"全焦点画面"有利。也适合需要极端手持/小体积的场景

## 镜头焦段的叙事含义

镜头焦段的选择直接决定观众与角色/空间的情感距离。

### 焦段分类与效果

| 焦段 | 分类 | 视角 | 典型效果 | 代表场景 |
|------|------|------|---------|---------|
| 14-24mm | 超广角 | 84°-114° | 夸张透视/空间扭曲 | 宏大环境/眩晕/不安/追逐 |
| 24-35mm | 广角 | 63°-84° | 空间感/环境关系 | 建立镜头(Establishing) / 纪录片环境感 |
| 35-50mm | 标准 | 40°-63° | "人的眼睛"—中立自然 | 对话/日常场景——最接近人眼视角 |
| 50-85mm | 中长焦 | 24°-40° | 人物聚焦/浅景深 | 特写/肖像/采访——压缩背景 |
| 85-135mm | 长焦 | 12°-24° | 压缩感/孤立 | 街头偷拍/情感特写——背景被"拉近" |
| 135mm+ | 超长焦 | 4°-12° | 极端压缩/扁平化 | 体育/野生动植/Kubrick式走廊 |

### 镜头选择的导演哲学

**广角（24-35mm）——环境感**
- 观众感觉"与角色同处一个空间"
- 广角迫使观众环顾画面四周——注意到空间中的一切
- 效果：增强场景的现实感/临场感
- 代表：Bong Joon-ho 在《寄生虫》中大量使用 25-35mm 镜头——让观众"近到能闻到角色的汗味"
- DP 搭档：与 [[concepts/director-dp-collaboration]] 中的协作模式对应

**标准（35-50mm）——中立感**
- "无风格"的风格——画面不制造强烈的透视效果
- 适合：纪录片、纪实风格、角色对话
- 代表：是枝裕和偏好 50mm——中立的观察者视角

**长焦（85mm+）——压缩感**
- 空间被压缩——前景与背景"贴在一起"
- 效果：角色与环境的分离感、情节剧( melodrama) 感
- 代表：王家卫偏好 50mm 但常配合近摄——杜可风的 35mm 步幅摄影创造"拥挤中的亲密"
- Wong Kar-wai 使用长焦创造的压缩走廊效果 → [[concepts/masterclass-film-analysis]]

### 定焦 vs 变焦

| 维度 | 定焦 (Prime) | 变焦 (Zoom) |
|------|------------|------------|
| 画质 | 更锐利 / 更大光圈 / 更少畸变 | 折衷（高端变焦已接近定焦） |
| 景深控制 | 更浅——f/1.4 或更大光圈 | 通常最大 f/2.8 |
| 工作流 | 换镜头 = 换焦段——物理上移动摄影机 | 不换镜头——站在原地变焦 |
| 导演哲学 | 你必须"选择"位置——镜头限制决定构图策略 | 提供"调整"自由度——可后期在剪辑中决定 |
| 典型场景 | 院线电影（Kubrick/Nolan 只用定焦） | 纪录片 / 电视 / 快节奏制作 |

**Kubrick 式的极端**：Kubrick 不仅只用定焦，还常用蔡司 Planar 50mm f/0.7（原本用于 NASA 卫星摄影）在《乱世儿女》的烛光场景中——因为他需要在不使用人工光的条件下获得足够曝光。

## 变形宽银幕 (Anamorphic) vs 球面 (Spherical)

### 核心区别

| 维度 | 球面 (Spherical) | 变形 (Anamorphic) |
|------|-----------------|------------------|
| 光路 | 圆形对称——影像不压缩 | 光学压缩（通常是 2x）→ 横向压扁 → 后期展宽 |
| 画幅比 | 1.33:1 ~ 1.90:1（取决于传感器+遮幅） | 2.35:1 ~ 2.76:1（变形镜头的自然宽屏） |
| 景深 | 数学计算的景深 | 同样光圈下景深更浅（有效光圈因压缩而增大） |
| 炫光 (Flare) | 圆形/多瓣形光斑 | 标志性水平蓝色炫光 |
| 焦外 (Bokeh) | 圆形 | 椭圆/拉长——"经典电影感" |
| 畸变 | 极少 | 边缘拉伸 / 椭球变形——充满性格 |

### 叙事含义

- **球面**：更"真实"、更自然的视觉呈现。适合纪录片、现实主义、手持风格
- **变形**：更"电影感"、更梦幻的质感。适合内容需要宏大感、怀旧感、沉浸感的场景
- **变形选择也是预算选择**：变形镜头价格可能 3-10 倍于同档球面镜头

### 经典 DP 偏好

- **Hoyte van Hoytema (Nolan 的 DP)**：使用 IMAX 球面（大画幅提供足够的"宽感"，不需要变形压缩）
- **Roger Deakins**：大多数项目偏好球面——"清晰的画面比风格化更重要"
- **Robert Richardson (Tarantino / Scorsese 的 DP)**：偏好变形宽银幕——尤其是他标志性的"双源光 + 变形炫光"
- **Emmanuel Lubezki (Cuaron / Iñarritu 的 DP)**：球面——大画幅 + 自然光的组合

## 滤镜系统

### ND 滤镜（中性密度）

- **功能**：减少进入镜头的光量——在大光圈拍摄时控制曝光（不改变快门角度）
- **重要性**：在外景拍摄时的必需品——晴朗阳光下，没有 ND 你无法使用 f/1.4 拍摄
- **内置 vs 外置**：ARRI Alexa 的 0.6-2.1 内置 ND 系统是导演/DP 工作流程的关键便利——无需停机安装（此为选购摄影机时的重要考量）
- **可变 ND**：快速调整但可能产生不均匀/偏色

### 偏振镜 (Polarizer)

- 消除非金属表面的反光（水面/玻璃/叶子）
- 增加天空的饱和度——蓝天更深
- 不可过度使用——会不均匀地影响广角画面

### 黑雾镜 (Black Pro-Mist)

- **近年使用最广泛的柔焦滤镜**
- 功能：柔化高光（光晕）+ 降低对比度 + 柔化皮肤纹理
- 强度选择：1/8（极微），1/4（标准），1/2（明显）
- 数字时代尤其流行——用于"去数字感"，模拟胶片的柔和高光
- Tiffen 的 Black Pro-Mist 和 Schneider 的 Hollywood Black Magic 是行业标准

### 其他常用滤镜

- **雾镜 (Fog Filter)**：能整体降低画面的锐度
- **柔焦/柔光/扩散滤镜**：diffusion filter，常常用来给女性角色柔化肌肤
- **颜色渐变滤镜**：现在多数通过后期调色实现，但在拍摄中仍可用于特定效果
- **常用组合**：Black Pro-Mist 1/4 + Polarizer + ND（DP 的常见"每日配置"）

## 数字 vs 胶片的选择哲学

### 胶片的"不可替代"特质

1. **曝光宽容度在暗部**：胶片的暗部不是"噪点"而是"颗粒"——视觉上更自然
2. **色彩传递**：胶片的色彩并非"准确"而是"理想化"——富士/柯达的胶片配方本身是一种美学选择
3. **高光滚动 (Highlight Roll-off)**：胶片从高光到白曝的过渡是平滑的"卷曲"——数字传感器则是硬截止
4. **拍摄"被迫"限定**：胶片长度限制（400ft = ~11min / 1000ft = ~22min）迫使导演和 DP 在每一条拍摄前都做好决策
5. **物理"在场"**：胶片的成本迫使全组更聚焦更认真

### 数字的不可逆优势

1. **即时回放（Video Assist）**：导演和 DP 可以立即回放检查表演和构图——胶片需要等冲印
2. **高 ISO 表现**：数字可以在 ISO 6400+ 拍摄，胶片通常止步于 ISO 500-800
3. **后期灵活性**：RAW 格式下可以在后期大幅调整曝光和色彩（尤其是在 Alexa 的 ARRIRAW 格式下）
4. **长时间录制**：一小时的录制不需要更换片盒
5. **成本**：数字不消耗物理介质

### 著名导演的选择

| 导演 | 偏好 | 原因 |
|------|------|------|
| Nolan | 坚定胶片（IMAX 65mm + 35mm） | "观众能看出区别。数字是'伪电影'。" 胶片的高宽容度和真实质感不可替代 |
| Fincher | 坚定数字（RED） | 完美的控制——数字是"精确"的，Fincher 可以拍摄 50-100 条而不用心疼胶片成本。后期完全在 DI 中控制每个像素 |
| Tarantino | 胶片 | "数字是电视。" 但在《八恶人》中使用 70mm 胶片（Panavision 超宽画幅） |
| Cuaron | 灵活切换 | 《罗马》使用 Alexa 65——数字的中性让自然光拍摄更灵活。《人类之子》使用胶片和数字混合 |
| Villeneuve | 数字为主 | 《沙丘》使用 Alexa LF/Alexa 65——IMAX 镜头使用胶片。《降临》数字拍摄。"现代数字已经足够好。" |
| 张艺谋 | 数字（近年） | 从《英雄》的胶片色彩交响到《影》的数字控制——技术服务于视觉风格 |

### 混合工作流

越来越多的项目开始混合数字和胶片：
- **A 机**（主场景）：数字（Alexa LF / RED Monstro）
- **B 机**（特定场景/闪回）：胶片（16mm / S35）
- 示例：《小丑》(2019) —— 主体为 Alexa 65（数字），但 Todd Phillips 选择用 35mm 胶片拍摄闪回序列，以制造"记忆的温度差"
- 示例：《婚姻故事》(2019) —— 主体为胶片，但 Noah Baumbach 与 DP Robbie Ryan 用数字拍摄了激烈的争吵戏——为了"更像电视新闻的真实感"

## 实操指南

### 低成本项目的决策流程

```
预算上限 → 确定可用总金额
    │
    ├── 50%-60% 花在租赁（机身 + 镜头 + 灯光 + 声音）
    ├── 20%-30% 花在后期（调色 + 声音 + VFX）
    └── 10%-20% 花在存储/(备份/现场DIT)

镜头优先级 > 机身优先级（在机身不低于"足够好"的阈值下）
灯光优先级 > 摄影机优先级（好光 + 普通机 > 好机 + 普通光）
```

### 看片与测试

在选定摄影机和镜头前，导演和 DP 应该：

1. **看样片**：找到该机型拍摄的已完成影片——在影院/大屏幕上观看（而非手机屏幕）
2. **做镜头测试（Lens Test）**：
   - 在典型拍摄条件下测试候选镜头组
   - 拍摄肤色、高光、暗部
   - 测试不同光圈下的表现
3. **共同决策**：选择不仅基于技术指标，还要基于"这组工具拍出的画面是否符合这部电影的视觉目标"

## 关键洞察

- **最好的摄影机是你有的那台**：许多导演（Lynch 的《穆赫兰道》部分数字场景、Soderbergh 用 iPhone 拍摄《高飞鸟》）在受限条件下找到创造力
- **"分辨率"不是画质的代名词**：一台 6K RED 不一定比一台 Alexa（原生 3.4K）画面"更好"——色彩科学和动态范围更重要
- **焦段决定情感距离**：不要因为"习惯"选择 50mm 来拍所有戏——每场戏的情感目标应该对应一个焦段选择
- **变形是风格选择，不是升级**：不是所有电影都需要变形——球面的直接感往往是更好的选择
- **数字和胶片都是工具**：没有"正确"的选择，只有"最合适这部电影"的选择。Nolan 和 Fincher 都是对的——因为他们对各自作品的需求完全不同
- **灯光 > 镜头 > 机身**：在预算有限时，预算分配的优先级是布光 -> 镜头 -> 机身。花在灯光上的一块钱比花在摄影机上的一块钱对画面质量的影响更大

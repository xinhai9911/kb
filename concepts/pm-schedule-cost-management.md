# 项目进度与成本管理

## 概述

进度和成本是项目管理中最重要的两个约束维度（与范围一起构成"三重约束"）。

## 进度管理

### PMBOK 进度管理过程

1. **规划进度管理** — 进度计划方法、工具、发布日历
2. **定义活动** — 将工作包分解为具体活动
3. **排列活动顺序** — 前置依赖关系（FS/SS/FF/SF）
4. **估算活动持续时间** — 专家判断、类比估算、参数估算、三点估算
5. **制定进度计划** — 关键路径法（CPM）、关键链法、资源平衡
6. **控制进度** — 进度偏差分析、赶工（Crashing）、快速跟进（Fast Tracking）

### 常用排程技术

- **甘特图（Gantt Chart）** — 可视化任务时间线
- **关键路径法（CPM）** — 确定项目最短工期与浮动时间
- **PERT（计划评审技术）** — 三点估算（乐观/最可能/悲观）

## 成本管理

### PMBOK 成本管理过程

1. **规划成本管理** — 成本管理计划、计量单位、精确度
2. **估算成本** — 类比/参数/自下而上/三点估算
3. **制定预算** — 成本基线 = 估算 + 管理储备
4. **控制成本** — 跟踪实际支出，分析偏差

### 挣值管理（EVM）

EVM 是同时衡量进度与成本的集成方法：

| 指标 | 含义 |
|------|------|
| PV（计划值） | 计划完成工作的预算 |
| EV（挣值） | 实际完成工作的预算 |
| AC（实际成本） | 实际花费 |
| SV = EV − PV | 进度偏差（正数好） |
| CV = EV − AC | 成本偏差（正数好） |
| SPI = EV/PV | 进度绩效指数 |
| CPI = EV/AC | 成本绩效指数 |

## 敏捷中的估算

- **故事点（Story Point）** — 相对估算单位
- **Planning Poker** — 团队集体估算，消除偏见
- **T-shirt Sizing** — S/M/L/XL 快速分类

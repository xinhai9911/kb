# 分切编辑 J-Cut / L-Cut

## 概述

J-Cut 和 L-Cut（合称 Split Edit / 分切编辑）是最常用也是最重要的剪辑手法之一。让**音频和视频不在同一时刻切换**，从而引导注意、平滑过渡、或制造预测偏差。

名称来源于时间线上音视频轨道的形状：
- **J-Cut**：声音先于画面出现 → 轨道形状像字母 J
- **L-Cut**：声音延续到下一画面 → 轨道形状像字母 L

## J-Cut（音频先入 + 视频后切）

**定义**：下一镜头的音频在**当前镜头画面**还在播放时提前出现。

**效果**：
- 引导观众注意力提前转向未见的画面
- 创造流畅的过渡感
- **预测编码视角**：大脑通过提前听到的音频开始预测下一画面，过渡更平滑

**经典用法**：
- 角色先说话，镜头仍在对白对象上 → 镜头切到说话者（对话场景）
- 城市环境音先入，画面仍在前一场 → 切到城市全景（转场）

## L-Cut（视频先切 + 音频后出）

**定义**：当前镜头的音频**延续到**下一镜头的画面中。

**效果**：
- 保持当前情绪/信息流，不被画面切换打断
- 制造思想连续性或情感回响
- 可用于误导：画面已变，声音仍在上一场景，产生不安感

**经典用法**：
- 角色走出房间（画面切到室外），脚步声延续到室外镜头
- 闪回结束：画面回到现在，但音乐仍在延续情绪

## 分切编辑与预测编码

根据 PLOS ONE (2024) fMRI 研究的[[sources/电影 认知 PLOS 一|神经科学证据]]：

- 大脑是**预测机器**，在时间线上不断预测下一刻的感官输入
- **J-Cut 利用了预测机制**：提前入的音频激活了大脑对未来画面的预期，因此当画面最终切换时，过渡感知为"自然"而非"突兀"
- **L-Cut 利用了回响机制**：画面已切换但音频延续，大脑在"已更新的视觉信息"和"未结束的听觉信息"之间协调，产生情感连续性
- 这解释了为什么分切编辑比硬切感觉"更电影化"

## 其他重要剪辑类型

- **硬切（Hard Cut）**：音画同时切换，不加任何过渡
- **匹配切（Match Cut）**：利用构图 / 动作 / 声音的相似性连接两个镜头（如《2001 太空漫游》骨头→飞船）
- **跳切（Jump Cut）**：同一主体的两个相似镜头直接相连，产生时间跳跃感（戈达尔标志性手法）
- **交叉剪辑（Cross-Cutting / Parallel Editing）**：两个或多个场景交替出现，暗示同时发生（《教父》洗礼蒙太奇）
- **Smash Cut**：从安静突然切到极度响亮或极具冲击力的画面，制造惊吓效果
- **隐形切（Invisible Cut）**：利用动作遮挡 / 摇镜 / 暗帧隐藏剪辑点

# 导演与摄影指导的协作

## 定义

摄影指导（Director of Photography / DP / Cinematographer）是导演在视觉层面的首要合作伙伴。DP 负责将导演对场景的情绪和叙事需求转化为具体的镜头、灯光和摄影机运动方案。好的导演-DP 关系建立在**共同视觉语言**之上。

## 沟通工具

### 参考片（Reference Film）

导演和 DP 一起看片，从中提取特定场景的视觉参考。对话模板："这个场景的光我希望像《银翼杀手2049》那样，但摄影机运动更像《锅匠，裁缝，士兵，间谍》。"

### 色彩板（Color Palette / Mood Board）

使用图片（电影截图、摄影作品、绘画）确定影片的色彩方向和整体调性。工具：Pinterest、Milanote、Adobe Color。

### 镜头测试（Lens Test）

在前期阶段用实际摄影机和镜头拍摄测试素材——测试肤色还原、对比度、焦外成像（Bokeh）质感、暗部细节。DP 会准备多组镜头组合供导演选择。

### Shot List / Look Book

- **Shot List**：逐镜头表格，标注景别、角度、运镜方式，由导演和DP协作完成
- **Look Book**：影片整体视觉风格参考册，用于向剧组各部门传达视觉方向

## 关键对话

导演和DP之间最核心的问题只有一个：**"这场戏的情绪是什么？"**

| 情绪目标 | 对应的视觉策略 |
|---------|--------------|
| 不安 / 紧张 | 手持摄影、硬光、高对比度、冷色温 |
| 浪漫 / 温暖 | 柔光、暖色、漫射、浅景深 |
| 孤独 / 疏离 | 广角镜头、负空间、冷色调、背光 |
| 权力 / 压迫 | 低角度、阴影笼罩、深焦 |
| 混乱 / 迷失 | 荷兰角、跳接、多种镜头混合 |

## 信任与分工

好的 DP 不是执行者，而是**贡献者**：

- 导演决定"要什么"——DP 决定"怎么拍"
- 导演可以否决技术方案，但应该给 DP 探索空间
- 在片场，导演对演员负责；DP 对画面负责
- 优秀 DP 会在导演犹豫时给出果断建议

## 创意分歧处理

导演和 DP 之间难免有分歧。健康的分歧处理机制：

1. **引用参考**：用第三方的参考片来客观化讨论
2. **拍两个版本**：时间允许的情况下，双方方案各拍一条
3. **理由优先**：不是"我不喜欢"，而是"这个方案会让观众觉得..."
4. **最终决定权属于导演**——但聪明的导演很少使用这个权力

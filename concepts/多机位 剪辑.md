# 多机位剪辑

## 概述

多机位剪辑（Multicam Editing / Multi-Camera Editing）指使用多个摄像机同时拍摄同一场景，然后在后期从多个角度中选择最佳镜头进行剪辑。广泛应用于访谈、情景喜剧、演唱会、体育赛事和纪录片。

多机位剪辑的核心优势是**时间效率**——剪辑师可以实时切换角度，而非逐一查看每个摄像机的整段素材。

## 多机位拍摄设置

### 常见机位布局

**三人访谈标准**：
- **A Cam**：主机位，正对主持人/核心人物，中景
- **B Cam**：过肩镜头或正对受访者
- **C Cam**：广角全景，覆盖所有参与者
- **D Cam（可选）**：细节特写镜头

**情景喜剧**（典型的四机位）：
- 三个机位覆盖主场景（广角+左右过肩）
- 一个机位专门拍摄观众反应

**演唱会**：
- 舞台正面/侧面主机位
- 跟拍摄影师（Steadicam / 手持）
- 摇臂全景
- 观众反应机位

### 同步方法

| 方法 | 精度 | 适用场景 | 注意事项 |
|-----|------|---------|---------|
| **时间码 (Timecode)** | 帧精确 | 专业制作（所有摄像机使用同一时钟源） | 需要 Jam Sync 或多机时码盒 |
| **波形同步** | 亚帧精确 | 对话/音乐场景 | 软件自动对齐，但需足够音频参考 |
| **打板 (Clapper)** | 帧精确 | 电影/广告 | 手动对齐打板声 + 画幅，人力成本高 |
| **TC + 打板双重保险** | 最高 | 高端影视 | 时间码为主，打板为备份，后期自动同步失败时手动补 |

### 拍摄注意事项

- 所有摄像机使用相同的帧速率（23.976 / 29.97 / 50 / 59.94 fps）
- 所有摄像机使用相同的快门角度和色温
- 录制足够的参考音频（机头麦至少）
- 拍摄前对齐时间码
- 避免交叉画面的机位穿帮

## 多机位剪辑工作流

### 步骤一：素材准备

1. 将所有摄像机的素材拷贝到存储
2. 创建多机位序列（Multicam Clip / Multicam Source Sequence）
3. 软件自动/手动同步所有角度

### 步骤二：实时切换剪辑

在多机位模式下，剪辑师播放多角度画面（通常 2-9 个角度的缩略图），在播放过程中实时点击选择"当前播出画面"。

**切换策略**：
- **反应优先**：切换到说话人的反应镜头而非说话人本人——让观众看到"谁在听"
- **打断（Interruption）**：当有人在讲述关键信息时，切入打断者的反应——创造戏剧张力
- **覆盖（Coverage）**：每 5-30 秒切换一次，避免单一机位过长
- **全景重置**：每段对话后切回全景，让观众重新确认空间关系

### 步骤三：精剪

1. 解除多机位剪辑（Flatten / Disable Multicam）
2. 逐帧调整切换点（对齐动作最高点）
3. 添加二级修剪（Trim clips individually）

### 步骤四：画面微调

- 调整相邻镜头的白平衡和曝光匹配
- 微调各机位的裁剪和重新构图
- 添加 B-Roll 覆盖

## 各 NLE 多机位操作

### [[entities/DaVinci Resolve|DaVinci Resolve]]

- **创建**：在媒体池选择多个片段 → 右键 → `Create Multi-Cam Clip`
- **同步方式**：波形、时间码、打板、In Point
- **操作**：Viewer 下方显示多角度缩略图，按 1-9 数字键切换
- **特色**：支持最多 36 个角度；可在剪辑页面和 Fairlight 页面同步操作
- **高级**：自动同步后可以手动微调各角度的偏移

### [[entities/Adobe Premiere Pro|Adobe Premiere Pro]]

- **创建**：选择多个片段 → 右键 → `Create Multi-Camera Source Sequence`
- **同步方式**：In Point、Out Point、时间码、打板
- **操作**：源监视器显示多角度画面，按 1-9 切换
- **特色**：支持嵌套序列作为角度；CS 模式可在多个角度间实时切换
- **键盘**：Shift+数字键 切换并剪切该角度到时间线

### [[entities/Apple Final 剪辑 Pro|Apple Final Cut Pro]]

- **创建**：选择多个片段 → `File` → `New Multicam Clip`
- **同步方式**：波形自动同步（Analysis Type: Audio）、时间码、打板
- **操作**：Angle Angle Viewer 实时切换
- **特色**：**自动同步**能力在 NLE 中最强——可一键同步混合角度和格式
- **限制**：最多支持 16 个角度

### [[entities/Avid 媒体 合成器|Avid Media Composer]]

- **创建**：通过 Group Clip 功能实现
- **同步方式**：Aux TC、Timecode、打板
- **操作**：MultiCamera Mode 按钮
- **特色**：MultiGroup 功能可在不同分组间切换
- **限制**：操作较复杂，需要助理剪辑专门创建 Group Clip

## 角度切换策略

### 基于对话的分析

- 切入说话者 → 建立信息源
- 切入听者 → 建立情感反应
- 过肩镜头 → 建立空间关系
- 特写 → 强调情感细节

### 基于节奏的分析

| 场景类型 | 平均镜头时长 | 切换节奏 |
|---------|------------|---------|
| 纪实对话 | 8-15 秒 | 慢，从容 |
| 戏剧对话 | 3-8 秒 | 中等 |
| 动作/打斗 | 1-3 秒 | 快，碎片化 |
| 体育 | 3-5 秒 | 中等偏快 |
| 访谈（单人） | 15-60 秒 | 慢，主要看反应 |

### 常见错误

- 同一角度使用太久 → 视觉疲劳
- 过度切换 → 观众晕眩
- 越轴切换 → 空间关系混乱
- 在人物眨眼/动作不连贯时切 → 跳跃感

## 多机位 vs 单机位选择

| 维度 | 多机位 | 单机位 |
|-----|-------|-------|
| 拍摄效率 | 一次完成全部覆盖 | 需反复重拍各角度 |
| 剪辑灵活性 | 角度有限 | 最灵活 |
| 光照控制 | 需照顾所有角度 | 单角度最优 |
| 穿帮风险 | 机位可能穿帮 | 无 |
| 预算 | 设备+操作成本高 | 较低 |
| 典型场景 | 访谈、现场、喜剧 | 电影、广告 |

# 色彩理论与调色方案实战

## 色轮基础

### HSL 三个维度

| 维度 | 定义 | 调色操作 |
|------|------|---------|
| Hue（色相） | 色彩的波长位置（0°-360°） | 色相偏移调整整体颜色倾向 |
| Saturation（饱和度） | 色彩的强度/纯度（0-100%） | 饱和度拉高=鲜艳，拉低=灰化 |
| Lightness/Luma（亮度） | 色彩的明暗程度 | 一级调色的 Lift/Gamma/Gain 控制 |

数字调色中的所有操作都可以归为这三个维度的调整。理解该三维度是操作色轮/矢量示波器/波形监视器的基础。

### 色轮与矢量示波器

- **色轮**：圆心=中性色，圆周=饱和色。调色师通过控制杆从中心向外拉动调整色偏
- **矢量示波器 (Vectorscope)**：显示画面色相和饱和度的分布。肤色线（SKIN TONE LINE）在 11 点钟方向
- **波形监视器 (Waveform)**：显示亮度分布。YRGB 模式显示每个通道的亮度

## 色彩调和方案

### 互补色 (Complementary)

色轮上相对的颜色（180° 对位）。产生最强烈的视觉对比。

```
Red ↔ Cyan
Green ↔ Magenta
Blue ↔ Yellow
```

应用：主体色 + 背景互补色 = 画面层次清晰。Teal & Orange 即此原理的特例。

### 类似色 (Analogous)

色轮上相邻的颜色（30°-60° 范围）。产生和谐安静的视觉效果。

应用：自然风光、温馨家庭场景。渐变过渡自然，不产生视觉紧张。

### 三角色 (Triadic)

色轮上三等分（120° 间距）。保持对比的同时比互补色更丰富。

应用：动画片、儿童节目、MTV 等需要活泼氛围的场景。

### 分裂互补色 (Split Complementary)

一个主色 + 其互补色两侧的颜色（形成 30°-150°-150° 分布）。

比直接互补色更柔和，保留视觉张力但减少生硬感。

### 四角色 / 双互补 (Tetradic / Double Complementary)

两组互补色形成矩形（60°-120°-60°-120°）。

最难驾驭的方案，适用于高度风格化的作品。

## 经典电影调色方案与情绪

### Teal & Orange（蓝橙互补）

原理：橙色（肤色）与青色（背景）在色轮 180° 相对，主体与背景自然分离。

经典运用：
- 《变形金刚》系列——Michael Bay 标志性配色
- 《疯狂的麦克斯：狂暴之路》——沙漠橙 + 天空青
- 几乎所有好莱坞大片级动作片/科幻片

技术实现：
- Lift/Shadows 偏移至青蓝色
- Gain/Highlights 偏移至暖橙色
- 保留肤色在橙色区域，其余画面拉向青蓝
- Qualifier 选区只调背景，不影响肤色

### 褪色 / 漂白 (Bleach Bypass / Desaturated)

原理：跳过胶片显影中的漂白步骤，银盐保留增加对比度，同时降低饱和度。

视觉特征：
- 高对比度 + 低饱和度 + 黑色压缩
- 画面呈现"金属感"

经典运用：
- 《拯救大兵瑞恩》——诺曼底登陆段，模拟战争新闻片
- 《疯狂的麦克斯：狂暴之路》——高对比低饱和度沙漠
- 《七宗罪》——黑暗、压抑的褪色效果
- 《罪恶之城》——极致化：丢弃饱和度保留高对比

技术实现：
- Contrast 大幅拉高
- Saturation 降至 20-40%
- Lift 降低，Gain 提升（扩展黑白范围）
- 红色或肤色可有选择地保留（二级调色）

### 单色 / 低保和 (Monochrome / Desaturated)

原理：完全或极度降低饱和度，用亮度层次传递信息。

经典运用：
- 《辛德勒名单》——小女孩红大衣是唯一色彩，其余黑白
- 《罗马》——黑白但保留胶片颗粒和灰阶纹理
- 《曼彻斯特海边的一天》——极低饱和度，冷色为主
- 《极简主义》——以灰阶和质感为主的纪录片

技术实现：
- Saturation 降至 0-10%
- 用黑白曲线精确控制灰阶分布
- 如果要保留选区的颜色，使用 Power Window + Qualifier

### 高饱和温暖 (Warm Saturated)

原理：拉高饱和度 + 色温向暖色偏移。传递快乐、怀旧、浪漫。

经典运用：
- 《爱乐之城》——莱恩·高斯林和艾玛·斯通的紫色夕阳场景
- 《布达佩斯大饭店》——粉红 + 紫 + 蓝的高饱和度 palette
- 《天使爱美丽》——绿色 + 红色的强烈暖调

技术实现：
- 白平衡色温调至 5500K+
- Saturation 整体提升（+20-40%）
- 特定颜色可通过 Hue vs Sat 曲线微调

### 冷色调 (Cool)

原理：色温向蓝色偏移，降低肤色饱和度或让肤色偏冷。

情绪：冷淡、疏离、科技感、恐惧、未来。

经典运用：
- 《黑客帝国》——标志性绿调（Matrix Green）
- 《七宗罪》——青蓝色冷调 + 高对比黑色
- 《银翼杀手 2049》——冷蓝 + 橙色补充
- 《机械姬》——冷白光代表 AI 的冰冷美学

技术实现：
- 色温向蓝色偏移（-2000K 左右）
- Shadows 加青蓝
- 肤色用二级调色降饱和或加绿/蓝
- 绿色或蓝色在 Highlights 中可选择性保留

### 胶片模拟 (Film Emulation)

模拟不同胶片的色彩科学：

| 胶片类型 | 特征 | 调色模拟 |
|---------|------|---------|
| Kodak Vision3 2383 | 暖色倾向，肤色偏橙 | Print Film LUT + 暖色偏移 |
| Fuji Eterna | 冷色倾向，肤色偏青 | 冷色 Look + 降饱和 |
| Kodak Tri-X 黑白 | 颗粒感 + 硬调 | 黑白 + Gain 压暗 + Grain |
| Kodak Portra | 柔和肤色，欠饱和 | 柔光过渡 + 皮肤 Hue 微调 |

## 创建自己的 Look

### 参考片分析流程

1. **截图**：从参考影片中截取风格鲜明的画面
2. **波形分析**：在 Resolve 中导入参考帧，用波形示波器分析亮度分布
3. **矢量分析**：用矢量示波器看色相分布的主倾向
4. **定性**：记录色温（冷/暖）、对比度（高/中/低）、饱和度、主色调

### 从分析到 LUT

```
参考帧分析 → 一级调色匹配 → 二级调色微调 → 输出 33x LUT → 应用到项目
```

- Resolve 内置"Shot Match"工具可自动匹配参考帧的色彩
- LUT 的规格：Cube 格式，33x33x33 点阵最常用
- LUT 不应包含一级调色（升格/降格问题），应只包含风格化转换

### LUT 类型

| 类型 | 输入 | 输出 | 用途 |
|------|------|------|------|
| Input LUT | Log | Rec.709/Rec.2020 | Log 素材转换到监看色彩空间 |
| Look LUT | Rec.709 | Rec.709 | 风格化转换（Teal & Orange 等） |
| Output LUT | 调色后 | 交付色彩空间 | SDR ↔ HDR 转换 |
| Calibration LUT | 标准信号 | 显示器特性 | 显示器校准（3D LUT） |

**不可链式**：不要在输入 LUT 之上再加输入 LUT，会破坏黑场和白场。

### 制作步骤（Resolve）

1. 导入参考帧到 Gallery > Stills
2. 右键参考帧 > Shot Match to Current Clip
3. 调整 Lift/Gamma/Gain + Contrast + Saturation 做一级匹配
4. 用 Color Wheels + Curves 做二级风格化
5. 右键片段 > Generate LUT（Cube 格式）
6. 命名为 `LookName_33.cube`

## 调色前的色彩校准流程

### 显示器校准

调色准确性依赖显示器校准。未校准的显示器会让调色在观众屏幕上无法复现。

- **硬件校准**：使用 X-Rite i1 Display Pro 或 Datacolor Spyder X
- **目标**：D65 白点（6500K）、Gamma 2.4（Rec.709）、100 cd/m² 亮度
- **频率**：每月一次，尤其 OLED 显示器漂移更快

### 监看环境

- 环境光控制在 10 cd/m² 以下（暗室）
- 墙壁中性灰（18% gray），避免色彩反射干扰
- 显示器背光不要直视眼睛

### 示波器参考

在未校准的显示器上调色时，完全依赖示波器：

- **Waveform**：黑电平不裁切（0%），白电平不裁切（100% 或 109% 超白）
- **Vectorscope**：确认肤色在 skin tone line
- **Histogram**：确认无频率缺失（gap）或堆积（clipping）

### 色彩空间设置

- 项目色彩空间应与素材匹配（Rec.709 / Rec.2020 / ACEScc）
- 调色套用 LUT 前先确认素材的色彩空间和 Gamma
- Log 素材必须先应用 Input LUT 或色彩空间转换到工作色彩空间

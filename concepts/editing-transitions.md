# 剪辑转场类型全解

## 概述

转场（Transition）是剪辑中连接两个镜头的技术手段。选择何种转场直接影响叙事节奏、情绪传达和观众的沉浸感。传统好莱坞连续剪辑追求"隐形"的转场，而风格化剪辑则利用特定转场创造修辞效果。

## 视觉转场

### 硬切 (Hard Cut / Straight Cut)

最常见的转场——两个镜头直接首尾相接，不附加任何光学效果。

- **何时用**：默认选择，观众"不应该"注意到的场景过渡
- **何时不用**：需要明确的时间跨度或地点转换信号时
- **变体**：Smash Cut — 在安静场景后骤然切入激烈画面，用于制造冲击

### 溶解 (Dissolve / Cross Dissolve)

前一个画面逐渐淡出，同时后一个画面逐渐淡入，两者有一段时间重叠。

- **何时用**：表示时间流逝、地点转换、或柔情回忆
- **何时不用**：需要快速节奏或强烈冲击感时
- **时长约定**：24fps 下典型溶解 16-24 帧（约 0.7-1 秒），长溶解（2-4 秒）表示更长时间跨度

### 淡入淡出 (Fade In / Fade Out)

画面完全变为黑色（或白色）再出现新画面。

- **Fade to Black**：段落的结束，类似幕布落下——常用于正片结束或重大时间跳跃
- **Fade to White**：较少使用，通常表示梦境、记忆或迷失感
- **何时用**：章节结束、长时间的叙事停顿
- **何时不用**：同一连续场景中——会打断节奏

### 擦除 (Wipe)

一条明确的边界线横跨画面，像"擦去"上一个镜头露出下一个。

- **何时用**：星球大战系列将其作为风格标志；也用于表现并列对比
- **何时不用**：严肃现实主义风格——擦除过于"有意"

### 虹膜 (Iris)

画面从中心圆形扩展开（Iris In）或收缩到一点（Iris Out）。

- **何时用**：默片时代标志性转场；现代偶尔用于复古风格或强调细节
- **变体**：Iris Wipe — 以几何形状而非圆形做边缘

## 匹配转场

### 匹配切 (Match Cut)

利用构图的相似性将两个镜头连接在一起，让观众"看到"视觉上的对应关系。

**经典案例**：
- [[entities/walter-murch|2001 太空漫游]]——猿人抛骨 → 太空飞船（形状匹配：骨头→飞船）
- [[entities/walter-murch|现代启示录]]——转动的风扇桨叶 → 直升机旋翼（运动匹配）
- 劳伦斯·奥立佛的《亨利五世》——后台化妆 → 正式台词（情境匹配）

**变体**：
- **形状匹配 (Graphic Match)**：画面构图或形状相似
- **运动匹配 (Motion Match)**：画面中物体的运动方向和速度匹配
- **声音匹配 (Sound Match)**：后一个镜头的第一个声音"叠"在前一个镜头的最后一个声音上

### 匹配溶解 (Match Dissolve)

匹配切 + 溶解的组合——两个相似构图在溶解过程中对齐。广泛应用于纪录片和历史剧中的时间转换。

## 声音转场

声音转场是比画面转场更具叙事效率的手段。

### 声音桥接 (Audio Bridge / Sound Bridge)

后一个场景的声音在前一个场景结束前开始（声音提前），或前一个场景的声音延续到后一个场景（声音延续）。

- **声音提前 (Audio Lead)**：先听到下个场景的声音，再看到画面——类似 J-Cut 但不仅限于对白
- **声音延续 (Sound Hold)**：上个场景的环境声延续到新场景——用于建立情感联系

### L-Cut / J-Cut

参见 [[concepts/split-edits-j-cut-l-cut]]。

### 其他声音转场技巧

- **声音叠化 (Audio Dissolve / Crossfade)**：两条音轨的电平渐变交换，与画面溶解同步或不同步
- **无声/骤静 (Silence / Dead Cut)**：主动切断所有声音 1-3 帧，制造停顿感
- **WFX (Whoosh)**：快速划过声效遮盖硬切，常用于节奏剪辑或动作场景

## 特殊转场类型

### 隐形剪辑 (Invisible Cut)

通过精心的画面设计让观众完全察觉不到剪辑点的存在。

**技术手段**：
- **Whip Pan**：快速甩镜头时切，两段甩镜在模糊处接合
- **Whip Zoom**：同上，快速变焦推拉
- **遮挡剪辑 (Cutting on Action / L Cut)**：物体或人物完全遮住画面时剪辑
- **匹配地形**：利用画面的明暗/色彩在切点处匹配

典型的"一镜到底"长镜头电影（如《1917》《鸟人》）实际上由数十个隐形剪辑拼接而成。

### 跳跃剪辑 (Jump Cut)

同一人物或场景中，两个镜头在时间上不连续、在空间位置上相近，造成"跳跃"感。

**有意 Jump Cut**（风格化手段）：
- 戈达尔的《精疲力尽》——新浪潮标志性手法，打破连续剪辑规则
- 现代 YouTube / 自媒体——删除冗余停顿，压缩时间
- 科恩兄弟电影——制造不安或荒诞感

**无意 Jump Cut**（需要避免）：
- 越轴剪辑导致的视线跳跃
- 同一镜头中运动不连续
- 不同 take 之间表演或位置不匹配

## 转场选择指南

| 叙事意图 | 推荐转场 | 理由 |
|---------|---------|------|
| 时间推进（短，同一场景） | 硬切 | 最自然 |
| 时间推进（长，跨场景） | 溶解 → 黑场 → 新场景 | 视觉分段 |
| 地点转换 | 擦除 / 匹配切 | 明确标志 |
| 强烈对比 | Smash Cut | 最大化冲击 |
| 模糊/梦境感 | 长溶解 / 声音桥接 | 柔化过渡 |
| 节奏压缩 | Jump Cut | 消除冗余 |
| 观众参与感 | 匹配切 | 创造联系 |
| 完全沉浸 | 隐形剪辑 | 不打断叙事流 |

## 与叙事心理学的关系

转场选择深刻影响观众认知。[[concepts/narrative-psychology-editing|剪辑叙事心理学]]的预测编码理论表明：当转场符合观众预期（如场景结束→淡出→新场景），大脑可以无缝处理；当转场打破预期（如 Smash Cut），大脑需要额外努力建立因果联系——恰恰是这个"理解成本"创造了情绪冲击。

# 电视剧导演方法

## 电视剧 vs 电影导演的核心差异

电视剧导演与[[concepts/电影 制作 工作流|电影导演]]的工作存在根本性差异。电影导演是作品的最终作者，而电视剧导演（尤其是单集雇佣导演）更像一个"代笔人"——在已建立的视觉系统和叙事框架中完成指定集数。

| 维度 | 电影导演 | 电视剧导演（单集雇佣式） |
|------|---------|----------------------|
| 创作控制权 | 导演拥有 Final Cut（或与制片人共享） | 导演服从 Showrunner 的视觉/故事决策 |
| 制作周期 | 6 个月到数年 | 8-10 天/集（一小时剧集） |
| 剧本来源 | 自己写或深度参与 | 几乎是固定剧本，导演不修改 |
| 视觉风格 | 导演决定整体视觉 | 导演继承已有视觉框架（Look Book / Style Guide） |
| 后期参与 | 深度参与剪辑/调色/混音 | 导演通常不参与后期 |

## Showrunner 制

Showrunner（创剧人/执行制片人）是美剧独有的核心角色，同时担任总导演、总编剧和制片人三重职能。Showrunner 是全季/全系列的最高创作权威。

- **Showrunner 的日常**：审阅所有剧本、看每日素材(Dailies)、批准剪辑、管理编剧室、与制片厂/电视台沟通
- **典型Showrunner**：David Chase（《黑道家族》）、Vince Gilligan（《绝命毒师》）、David Benioff / D.B. Weiss（《权力的游戏》）、Sam Levinson（《亢奋》）
- **Showrunner 不一定是导演**：许多 Showrunner 只导演试播集或关键集，其余集数交给雇佣导演
- **英国模式**：传统上由"制片人"而非"创剧人"主导，但近年已趋近美式 Showrunner 制

## 剧集类型对导演的影响

- **单集雇佣导演（Episode Director）**：最常见的模式。导演进入已运行数季的剧组，在既有视觉模板下工作。典型的《法律与秩序》式流程：5 天 Pre-pro + 8 天拍摄 + 不参与后期
- **导演-制片人（Director-Producer）**：在剧集内同时担任制片职务，参与创意方向讨论，通常每季导演 2-4 集
- **剧集创导（Creator-Director）**：独立创作并导演全季（迷你剧较多，如《切尔诺贝利》Johan Renck、《后翼弃兵》Scott Frank）
- **有限剧集导演**：6-10 集常由同一导演完成全部或大部，制作节奏接近长电影的分段拍摄

### 多导演协作与视觉统一

同一剧集有多位导演分别执导不同集数时，视觉统一是关键挑战。

- **Style Bible（风格圣经）**：剧集建组初期由主创 DP 和美术指导制作的参考手册，包含色彩脚本、灯光方案、镜头语言规则
- **每日素材审阅（Dailies Review）**：Showrunner 和 DP 审阅所有导演的每日素材，确保风格一致
- **Look Book / Mood Boards**：为每季甚至每集创建视觉参考板
- **重复使用拍摄方案**：同一场景/角色的灯光和镜头方案需横跨多集保持一致
- **剪辑统调**：后期阶段通过调色和声音设计抹平导演间差异

## 试播集（Pilot）的特殊地位

试播集是剧集中最特殊的集数。它承担着：确立视觉风格、建立角色基调、定下叙事节奏、说服电视台/流媒体续订的多重任务。

- **Pilot 通常由剧集创导或资深导演执导**，作为全剧的视觉模板
- **Pilot 制作耗时**通常为普通集数的 2-3 倍
- **Pilot 后的风格偏移**：剧集续订后，Pilot 中的某些元素可能会改变（演员替换、角色调整）
- **Pilot 的遗留问题**：Pilot 的视觉决策会成为整剧的约束——换 DP 后需延续 Pilot 的视觉语言
- **Netflix 的"Pilot 消亡"**：流媒体更倾向于直接预订全季（Straight-to-Series），跳过传统 Pilot 阶段

## 长篇剧集导演挑战

长期运行的剧集（5 季以上）存在独特的导演挑战：

- **角色一致性**：角色在第 5 季的行为逻辑必须与第 1 季自洽
- **演员关系动态**：演员间真实的私人关系变化会影响场景表演
- **续约不确定性**：编剧无法确认下季演员是否回归，影响季末叙事设计
- **视觉风格演变**：随着技术升级（4K/HDR/大画幅）和审美变化，视觉风格需要渐进式演变
- **观众预期管理**：老观众有固定的期待，新观众需要被快速带入

## 流媒体剧集 vs 传统电视

流媒体（Netflix/Apple TV+/Prime Video/HBO Max）从根本上改变了电视剧导演的工作方式：

| 传统电视 | 流媒体 |
|---------|--------|
| 固定时长（42 分钟/22 分钟） | 变长时长（30-80 分钟，视故事需要） |
| 广告插入决定节奏（Act Break） | 无广告，叙事节奏更接近长电影 |
| 每周一集，需设计每集悬念（Cliffhanger） | 一次性发布（Binge Release）或分批发布 |
| 更紧的预算和拍摄天数 | 接近独立电影的预算水平 |
| 审查制度更严格（网络标准部/ Broadcast Standards） | 更宽松的内容限制 |
| 完整 Pilot 测试后再续订 | Straight-to-Series 直接预订 |

流媒体的"电影化"趋势正在模糊电视剧和电影的界限——许多剧集（如《继承之战》《最后生还者》《怒呛人生》）的制作标准已完全对标电影，使用变形宽银幕镜头、ARRI Alexa LF/65 等电影级设备。

## 电视剧导演的工作流

### Pre-Production（通常 5-10 天）

- 读剧本 → 与 Showrunner 讨论解读方向
- 技术堪景（与 DP、美术一起）→ 制定拍摄计划
- 选角（如果该集有客串角色）
- 创建 Shot List / Floor Plan
- 与 DP 讨论视觉方案（遵守 Style Bible 的前提下争取个人发挥空间）

### Production（通常 6-10 天/集，视集数预算而定）

- 日拍摄量：4-7 页剧本/天（电影通常 1-3 页/天）
- 快速走戏 → 调光 → 拍摄 → 下一镜
- **导演在片场的决定权更小**——必须服从大日程(Master Schedule)
- 需要更快速地与演员建立信任（演员只有几天时间认识你）

### Post-Production（导演通常不参与）

- 导演拍完即进入下一集 Pre-pro
- Showrunner/剪辑师/制片人完成剪辑
- 导演可能被邀请看导演剪辑版(Director's Cut)——但最终由 Showrunner 决定

## 电视剧导演的核心能力

- **快速阅读剧本**：在几天内理解一集在整季中的叙事位置
- **继承风格的能力**：在他人建立的视觉系统内工作，同时保持个人触感
- **高效沟通**：时间紧迫下，明确而不含糊的指令是关键
- **适应不确定性**：剧本可能拍摄当天还在改，失去控制是常态
- **与"日常"共处**：电视剧的日常节奏意味着导演需要在高强度下保持创造力

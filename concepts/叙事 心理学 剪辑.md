# 剪辑的叙事心理学

## 概述

剪辑不仅是技术流程，更是一套**操纵观众认知**的工具。从 Kuleshov 效应到现代神经影像学，研究发现观众的大脑在观看剪辑时自动构建因果关系、预测后续内容、并产生情绪回响。

## 库里肖夫效应（Kuleshov Effect）

1920 年代 Lev Kuleshov 的实验：同一张无表情的脸接不同的画面（棺材/食物/风景）→ 观众读出不同的情绪（悲伤/饥饿/喜悦）。证明**蒙太奇创造意义**，意义不在单个镜头中。

**2024 年 fMRI 验证**（[[sources/电影 认知 PLOS 一|PLOS ONE 研究]]）：
- 有序蒙太奇激活前额叶皮层、颞上沟、楔前叶——社会认知与因果推理区域
- 随机排列则无此激活
- 观众自动构建"叙事黏合"——将两个独立镜头视为有因果关系
- 该过程在意识层以下自动发生

## 预测编码（Predictive Coding）

预测编码理论认为：**大脑是一台预测机器**，不断根据过去预测未来的感官输入。

**剪辑中体现为**：
- 每一帧都是对下一帧的预测
- **J-Cut**：提前入的音频激活了对未来画面的预测，过渡更自然
- **硬切**：打破了预测 → 注意力被重新捕获
- **跳切**：预测失败 → 感知到时间断裂
- **匹配切**：预测被顺势满足，过渡平滑
- 对预测的违反程度 = 观众感受到的"剪辑存在感"

## 神经电影学（Neurocinematics）

使用 fMRI / EEG / GSR 等工具量化观众响应：

- **观影时脑间同步（Inter-Subject Correlation / ISC）**：高度剪辑的电影（主流好莱坞）在不同观众中引发相似的脑活动模式
- **长镜 / 慢节奏片**：ISC 较低，每个观众的神经响应更个性化
- 剪辑节奏越急促，脑间同步越高——观众"失去"个体差异

## 认知负荷与流畅度

- **剪辑流畅度（Editing Fluency）**：观众加工剪辑序列的容易程度
  - 越流畅 → 越沉浸（叙事吸收）
  - 越不流畅 → 越清醒意识到"这是电影"
- **180 度规则**的认知基础：不越轴维持空间一致性，降低认知负荷
- **30 度规则**：同主体镜头切换时角度变化需 > 30 度，否则产生跳切

## 剪辑作为"注意力操控"

- **眼动追踪研究**：剪辑利用视觉注意力机制引导视线
- **视线匹配切（Eyeline Match）**：角色看 → 看到什么，利用人的意图理解系统
- **动作匹配**：利用运动连续性跨越空间/时间断裂
- **剪辑频率与情绪**：快剪 → 紧张/兴奋；慢剪 → 沉思/悲伤

# 导演与音乐叙事

## 概述

音乐是电影中最直接作用于情感的工具——好的音乐在几秒内就能让观众落泪、紧张或振奋。但导演在音乐上的挑战不是"找首好曲子"——而是决定什么时候\*不要\*用音乐、用什么样的音乐、如何让音乐不是"贴上去的"而是"长出来的"。

本页从导演视角审视音乐的使用——不涉及作曲技术，而是聚焦于导演在配乐/选曲上的决策框架以及与作曲家的协作。

与 [[concepts/导演 声音]] 的"整体声音叙事"互补。

## 配乐 vs 选曲：导演的两条路径

### 配乐（Score / Original Score）

专门为这部电影创作的音乐。

| 优势 | 劣势 |
|------|------|
| 完全贴合电影的节奏和情绪 | 制作周期长、成本高 |
| 可以贯穿整部电影发展主题 | 需要作曲家对导演意图的深度理解 |
| 音乐可以"写"给特定角色/主题/地点 | 不好的配乐比不好的选曲更跳戏 |
| 导演拥有全局音乐控制权 | 导演需要知道如何"说明"音乐需求 |

### 选曲（Source Music / Diegetic Music）

借用已有的歌曲或录音——可以是角色在场景中听到的（收音机/耳机/现场音乐）或仅作为配乐。

| 优势 | 劣势 |
|------|------|
| 自带文化/时代语境（1960年代老歌瞬间锚定时代） | 版权费用高昂（著名歌曲可能数十万到百万美元） |
| 歌词可以直接参与叙事（歌词与角色的关系产生 "意义的第三层"） | 歌曲的"预设情感"可能限制导演的控制 |
| 快速建立观众情感关联（熟悉歌曲 → 立即唤起听者个人记忆） | 观众可能被歌曲"带出"电影（"这不是我喜欢的歌"） |
| 可以形成风格签名（Scorsese/昆汀/Wes Anderson） | 过度依赖选曲可能显得偷懒或缺乏原创性 |

### 混合策略

大多数电影采取配乐+选曲混合策略：

- **配乐**用于关键情感线和主题
- **选曲**用于时代建立、场景过渡、角色特征
- 《Guardians of the Galaxy》是极端混合案例——选曲不再是背景而是叙事主线（主角个性通过他的"混录带"定义）

## 音乐的叙事功能

### 情绪渲染

最传统也最直接的功能——音乐告诉观众"应该感到什么"。

- 小调→悲伤、紧张、不祥
- 大调→安心、快乐、希望
- 不和谐音→不安、恐惧、危险
- 但要注意：过度使用情绪提示会让观众感到被操纵——不如在某些情绪时刻"不给音乐"让观众自己感受

### 节奏控制

音乐可以改变场景的"感知速度"：

- **加速**：快速节奏的音乐叠加在常规叙事上——让观众感到时间加速

  - 《Goodfellas》Copa Cabana 长镜头——手推车角度、人物快速行动、频繁移动——\~ 快节奏把观众卷入兴奋和失控
- **减速**：缓慢的音乐让时间感觉被拉长

  - 《Inception》中慢速版的"Non, Je Ne Regrette Rien"——旋转中的坠落变得永恒
- 节奏对抗：画面节奏快 × 音乐节奏慢（或反之）——制造不安、张力或诗意

### 主题标识

音乐主题（Leitmotif）是电影最强大的叙事工具——每种情感/每个角色/每个概念可以有自己专属的音乐"签名"。

- **角色主题**：Vader 的《帝国进行曲》、印第安纳·琼斯的号角、007 主题
- **关系主题**：James Horner 在《Titanic》中的 "My Heart Will Go On"——不仅对应 Jack-Rose 的关系，也对应"船"本身的浪漫/悲剧
- **地点主题**：《指环王》的夏尔主题 vs 魔多主题——音乐直接告诉观众"你在哪儿/你处于什么样的情感空间"
- **概念主题**：《Inception》中低音号代表"时间流逝"的物理感受

### 叙事反点

音乐与画面\*不匹配\*——这是最精妙的音乐叙事方式：

- 暴力画面上播放欢快音乐（《A Clockwork Orange》中 Alex 伴着《雨中曲》打架）
- 悲伤画面上播放欢快音乐（《The Truman Show》结尾的背景音乐与主角的情绪对比）
- 中性画面上播放悲伤音乐（预告未知的悲剧）
- 叙事反点迫使观众同时体验两个矛盾的情绪——产生复杂的、不单一的观影体验

## Temp Track 的用法与风险

Temp Track（临时音轨）是导演在剪辑阶段为场景临时贴上的参考音乐——通常是已有电影的原声，用来"感受"场景的节奏和情绪。

### Temp Track 的作用

- 剪辑师用 Temp Track 决定场景的节奏（音乐的速度给出了"剪辑节拍"）
- 导演用 Temp Track 向作曲家"说明"想要的情绪——这是一种"参考音乐"而非"最终需求"
- 让非音乐出身的导演能够\*具体\*地表达音乐需求（"像 Hans Zimmer 在《Inception》第 2 轨那样"）

### Temp Track 的风险

- **Temp Love**：导演/制片人习惯了 Temp Track 后，无法接受作曲家原创音乐的"不同"——虽然原创音乐更好，但"听起来不一样"导致导演拒绝
- 这是作曲家最常见的抱怨：Temp Track 绑架了最终配乐的原创性
- **临时情绪的固化**：Temp Track 的节奏/和声被"剪进"电影——作曲家必须匹配这个节奏，不能完全自由创作
- 解决方法：导演必须知道"Temp Track 是一种参考，不是一种需求"——给作曲家的 Brief 应该基于"情绪"而非"听起来像某人的配乐"

## 与作曲家的协作

### Spotting Session

导演和作曲家一起看剪辑完成的电影，决定音乐在什么时候需要、什么时候不需要。

- 逐场判断：这个场景需要音乐吗？如果需要，什么样的音乐？什么情绪、节奏、乐器？
- 导演告诉作曲家：这个场景的情感目标是什么，观众应该感受到什么
- 作曲家告诉导演：音乐的"进入点"和"退出点"在哪里——有时作曲家的直觉比导演更准
- Spotting Session 的产出：\*Spotting Notes\*——一页每个音乐 cue 的详细描述

### 主题发展

作曲家基于 Spotting Session 创作核心主题，然后在整个配乐中发展：

- **主题呈现**：电影早期把核心主题完整演奏一次（建立"这个旋律"= 这个情感）
- **主题变奏**：主题在不同情境下被变化——加速、减速、改变乐器、改变和声
- **主题分裂**：大主题被分解为短小的动机（cell）——用于更细致的叙事点
- **主题的交织**：两个主题在同一段落中交替或重叠——暗示两种情感/概念的同时存在

### 导演与作曲家沟通清单

- 我想让观众在这个场景\*感到\*什么？（具体到动词：不安/兴奋/感伤/悬疑/忧郁/怀旧）
- 音乐应该是"画面上"还是"画面下"？(Source vs Score)
- 音乐是"告诉观众怎么想"还是"让观众自己感受"？(Emotion-leading vs Emotion-reflecting)
- 这个场景的节奏（时间感）是什么？(快速/中速/缓慢/无节奏感）
- 有什么乐器/音色与这个角色/场景的精神共鸣？
- 这是"西方音乐"还是"非西方音乐"体系？(调性 vs 无调性/五声音阶 vs 十二音）

## 经典导演-作曲家搭档

### Steven Spielberg / John Williams

- 电影史上最长、最成功的导演-作曲家合作（1974-present, 超越 30 部电影）
- Williams 是 Spielberg 的情感"翻译器"——Spielberg 描述一种视觉感受，Williams 把它转化为旋律
- 合作方式：Spielberg 给 Williams 极大自由——Williams 可以先写出主题，Spielberg 再围绕音乐调整剪辑
- 产物：电影史上最著名的主题之一——鲨鱼主题（Jaws）、印第安纳琼斯号角、ET 飞行主题、《辛德勒的名单》小提琴独奏

### Christopher Nolan / Hans Zimmer

- 合作周期：2005-2020（蝙蝠侠三部曲、《Inception》、《Interstellar》、《Dunkirk》）
- Zimmer 的电子+管弦混合风格完美匹配 Nolan 的时间与空间主题
- 合作方式：Zimmer 经常在拍摄之前就写出主题，Nolan 在片场播放 Zimmer 的音乐给演员营造氛围
- 《Inception》的"Non, Je Ne Regrette Rien"使用是 Nolan 在剪辑中引入 Temp Track，Zimmer 在此基础上创作
- 《Interstellar》中 Zimmer 在接到任何信息前只收到了一个词："父亲"

### Sergio Leone / Ennio Morricone

- 合作定义了"意大利面西部片"（Spaghetti Western）的声音——口哨/人声/电吉他/口琴的革命性组合
- Morricone 在\*拍摄前\*就写出音乐主题——Leone 在片场用 Morricone 的音乐作为"声音布景"（Sound Set）
- 《黄金三镖客》的主题（"The Ecstasy of Gold"）成为史上最经典的西部片配乐
- Morricone 的音乐不仅是配乐，也是叙事的一部分——角色间"对峙"场景的节奏完全由音乐驱动

### Tim Burton / Danny Elfman

- 合作定义了"Burtonesque"音乐风格——马戏团式怪诞、哥特式旋律、黑暗童话感
- Elfman 的音乐是 Burton 视觉风格的声学等价——扭曲、夸张、却又莫名地真诚
- 《圣诞夜惊魂》《蝙蝠侠》《剪刀手爱德华》的共同音乐 DNA

### Paul Thomas Anderson / Jonny Greenwood

- Greenwood（Radiohead 吉他手）是当代最激动人心的导演-作曲家合作
- 他的音乐颠覆传统配乐——不依赖旋律驱动的主题，而是基于音色/纹理/不和谐音

  - 《There Will Be Blood》：无调性弦乐——油井的暴力声响
  - 《The Master》：分阶段的、断裂的、几乎"非音乐"的音乐
  - 《Phantom Thread》：仿 1950 年代浪漫配乐——但加入了微妙的失谐感
- 合作方式：Greenwood 和 Anderson 一样极端准备——\*在拍摄前\*写出大量音乐素材

## 音乐剪辑：对点 vs 情绪配合

### 对点（Mickey Mousing / Hit Pointing）

音乐与画面动作精确同步——音乐\*描述\*画面中的物理事件。

- 早期动画片的标配（米老鼠的名字由此而来）
- 动作片和喜剧中依然广泛使用：一拳出去→一声鼓、摔倒→滑音
- 好的对点是不被注意的——观众只感到"动作和音乐配合得很好"

### 情绪配合（Mood Matching / Underscore）

音乐不与画面精确对点，而是以长段落的方式配合场景的\*总体情绪\*。

- 更现代、更微妙的方法——音乐"漂浮"在场景之上而非"钉"在动作上
- 要求导演和剪辑师对"情感的弧线"有共识——音乐不是逐秒配合而是配合一场戏的\*情绪弧度\*
- 经典案例：Thomas Newman 的配乐——音乐似乎有"自己的节奏"，与画面节奏若即若离

### 节奏选择

| 场景特征 | 推荐音乐策略 |
|---------|-------------|
| 动作追逐 | 明确的节奏感（4/4 拍）——对点制造冲击感 |
| 悬疑场景 | 节奏模糊、不规律——让观众不知道"危险什么时候来" |
| 情感高潮 | 长线条旋律——让情绪扩展而不是被打断 |
| 对话场景 | 极轻的垫底/无声——音乐不抢对白的注意力 |
| 蒙太奇 | 音乐决定整段的节奏——剪辑点和音乐节拍一致 |

## 无配乐的导演选择

不使用任何配乐或极少使用配乐是一种极强的电影宣言。

- 《The Birds》（Hitchcock, 1963）：没有任何传统配乐——Hitchcock 的"声音"是电子合成的鸟叫声（当时极其革命性）
- 《No Country for Old Men》（Coen, 2007）：几乎无配乐（只有结尾极短的吉他音乐）——拒绝给观众"情感提示"
- 《1917》（Mendes, 2019）：虽然 Thomas Newman 做了配乐——但导演刻意在大量段落中\*省略音乐\*，让战场环境音成为"音乐"
- 《犬之力》（Campion, 2021）：Jonny Greenwood 的配乐极其克制——长时间的音乐缺席让观众只能面对\*沉默中的人物凝视\*

**无配乐的优势：**

- 声音的真实感更强——环境音、对白和效果声不需要"与音乐竞争"
- 情感更"干"——没有音乐的"软垫"，观众面对更直接的情感体验
- 当音乐终于出现时——观众的耳朵被"唤醒"——音乐的力量被最大化

**无配乐的风险：**

- 观众习惯了电影"总是有音乐"——无配乐可能让人感到"空"或"制作不完整"
- 需要声音设计足够丰富——单纯地"没有音乐"不构成艺术选择，必须要有精心构建的环境声填补听觉空间

## 音乐版权的导演考虑

- **Sync License**（同步许可）：使用已有歌曲需要从词曲版权方获得许可——一个热门歌曲可能花费 5 万到 100 万美元
- **Master Use License**（录音使用许可）：从唱片公司获得对特定录音的许可——可能在 Sync License 之上额外付费
- **Original Score 的版权**：作曲家通常保留配乐的著作权，但电影公司通过 "Work for Hire" 协议获得所有权
- 独立电影和小成本制作的音乐策略：
  - 与独立音乐人合作、使用 CC 许可音乐
  - 请新作曲家（刚毕业的作曲学生可能以低成本做出卓越的配乐）
  - 将音乐预算集中在 3-5 个关键场景而非全片覆盖
  - 参考 [[concepts/低 预算 电影制作]] 中的"限制→风格转化"路径

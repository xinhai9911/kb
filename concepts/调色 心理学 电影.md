# 电影色彩心理学

## 定义

电影色彩心理学研究如何使用颜色的色相、饱和度、明度来影响观众的情绪和叙事理解。色彩是导演和美术指导最强大的潜台词工具之一——观众不一定意识到颜色的存在，但一定会感受到它的效果。

## 基础色彩语义

| 颜色 | 常见情感关联 | 电影应用 |
|------|------------|---------|
| **红色** | 危险、激情、暴力、欲望 | 警告信号、爱情场景、血迹 |
| **蓝色** | 冷、孤独、科技、忧郁 | 夜景、未来世界、疏离状态 |
| **黄色** | 温暖、疯狂、警告、希望 | 回忆场景、疯狂角色、希望象征 |
| **绿色** | 嫉妒、自然、病态、不自然 | 反派标志、超自然光源、自然场景 |
| **紫色** | 神秘、富贵、超自然 | 奇幻场景、贵族角色 |
| **橙色** | 温馨、活力、舒适 | 家庭场景、晨光、怀旧 |
| **白色** | 纯洁、空无、冰冷 | 医疗场景、来世、完美幻想 |
| **黑色** | 死亡、未知、权力 | 反派服装、阴影覆盖、不可知 |

## 色彩作为叙事工具

### 角色关联色（Color Motif / 主题色）
- 特定角色全程绑定一种颜色
- 角色转变时颜色渐变（从冷到暖 = 从封闭到开放）
- 例：《教父》迈克尔的西装从浅色逐渐变为深色

### 场景区分（Color Palette Shift）
- 不同时间线/空间用不同色调区分
- 闪回用暖色/褪色（《美丽心灵的永恒阳光》）
- 记忆 vs 现实的色调对撞

### 情绪过渡（Color Arc）
- 整部电影的颜色弧线：从高饱和到低饱和（或相反）
- 压迫场景：降低饱和度 + 偏向冷色
- 释放场景：提高饱和度 + 偏向暖色

## 调色实战思路

- **Color Grading（调色）** 是后期制作中将色彩方案落实到画面的核心环节
- **Lookup Table（LUT）**：预制的色彩转换表，快速给素材施加统一的颜色风格
- 导演和调色师在后期一起确定每一场景的最终色调

## 著名色彩方案

- 《黑客帝国》：现实世界褪绿，Matrix 内绿色染光
- 《布达佩斯大饭店》：粉彩调色板，不同时代用不同主色调
- 《英雄》：每一叙事段用一种主色（红/蓝/绿/白）
- 《爱乐之城》：高饱和霓虹色，LA 夜景标志性紫-蓝-红

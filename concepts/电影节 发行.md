# 电影节与发行策略

## 概述

对于绝大多数导演，特别是独立导演，电影节是电影从创作走向世界的"第一道门"。但电影节远不止红毯和奖杯——它是一个复杂的商业/社交/艺术网络。理解这个网络的规则，是导演生存技能的一部分。

## 电影节分级体系：A/B/C 类

FIAPF（国际电影制片人协会联合会）将竞赛型电影节分为三类：

### A 类（Competitive Feature Film Festivals）
最高级别，可颁发大奖，必须包含国际竞赛单元。共 15 个：
- 欧洲：戛纳、威尼斯、柏林（"三大"）、莫斯科、卡罗维发利、洛迦诺、圣塞巴斯蒂安、华沙
- 北美：无 A 类（但多伦多、圣丹斯事实上影响力超过部分 A 类）
- 亚洲：上海、东京、塔林黑夜
- 拉美/非洲：马德普拉塔（阿根廷）、开罗

### B 类（Specialised Competitive）
专注特定类型或主题的竞赛电影节：
- 安塔利亚、布加勒斯特、希洪等
- 地位低于 A 类，但在特定类型内可能更有影响力

### C 类（Non-Competitive）
不设竞赛但仍重要的展览平台：多伦多国际电影节（TIFF）是 C 类中最有影响力的

### 导演需要注意的事实
- FIAPF 认证对电影节地位很重要，但不是唯一标准
- **圣丹斯**（无 FIAPF 认证）是独立电影最重要的电影节，影响力超过大部分 A 类
- **多伦多（TIFF）**的观众选择奖通常是奥斯卡的预言家
- **西南偏南（SXSW）**侧重跨界和新兴媒体
- A 类不一定适合你的电影——类型片去戛纳很难，去锡切斯（奇幻电影节）更合适

## 电影节投递策略

### Premiere 策略（首映策略）

首映状态是电影节最看重的资产：

| 等级 | 含义 | 适用电影节 |
|------|------|------------|
| World Premiere | 全球首映 | 三大最高价值 |
| International Premiere | 国际首映（已在本国放过） | 多伦多、洛迦诺 |
| European Premiere | 欧洲首映 | 柏林、威尼斯 |
| National Premiere | 在该国首次放映 | 区域性电影节 |

**核心原则**：World Premiere 只能给一个电影节。一旦在 A 处首映，在 B 处的价值断崖下跌。

### 投递节奏

1. **首映目标**（1 个）：选择最有声望且最匹配影片风格的大型电影节
2. **次选目标**（2-3 个）：如果在首映目标被拒，作为替补
3. **市场目标**（2-3 个）：侧重市场交易而非首映声望
4. **本地目标**（1-2 个）：在母国电影节建立口碑

### 投递费用预算
- 大型电影节早鸟投递费：$50-$150 不等
- 常规截止：$80-$200
- 延迟截止：$100-$300
- 预算建议：$1,000-$3,000 投递 10-15 个电影节
- 费用减免：独立/少数群体/学生通常可申请 fee waiver

## 电影节的真实作用

### 1. 卖片（Sales）
- 电影节是买家（发行商、销售代理）的集中地
- 电影在电影节上的"反响"（掌声长度、媒体评价、获奖）直接影响发行价格
- 销售代理（Sales Agent）往往从电影节首映就开始洽谈

### 2. 人脉（Networking）
- 90% 的有效连接发生在放映后的酒会、早餐、会议室
- 建立长期关系的价值超过单次交易
- 常见连接对象：制片人、发行商、电影节程序员、其他导演

### 3. 奖项（Awards）
- 奖项最大的价值不是奖杯，而是"标签"——获得戛纳金棕榈的电影在发行时关注度完全不同
- 奖项带来媒体的二次曝光（"X 电影节获奖电影"）
- 但注意：奖项 ≠ 发行成功（很多获奖者仍然找不到好发行商）

### 4. 声望积累（Career Building）
- 多次入选同一电影节建立"电影节导演"身份
- 被选入戛纳导演双周或影评人周比一种关注更能建立职业生涯
- 短片在知名电影节的成绩是长片融资的重要凭证

## 现代发行路径

### 传统路径（正在萎缩）
```
电影节 → 发行商签约 → 院线窗口（90天）→ 家庭视频/DVD → 电视 → VOD
```

### 当代路径（多样化）
| 窗口 | 说明 | 代表玩家 |
|------|------|----------|
| **院线（Theatrical）** | 首窗口，但窗口期正在缩短 | AMC、Regal、独立影院 |
| **PVOD（Premium VOD）** | 高价位点播（$15-30/次），可在院线窗口同期或提前 | Apple TV、Amazon Prime |
| **SVOD（Subscription VOD）** | 订阅制流媒体 | Netflix、HBO Max、Disney+ |
| **AVOD（Advertising VOD）** | 广告支撑的免费流媒体 | Tubi、Pluto TV、Freevee |
| **TVOD（Transactional VOD）** | 单次付费租赁或购买 | iTunes、Google Play、Vudu |
| **EST（Electronic Sell-Through）** | 数字购买永久拥有 | iTunes、Amazon |
| **TV** | 有线电视/卫星电视，通常是最后窗口 | HBO、Showtime |

### 关键趋势
- **窗口期瓦解**：疫情加速了"同步发行"（Day-and-Date），院线和流媒体同日上映
- **流媒体收购**：Netflix、Apple、Amazon 在电影节大量收购，出价超过传统发行商
- **自我发行崛起**：导演跳过传统发行商，直接通过 Vimeo OTT、DistroKid 等平台自我发行
- **数据驱动的发行决策**：社交媒体反响、预告片点击量、邮件订阅数成为发行商的决策依据

## 独立电影发行策略

### 方案选择

| 策略 | 适用场景 | 回报潜力 | 控制权 |
|------|----------|----------|--------|
| 传统发行商 | 电影节反响热烈 | 中-高 | 低 |
| 自我发行 | 有现有观众群 | 中 | 高 |
| 混合模式 | 两边都不想放弃 | 中-高 | 中 |
| 流媒体直接出售 | 急需现金流或无发行信心 | 低-中（一次性买断） | 无 |
| 社区驱动发行 | 主题驱动的纪录片/政治电影 | 中（口碑导向） | 高 |

### 自我发行 checklist
1. 建立邮件列表（从拍摄期就开始！）
2. 社交媒体内容日历（幕后花絮、剧照、预告片节奏）
3. 寻找社区合作伙伴（主题相关的 NGO、机构、意见领袖）
4. 确定定价策略（租赁 $3.99-$6.99 / 购买 $9.99-$14.99）
5. 排片策略（Virtual Cinema + PVOD 同步）
6. 参加虚拟 Q&A 和社区放映活动

## 电影节申请材料清单

### 必备材料
- [ ] 完整成片（DCP or 数字文件 .mov/.mp4 H.264）
- [ ] Screener 链接（Vimeo/YouTube 私密链接，带密码）
- [ ] 预告片（1-3 分钟）
- [ ] 剧照 5-10 张（300dpi）
- [ ] 导演照片
- [ ] 演职员表（完整名单）

### 文字材料
- [ ] 导演陈述（Director's Statement）— 为什么要拍这部电影（300-500 字）
- [ ] 剧情简介（Logline 1 句 + Synopsis 100-200 字）
- [ ] 长简介（Synopsis 500-800 字）
- [ ] 导演简历/Bio
- [ ] 制片人简历
- [ ] 项目历史（电影如何被制作出来的）
- [ ] 电影节策略信（为什么选这个电影节）

### 补充材料
- [ ] Press Kit（含 quotes、reviews、previous awards）
- [ ] 剧本（个别电影节需要）
- [ ] 预算与融资证明
- [ ] 版权/音乐版权声明
- [ ] 字幕文件 (.srt 或 .ass)

# 轻量 Agent 框架

相对 [[智能体 框架|LangGraph / CrewAI / AutoGen]] 这些"重编排"框架，下面几个库更轻、更贴近"薄 harness"（见 [[LLM 智能体 测试框架]] C 类）：

| 框架 | 语言 | 特点 | 适用 |
|------|------|------|------|
| **Pydantic AI** | Python | 基于 Pydantic 的类型安全 Agent，结构化输出、依赖注入、多模型（OpenAI/Anthropic/Gemini） | 生产级、强类型后端 |
| **smolagents** | Python | HuggingFace 出品，极简；`CodeAgent` 直接写 Python 行动，依赖极少 | 教学 / 快速原型 |
| **Agno** | Python | 原名 Phidata，多模态、速度快，Agent + Knowledge + Memory 一体 | 多模态 / 知识型 Agent |
| **LlamaIndex** | Python | 数据 / RAG 框架，Agent 是其编排的一环（Query Engine → Agent） | 检索增强型 Agent |

## 共同点

- 都提供 harness 基本盘：运行循环 + 工具 + 上下文 / 记忆 + 可观测（详见 [[LLM 智能体 测试框架]]）。
- 都比"纯 `while` 循环"（D 类）省事，又比"重框架"灵活。

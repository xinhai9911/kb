# ADR、配音与多语言工作流

## ADR（Automated Dialogue Replacement）

ADR 是在后期阶段重新录制演员对白的技术。尽管名称中带"Automated"，实际过程高度人工且需要精细操作。

### 何时需要 ADR

- **现场录音质量差**：底噪过大、风声、飞机声、对白被其他声音掩盖
- **技术问题**：无线麦克风掉频、话筒被遮挡、电平削波
- **表演问题**：导演在剪辑后希望调整对白语气/情绪
- **内容修改**：剧本调整、品牌名替换、台词重写
- **无法避免的杂音**：古装片的硬铠甲摩擦声、动作戏喘息与水声冲突
- **其他演员串词**：多演员现场录音中重叠对白无法分离

### ADR 录音设置

```
录音棚 → 演员 + 耳机 → 投影屏幕或 Cue Monitor → 录音师 → Pro Tools
```

**设备要求**：
- 录音棚：经过声学处理的密闭空间，无混响
- 麦克风：大振膜电容话筒（Neumann U87 / Sennheiser MKH 416），与现场拍摄使用同型号最佳
- 耳机：封闭式，避免录音泄漏
- 监看系统：可循环播放素材的画面，带 2-3 秒前导 Cue

**录音流程**：
1. 音频素材分割为 ADR 段落（每条 10-20 秒为最优）
2. 给演员播放原始对白（Guide Track），作为语气和节奏参考
3. 演员重复台词，录音师录制 3-5 次 Take
4. 每次 Take 后确认同步精度（Lip Sync）
5. 选用最佳 Take，标注备用 Take

### ADR 同步技巧

| 方法 | 原理 | 精度 |
|------|------|------|
| 波形对齐（Visual Sync） | 目视对齐 ADR 波形与参考轨道的波形包络 | ±1 帧 |
| Pocket（微调工具） | Pro Tools 的 VocALign / Synchro Arts Revoice Pro 自动时间伸缩 | 亚帧精 |
| Time Warp（手动伸缩） | 手动拖拽 ADR 轨道的少量时间偏移 | ±1/2 帧 |
| XLI 格式 | Avid 时间码锁定文件，在 NLE 中调整 ADR 位置 | ±1 帧 |

**同步检查方法**：
- **频闪法**：显示 ADR 与参考轨道的相位差，频闪消失表示同步
- **测光法**：嘴巴闭合/张开的帧对应元音开始/结束
- **齿音法**：S/T/P 等爆破音和摩擦音可精确对位

## 配音（Dubbing）工作流

配音是将影视作品的对白完全替换为另一种语言的过程，与 ADR 的核心区别在于**语言变化**而非音质替换。

### 完整工作流

```
翻译 → 台本调整 → 选声 → 录音 → 同步 → 混音 → QC → 交付
```

#### 1. 翻译（Translation）
- 翻译原始语言对白为目标语言
- 需注意口型匹配（Lip Sync）的对白长度和音节数
- 翻译中需标注文化参考、双关语、特殊术语

#### 2. 台本调整（Adaptation）
- 适配师（Adaptor）根据画面中演员的口型运动调整译文
- **开闭原则**：译文在演员嘴唇张开时以开口音起始，闭合时以闭口音结束
- **节奏匹配**：译文长度必须与原始发音长度相近（±2 帧内）
- **情感匹配**：译文语气的强度/温度须匹配表演

#### 3. 选声（Casting）
- 配音演员的声音气质、年龄感、音色需匹配原演员
- 选声测试：配 3-5 句关键对白，与原片对比
- 知名配音演员往往专门对应特定原演员

#### 4. 录音（Recording）
- 与 ADR 录音类似，但流程不同：
  - 通读：先完整通读一遍熟悉情绪
  - 分句录制：逐句/逐短语录制，保证口型精度
  - Group Dubbing：多配音演员同时录制（讨论场景），保持互动感
- 导演在控制室通过对讲系统指导表演

#### 5. 同步（Synchronization）
- 主要工具：VocALign / Revoice Pro / TimeShift
- 细化到音节级的时间对齐
- 特殊技巧：对某些语言（如日语 → 英语），音节数差异大时需要大量手动调整

#### 6. 混音（Mixing）
- 配音音轨需要与环境音/音乐/音效混合（M&E Tracks）
- 匹配原始混音的 EQ / 混响 / 空间感
- 响度标准化至目标标准

### ADR 与配音的区别

| 方面 | ADR | 配音 |
|------|-----|------|
| 目的 | 修复原始对白音质 | 替换为另一种语言 |
| 演员 | 原始演员 | 专业配音演员 |
| 语言 | 同语言 | 不同语言 |
| 同步要求 | 精确匹配原始表演 | 匹配口型但节奏可调 |
| 责任方 | 声音后期部门 | 配音导演 + 本地化公司 |
| 预算 | 包含在后期预算内 | 独立本地化预算 |

## 口型同步高级技巧

### Pocket（微调法）
- VocALign：行业标准的自动对齐插件
- 分析原始 Guide 与新的 ADR/配音的波形包络
- 自动计算时间伸缩曲线
- Revoice Pro：更高级的版本，保留音色特征

### Time Warp（手动伸缩）
- Pro Tools 的 Elastic Audio / Time Shift
- 手动绘制时间拉伸曲线
- 适合需要保留特定语音细节的精细调整

### XLI 格式（时间码交换）
- Avid 与 Pro Tools 之间的 ADR 交换格式
- 包含原始 Timecode + ADR Text + 时间偏移量
- 回套时自动对齐到时间线

## 多语言版本管理

### 不同语言音轨的同步与嵌套

多语言版本管理的核心问题：**画面锁定后，如何在单个节目中管理 10-30 种语言的配音音轨？**

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| 单一母版 + 音频替换 | 画面母版不变，各语言独立音频文件 | 流媒体/Netflix/DVD |
| 多语言时间线 | 每语言一个时间线序列 | 传统广播交易 |
| IMF (Interoperable Master Format) | 标准化的版本打包框架，支持多语言音轨 + 分轨 | 现代好莱坞标准 |

**IMF 多语言流程**：
- 画面母版：单一 APP（Audio-Picture Package）
- 各语言音轨：独立的 Audio Track Files 含 M&E 与对白
- 合成时 APP + Audio Only Track 按需组合

## 配音演员导演方法

| 导演方法 | 描述 | 适用场景 |
|---------|------|---------|
| 情绪引导法 | 描述场景情境/演员动机，不做具体指示 | 资深配音演员 |
| 示范法 | 配音导演先示范一遍语速/语气/音高 | 新手或复杂场景 |
| 分析法 | 逐句分析台词的情感诉求和目标 | 文学/艺术电影 |
| 口型精确法 | 严格要求口型同步优先于表演情绪 | 动画片/游戏 |

### 已知配音导演技法
- **Walla 技巧**：在群杂场景中让配音演员即兴发出无意义对话填充背景
- **Loop Group**：多名配音演员同时录制背景对白
- **Tonal Matching**：录音前播放原片，让配音演员在前 30 秒内匹配基调

## 字幕 vs 配音的选择决策

| 因素 | 倾向字幕 | 倾向配音 |
|------|---------|---------|
| 成本 | 低（$200-800/小时成品） | 高（$3000-20000/小时成品） |
| 文化距离 | 观众愿意看原文 | 观众排斥外文对话 |
| 儿童/非阅读人群 | 不适用 | 配音优先 |
| 原声保留 | 保留原演员表演 | 丢失原表演 |
| 市场规模 | 小国家/小众语言 | 大市场（德语/法语/日语/西语/中文） |
| 内容类型 | 纪录片/艺术片/成人内容 | 动画/儿童/商业大片 |
| 制作时间 | 1-2 周 | 4-8 周 |

**全球趋势**：
- 东欧/德国/法国/西班牙/意大利/日本/中国：配音为主流
- 北欧/荷兰/东欧年轻一代：逐渐从配音转向字幕
- 流媒体（Netflix）策略：配音 + 字幕同时提供，让用户选择

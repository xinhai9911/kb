# 片场导演实时决策

## 概述

片场是导演真正"赚工资"的地方。前期所有准备工作——剧本分析、分镜、选角——最终都在片场被转化为可拍摄的镜头。片场环境变化极快（天气、光线、演员状态、设备故障），导演必须训练出在瞬间决策的能力。

## 片场的一天

### 典型拍摄日流程

| 时间 | 活动 | 参与人 |
|------|------|--------|
| 06:00-07:00 | 导演与各部门到片场 | 全组 |
| 07:00-07:30 | 走戏排练（Blocking Rehearsal） | 导演、演员、DP、剧本监督 |
| 07:30-08:30 | 布光与摄影机定位 | DP、灯光组、摄影组 |
| 08:30-09:00 | 演员化妆/服装确认、最终排练 | 导演、演员、服装、化妆 |
| 09:00-09:15 | 拍第一条（First Take） | 全组 |
| 09:15-12:00 | 拍摄第一场（多角度、多 take） | 全组 |
| 12:00-13:00 | 午餐 + 设备转场 | 全组 |
| 13:00-17:00 | 拍摄第二场 | 全组 |
| 17:00-18:00 | 日落黄金小时拍摄 | 全组紧赶 |
| 18:00-19:00 | 检查回放（Dailies），确认明日计划 | 导演、DP、第一副导 |
| 19:00- | 导演与编剧/后期讨论，或休息 | 导演 |

### 走戏排练（Blocking）

导演与演员在实景中走位，确定：
- 演员的移动路径和时机
- 摄影机的最佳摆放位置
- 与 DP 讨论：摇臂、轨道还是手持？
- 与灯光沟通：哪些区域需要额外补光

## 实时决策框架

### 三角约束

每个片场决策都在三个维度中权衡：

```
        质量
        /\
       /  \
      /    \
     /______\
   时间     预算
```

- **有时间，有预算 → 追求最高质量**
- **没时间，有预算 → 增加人手/设备**
- **没时间，没预算 → 必须在质量上妥协**——关键是选择在什么上妥协
- **有时间，没预算 → 巧思替代方案**

### 决策速查

| 场景 | 快速决策原则 |
|------|-------------|
| 演员今天状态不对 | 改拍不需要这个演员的镜头；或改为特写掩盖状态 |
| 光线变化 | DP 应提前准备 A/B 方案；转到室内/搭景拍摄 |
| 设备故障 | 第一副导应预设备用方案；组合不同镜头完成场景 |
| 超时 | 导演和第一副导决定"砍哪个镜头"——通常砍最不重要的覆盖镜头 |
| 演员意见分歧 | 先拍导演的版本，有时间再拍演员的版本 |

## 面对意外的应对

### 天气

- 提前看天气预报是导演的功课
- 雨天备用方案：改为拍室内、或是利用雨天拍特定情绪戏
- 云的密度变化会影响光线连续性——DP 需要用大柔光布或人工光源补偿

### 演员状态

- 演员可能疲劳、情绪波动、生病
- 导演应识别演员的"最佳时段"——有些演员早上好，有些需要时间进入状态
- 何时喊停、何时继续——经验判断，没有公式

### 不可控因素（航班、许可、人群）

- 提前准备"B 计划清单"，每天早晨与第一副导确认
- 第一副导（1st AD）是导演的执行官——导演的每个决定通过 1st AD 转化为全组指令

## 片场沟通

### 导演给指令的原则

1. **公开表扬，私下批评**：当着全组表扬演员；批评时到一边说
2. **先说方向，再说调整**：先告诉全组这一条要达到什么效果
3. **明确信号**：确定全组通用的术语（"最后一次"、"再来一条安全版"、"检查声音"）
4. **控制信息流**：导演只和关键部门沟通（DP、1st AD、收音），避免片场多头指挥

### 导演周围的沉默原则

- 导演的监视器周围通常保持安静
- 导演专注看表演，不参与技术细节讨论（1st AD 和 DP 处理技术问题）
- 如果导演需要安静思考，提前告知团队

## 监视器前的观察方法

### 导演在看什么？

1. **表演**：演员的情绪是否真实？节拍是否对？
2. **视线匹配**：视线方向是否与对手演员匹配？
3. **画框内问题**：穿帮的道具、不该出现的人、阴影不合理
4. **连续性**：动作、道具位置、服装状态与上一个镜头是否一致
5. **节奏**：这场戏的节奏是否感觉对？

### 回放检查

- 每拍完一个 setup，导演和 DP 一起看回放
- 不要只看技术问题——看表演是否"活"了
- 如果感觉不对，可能是：演员不对 / 摄影机位置不对 / 节奏不对

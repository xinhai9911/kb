# 中间编解码器（Mezzanine Codec）

## 概述

Mezzanine Codec（中间编解码器，又称 Intermediate / "点心"格式）是后期制作管线中的**编辑主力格式**。与 Camera Raw（过大）和 Delivery Codec（过损）不同，Mezzanine 在解码性能、画质保真、文件大小之间取得最佳平衡。

## Mezzanine 的核心要求

- **帧内编码（Intra-frame）**：每一帧独立压缩，便于逐帧定位和实时播放
- **低压缩比**：视觉无损或接近无损
- **宽色深支持**：10-bit+、4:2:2 / 4:4:4
- **硬件加速友好**：GPU / M-chip 原生解码
- **多平台兼容**：至少主流 NLE 均支持

## 主要 Mezzanine 格式

### Apple ProRes 家族

| 格式 | 比特率 (1080p30) | 色深 | 色度 | 典型用途 |
|------|-----------------|------|------|---------|
| ProRes Proxy | ~45 Mbps | 8/10 | 4:2:0 | 离线代理 |
| ProRes LT | ~100 Mbps | 8/10 | 4:2:2 | 轻量后期 |
| ProRes 422 | ~150 Mbps | 10-bit | 4:2:2 | 通用剪辑 |
| ProRes 422 HQ | ~220 Mbps | 10-bit | 4:2:2 | 高质量后期 |
| ProRes 4444 | ~330 Mbps | 12-bit | 4:4:4 | VFX / Alpha |
| ProRes 4444 XQ | ~500 Mbps | 12-bit | 4:4:4 | 母版存档 |

### Avid DNxHD / DNxHR

- **DNxHD**：固定分辨率（720p/1080p），码率数字即近似 Mbps
  - DNxHD 36/45/145/220/444
- **DNxHR**：可变分辨率（HD~8K）
  - DNxHR LB（Low Bandwidth）/ LQ / SQ / HQ / 444
- **DNxHR HQ 4K** ≈ 600 Mbps
- **Avid 生态原生格式**，Media Composer 最佳性能

### Other

- **Cineform**：GoPro 开发的中间格式，支持 12-bit、Alpha、元数据嵌入
- **DNxUncompressed**：Avid 的无损模式

## 选择策略

| 场景 | 推荐格式 |
|------|---------|
| Mac / FCP 生态 | ProRes 422 HQ |
| Avid 合作流程 | DNxHD 145 / DNxHR HQ |
| 跨平台通用 | ProRes 422（Windows + QuickTime） |
| VFX / 绿幕 | ProRes 4444 / DNxHR 444 |
| 代理剪辑 | ProRes Proxy / DNxHR LB |
| HDR 调色母版 | ProRes 4444 XQ |

## 与 Delivery Codec 的区别

- **Mezzanine**：帧内、大文件、低压缩、编辑友好
- **Delivery**：帧间、小文件、高压缩、分发友好
- 典型链路：Camera Raw **→** Mezzanine（编辑） **→** H.264/AV1（交付）

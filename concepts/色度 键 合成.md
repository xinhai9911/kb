# 绿幕/抠像与合成

## 概述

色度抠像（Chroma Key）是一种通过颜色信息将前景从背景中分离的技术，通常称为"绿幕"或"蓝幕"。这项技术是现代视觉特效和虚拟制作的基础——将演员在纯色背景前的表演替换为数字背景或虚拟场景。

## 绿幕 vs 蓝幕

### 选择原则

| 因素 | 绿色 | 蓝色 | 原因 |
|-----|------|------|------|
| 传感器敏感度 | 更亮（需要更少光照） | 较暗 | 数字传感器对绿色通道最敏感，绿色更容易抠干净 |
| 肤色 | 优于蓝色 | 不如绿色 | 人类肤色不含绿色，而蓝色在服装和眼睛中更常见 |
| 溢出反射 | 绿色溢出到前景明显 | 蓝色溢出更柔和 | 但绿幕溢出在后期更难去除 |
| 服装/道具 | 避免绿色元素 | 避免蓝色元素 | 主体不能穿与背景同色的衣物 |
| 户外拍摄 | 不推荐于草地场景 | 更适合 | 户外天空和植物含大量绿色 |
| 电影传统 | 现代数字电影首选 | 胶片时代更常见 | 胶片绿色通道颗粒更粗，蓝色更干净 |

### 经验法则

- **首选绿色**除非：主体穿绿色服装（如绿幕中的超人）或场景包含大量绿色元素（如森林）
- **使用蓝色**当：拍摄夜晚场景（蓝色溢出更自然）、主体穿绿色、或胶片拍摄传统

## 拍摄注意事项

### 光照

- 绿色/蓝色背景需**均匀照亮**——亮度变化不超过 1/3 档
- 前景主体与背景分离——主体和背景距离至少 1.5 米，避免背景反射光"溢出"到主体边缘
- **背光（Rim Light / Kicker）**：在主体边缘打背光，帮助区分主体和背景的边界
- 避免背景上出现阴影——使用多角度光源消除

### 溢出 (Spill)

绿色或蓝色的反射光染到主体边缘或半透明区域（如头发），称为 Spill。

**解决方案**：
- 增加主体与背景距离
- 使用背光分离主体边缘
- 后期使用 Spill Suppression 工具
- 避免紧贴着绿幕放置主体

### 其他拍摄要素

- 使用大光圈（低 f-stop）最小化背景细节——减少背景纹理对抠像的干扰
- 运动模糊——快速运动的物体需与背景的运动模糊匹配，否则抠像边缘感明显
- 头发和烟雾是最难处理的抠像对象——需要精确的边缘细化

## 各软件抠像工具

### [[entities/DaVinci Resolve|DaVinci Resolve]]

| 工具 | 用途 | 位置 |
|-----|------|------|
| **3D Keyer** | 主抠像工具，基于 HSL 三维色彩空间 | 调色页面 |
| **Delta Keyer** | 高级抠像，支持边缘细化和 Spill 处理 | Fusion 页面 |
| **Lum Keyer** | 亮度键（基于亮度而非色度） | Fusion 页面 |
| **Ultra Keyer** | 简易抠像，快速上手 | 剪辑页面的 Inspector |

**推荐流程**：使用 Fusion 页面的 Delta Keyer → 调整 Matte 参数 → 添加 Edge Extend → Spill Suppression → 合成背景

### [[entities/Adobe Premiere Pro|Adobe Premiere Pro]] + After Effects

| 工具 | 平台 | 特点 |
|-----|------|------|
| **Ultra Key** | Premiere | 内置在 Premiere，简易抠像，适合快速作业 |
| **Keylight (1.2)** | After Effects | 行业标准抠像插件（原 The Foundry 产品），精细控制 |
| **AES Ultra Key** | After Effects | 改进版本，处理半透明区域更好 |
| **ROTO Brush** | After Effects | AI 辅助逐帧抠像，不依赖色度 |

**推荐流程**：After Effects Keylight → Screen Colour 选色 → Screen Gain/Balance 调阈值 → Clip Black/White 调 Matte → Alpha/Pre-multiplication 处理边缘

### [[entities/Apple Final 剪辑 Pro|Final Cut Pro]]

| 工具 | 特点 |
|-----|------|
| **Keyer** | 内置在 Color Inspector，一键抠像 + 自动 Spill Suppression |
| **Mask + Keyer 组合** | 手动遮罩 + 抠像，处理复杂背景 |

**推荐流程**：选择片段 → 打开 Color Inspector → Keyer → Sample Color（取色） → Strength 调节 → Edges 边缘处理

### Avid Media Composer

| 工具 | 特点 |
|-----|------|
| **AniMatte** | 基于 Avid FX，较复杂 |
| **SpectraMatte** | 改进的色度抠像引擎 |

Avid 的抠像能力相比 Resolve / AE 较弱，通常在 Avid 完成离线剪辑后将 VFX 镜头送往达芬奇或 AE 处理。

## 基础合成与跟踪

### 合成基础

合成（Compositing）是将多个视觉元素（前景、背景、特效层）融合为一帧的技术。

**关键概念**：
- **Alpha Channel**：存储透明度信息的通道 —— 白 = 不透明，黑 = 透明
- **Premultiplied vs Straight Alpha**：预乘和非预乘 —— 决定软件如何处理边缘颜色
- **Layer / Node**：基于图层（Photoshop 模式）或基于节点（Fusion / Nuke 模式）
- **Blend Mode**：叠加混合模式，如 Screen、Multiply、Overlay

### 跟踪基础

跟踪（Tracking）是通过分析画面像素运动来获取摄像机或物体运动数据的技术。

| 跟踪类型 | 用途 | 工具示例 |
|---------|------|---------|
| **点跟踪 (Point Track)** | 单点位置跟踪，用于替换屏幕内容等 | Fusion Tracker, AE Point Track |
| **平面跟踪 (Planar Track)** | 跟踪平面区域，用于屏幕替换、文字贴图 | Mocha, Fusion Planar Tracker |
| **摄像机反求 (Camera Solve)** | 从 2D 画面反算 3D 摄像机运动 | Resolve Camera Tracker, Nuke CameraTracker |
| **物体跟踪 (Object Track)** | 随物体运动的跟踪标记 | Fusion Object Tracker |

**典型应用**：
- 替换手机/电脑屏幕内容 → 点跟踪或平面跟踪
- 演员脸上添加特效化妆 → 平面跟踪
- 3D 场景合入实拍画面 → 摄像机反求

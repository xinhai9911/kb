# 动画导演方法

## 动画导演的核心差异

动画导演与[[concepts/film-production-workflow|真人电影导演]]的工作性质有根本差异。动画导演的"片场"存在于分镜板、计算机屏幕和剪辑时间线上，而不是实体拍摄现场。动画导演不"捕捉"表演，而是"构建"表演。

核心差异：

- **拍摄没有"现场"**：没有演员、摄影机、布景实体存在——一切都是被建造的
- **反馈延迟极长**：从给出指示到看到结果（动画师画完一卡）可能需要数周
- **总控能力更大**：每一帧都在导演控制之中——没有不可控的天气、演员状态、光线变化
- **更依赖前期**：动画的最终质量 80% 在分镜和 Layout 阶段决定
- **成本极高**：每一秒修改都意味着大量动画帧数重做，预决策压力巨大

## 三种动画形式的导演差异

### 2D 传统动画（手绘）

代表：宫崎骏（[[entities/miyazaki-hayao]]）、迪士尼黄金年代

- **导演从分镜开始画**：宫崎骏的方式——没有完整的剧本，从分镜画起
- **原画师(Key Animator)是核心合作者**：导演需要看懂原画草稿，判断动态是否准确
- **律表(Timing Sheet / Exposure Sheet)管理**：导演或演出(Animation Director)填写律表，控制每一帧的时长和摄影表
- **分层摄影(Multiplane Camera)**：传统 2D 动画的深度感通过分层实现
- **修型(Animation Director)**：日本动画体系中的"作画监督"负责统一角色的脸型/比例

### 3D CG 动画

代表：Pixar、DreamWorks、迪士尼 3D

- **导演与 CG 主管(CG Supervisor)**密切合作：CG 主管解决技术可行性问题
- **Layout（虚拟摄影）**：预告片阶段——用粗模建场景、定镜头、走戏，类似真人电影的 Blocking
- **角色绑定(Rigging)的约束**：角色的活动范围由绑定决定，导演需要理解绑定限制
- **渲染预算**：每一帧渲染需要时间，导演需要管理渲染资源分配
- **灯光(Lighting)在 final 阶段完成**：不像真人电影灯光在现场完成，CG 灯光在动画绑定之后
- **Blendshape / 面部控制系统**：3D 角色的面部表情由 Blendshape 系统控制，导演与面部动画师配合

### 定格动画(Stop-Motion)

代表：Laika Studios、Nick Park（阿德曼动画）

- **一切物理存在**：需要真实的木偶、布景、灯光——定格动画是"物理世界的动画"
- **拍摄极慢**：一整天可能只拍 2-3 秒镜头（24fps，即 48-72 张照片）
- **木偶制作周期极长**：一个主角色木偶可能需要数月制作
- **现场灯光不可调**：在长达数月的拍摄周期中，灯光必须维持绝对一致
- **Animator（动画师）即"演员"**：逐帧调整木偶姿态，导演通过监视器审阅每一帧
- **CG 辅助**：现代定格动画大量使用 CG 做面部替换、擦除支架、扩展背景

## 分镜（Storyboard）在动画中的核心地位

在[[concepts/on-set-directing|真人电影]]中，分镜是重要但不绝对的工具。在动画中，**分镜就是电影的全部**。

- **动画分镜包含一切**：角色走位、镜头运动、剪辑点、表情变化——甚至声音和配乐的时间
- **Animatic（动态分镜）**：将分镜配上临时对白和音效，制成粗略的"动画版"。Animatic 是导演最重要的决策工具
- **Animatic 会反复修改**，直到节奏和叙事完全正确——然后才进入做画/建模阶段
- **迪士尼模式**：从故事板开始，通过"故事板艺术家(Storyboard Artist)"分组竞争，最优秀的方案被采用
- **日本 TV 动画的"分镜"(絵コンテ)**：由"演出"（导演）或分镜师绘制，比西方分镜更详细，包含律表信息

## 配音指导

动画配音的特殊性在于**录音通常先于动画制作**。

- **Pre-Lay（预录音）**：动画师根据配音的波形和节奏做口型同步(Lip Sync)
- **配音导演的角色**：动画导演通常亲自指导配音，或委派专门的配音导演(Voice Director)
- **隔离录音**：动画配音演员通常独自分录（不像真人电影可以同场对戏），需要导演帮助演员建立对话感
- **表现代替外貌**：动画角色的年龄、种族、体型完全由声音决定——配音选角是关键
- **ADR（后期补录）**空间比真人电影小得多：因为口型已锁定在动画中

## 视觉开发（Visual Development）

动画电影的视觉开发是漫长且专业化的过程：

- **角色设计(Character Design)**：外观、姿态库、情绪表、比例图、发型/服装演变
- **场景设计(Environment Design)**：色彩脚本(Color Script)、光照条件、材质/纹理参考
- **色彩脚本(Color Script)**：全片色调演变地图——每场戏的调色方案，用于保证情绪的连续性
- **Prop Design（道具设计）**：每个进入画面的道具都需要专门设计
- **视觉开发艺术家(Vis Dev Artist)**：专门负责探索美学方向——在分镜前就已开始

知名视觉开发：Pixar 的 Ralph Eggleston、迪士尼的 Mary Blair、宫崎骏的男鹿和雄和武重洋二。

## 知名动画导演的创作方法

### 宫崎骏（[[entities/miyazaki-hayao]]）

- **无剧本，只画分镜**：据铃木敏夫所述，宫崎骏拍电影"没有剧本"，只有分镜板
- **手工至上**：坚持手绘、拒绝 CG（但《起风了》开始适度使用）
- **飞行母题**：几乎所有作品中出现飞行元素——飞行的物理快感是其电影魅力的核心
- **女性主角传统**：主动、勇敢、独立的少女主角是宫崎骏的标志

### Brad Bird（《超人总动员》《料理鼠王》《钢铁巨人》）

- **"角色动画的核心是行为可信"**：技术服务于表演，不炫技
- **拥抱限制**：在有限的 CG 技术条件下寻找风格性解决
- **跨类型能力**：从超级英雄到美食到科幻，不自我重复

### 庵野秀明（《新世纪福音战士》《新·哥斯拉》《新·假面骑士》）

- **从动画到真人到特摄的跨界**：日本当代最重要的影像作者之一
- **"表现主义写实"**：将内心状态外化为视觉设计（EVA 机体的"生物感"）
- **分镜即一切**：庵野的分镜以极度详细著称，几乎就是漫画版全片
- **体制批判**：EVA 表面的机器人动画下是对动画工业的自我反思

### 汤浅政明（《乒乓》《兽爪》《春宵苦短，少女前进吧！》）

- **变形动画的自由**：无视透视和比例规则，画面随情感自由变形
- **视觉想象力爆炸**：每一帧都充满信息，非传统叙事
- **表演在线上**：线条本身在表演——汤浅的线条充满生命力

## 动画导演的视觉节奏控制

- **Spacing（间距）**：帧之间的物体移动距离——决定运动的感觉（快/慢/弹性/重量）
- **Timing（时间）**：动作持续帧数——1 帧 vs 8 帧传达完全不同的情绪
- **Easing（缓动）**：加速和减速——动画的"灵魂"在于缓动的设计
- **Held Frames（停顿帧）**：关键瞬间的停顿创造戏剧效果
- **日本 TV 动画的"静止帧(静止画/止め絵)"策略**：在有限预算下用精心设计的一帧保持画面冲击力

## 动画导演与制作流程

动画导演围绕制作管线(Production Pipeline)而非片场工作：

1. **脚本/概念阶段** → 确定主题、基调、世界观
2. **视觉开发** → 角色/场景/色彩设计
3. **分镜 + Animatic** → 核心决策阶段
4. **Layout（3D 或 2D 粗排）** → 确定镜头构图和运镜
5. **动画制作** → 原画/建模/绑定/动画——最长的阶段
6. **灯光 + 渲染** → 最终视觉呈现
7. **合成 + 输出** → 与真人电影类似的后期流程

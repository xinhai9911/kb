# 低成本电影策略

## 定义

低成本电影不是"穷电影"——它是"在资源明确受限的情况下，每一分钱都有的放矢"的电影。几乎所有重要的导演都是从低成本起步的，低预算不是缺点而是风格的催化剂。

## 资源受限下的决策框架

### 预算三维度取舍

导演在低成本制作中不断做三角取舍：**时间 × 金钱 × 质量**。三者的关系是：

- 你**有钱**但是**没时间** → 雇更多人/租更好的设备 → 但场景需要更多天数
- 你**有时间**但是**没钱** → 用时间换（延展 prep、更多排练、后期精修）→ 但演员/crew 的档期会被拖累
- 你**有钱又有时间**但**资源总量少** → 在某个维度上"集中优势"（一个好的布景 + 好演员 + 简单的工作流程）

### 决策优先级

在每一场戏的筹备中，按优先级顺序问：

1. **剧本**：这一场戏真的需要吗？
2. **表演**：最好的演员是否在你愿意投入预算的地方？
3. **声音**：这个是"可以听到"还是"必须听清楚"？
4. **灯光**：一场戏只需要一个主光源是否能达成效果？
5. **摄影机**：当你把预算花在上面的四项之后，还剩多少给摄影机？
6. **特效/服装/道具**：排在最后，除非它们是叙事核心

## 用限制创造风格

### 限制即标识

电影史上大量标志性风格来自预算限制：

- [[entities/alfred hitchcock]]《夺魂索》用"一镜到底"隐藏剪辑，实际原因是想尝试单一场景挑战
- [[entities/stanley kubrick]]《巴里·林登》在无电力的城堡里只用了自然光 + 蜡烛光——因为当时没有便携灯光设备
- 《女巫布莱尔》用手持摄影让观众"以为是真实记录"——好处是好拍，恰好成为风格
- Sean Baker《橘色》用 iPhone 拍摄——完全因为预算，但恰好贴合主题

### 限制 → 风格的转化路径

| 限制 | 风格转化 |
|------|----------|
| 只能拍白天外景 | 明亮、阳光高反差风格 |
| 只有一支镜头 | 统一视觉语言，内部约束产生一致性 |
| 没有专用灯光 | 用可用光（窗户/路灯/霓虹灯）——制造自然主义 |
| 只有 2 个演员 | 亲密、叙事"室内剧" |
| 单一场地 | 让场地成为角色（《大饭店》《如月疑云》） |

## 写你能拍的，拍你写得起的

### 剧本阶段的自约束

- **写 5 个场景以内**：每多一个场景 = 多三分之一天拍摄 = 多一天费用
- **写日戏多于夜戏**：夜戏需要灯光，灯光需要电力，电力需要人
- **写 2-3 个角色**：每多一个主要角色 = 多一个选角 + 档期协调
- **写可用场地**：你或朋友家 / 附近公园 / 免费公共空间
- **写不需要特效的戏**：特效后期很贵

### 拍摄阶段的生存策略

**Crew 小型化**：3-5 人核心团队（导演 + 摄影 + 录音 + 灯光 + 制片）比 20 人队伍更灵活

**Blocking 优先于 Gear**：先在场地走满演员走位（Blocking），再决定机器放哪里。低成本电影的常见错误是"先架机器再排戏"

**"在镜头中"而非"在后期中"**：一切能在拍摄时做好的事，不要留给后期。实拍效果 > 后期特效

**相邻场次一起拍**：按场地/光位重新排拍摄计划，而非按剧本顺序——极端省钱

## 利用可用光、自然场景

### 可用光（Available Light）策略

- **窗口光**：最便宜的主光源——用白布/硫酸纸柔化
- **反光板**：30 元的 5 合 1 反光板比 3000 元的补光灯更常用
- **方向的选择**：在可用光环境下，最有效的控制是"把演员朝哪个方向放"——调整走位就是调整光线
- **混合光有意图**：白炽灯暖色 + 窗外冷色可以制造 Day-for-Night 倒替

### 自然场景（Location Scouting 核心原则）

- 选一个"视觉丰富"的场地——自带美术设计，不需额外装饰
- **场地三个条件**：1. 免费/极低价 2. 有电源或安静到可用电池 3. 有自然光的路景

## 小团队沟通

### 扁平化决策

5 人团队不需要"分级沟通"——导演直接和每个人对话。但核心原则：

- **拍摄前**：一次性讲全所有需求，别拍一半追加要求
- **拍摄中**：每拍完一个紧有用的镜头，导演确认"这条叙事上成立吗"再转到下一设置
- **拍摄后**：当日小结（3 分钟）——明天每个人的集合时间、场地、什么设备

### 士气管理

低成本电影的拍摄强度大、时间长。保持士气：

- 保证吃饭时间和质量
- 透明沟通预算限制——不让团队意外发现"我们没钱了"
- 每个拍摄日结束时庆祝"我们已经完成了！"

# 项目质量管理

## 概述

质量管理不是最终检验，而是**内建质量（Build Quality In）**。软件项目的质量管理包括过程质量与产品质量两个维度。

## PMBOK 质量管理过程

1. **规划质量管理** — 制定质量指标、质量检查表、质量成本（CoQ）
2. **管理质量（QA）** — 审计过程是否遵循标准，过程改进
3. **控制质量（QC）** — 检查可交付成果是否满足质量指标

## 质量成本（CoQ）

| 类别 | 示例 | 性质 |
|------|------|------|
| 预防成本 | 培训、规范、评审、TDD | 主动投入 |
| 评估成本 | 测试、代码审查、检查 | 检测投入 |
| 内部失败成本 | Bug 修复、返工 | 交付前发现 |
| 外部失败成本 | 线上事故、客户投诉 | 交付后才发现 |

## 软件质量管理实践

- **代码评审（Code Review）** — 同行检查，及早发现缺陷
- **TDD（测试驱动开发）** — 先写测试再写实现
- **CI/CD** — 持续集成 + 自动化测试
- **CMMI** — 能力成熟度模型集成（1–5 级）

## CMMI 成熟度级别

| 级别 | 特征 |
|------|------|
| 1. 初始级 | 过程不可预测，依赖英雄 |
| 2. 已管理级 | 项目级有过程管理 |
| 3. 已定义级 | 组织级标准化过程 |
| 4. 量化管理级 | 统计过程控制 |
| 5. 优化级 | 持续改进 |

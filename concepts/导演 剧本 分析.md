# 导演的剧本工作

## 定义

剧本分析（Script Analysis）是导演将文字转化为影像的第一次翻译——导演不是在被动"理解"剧本，而是在积极"发现"每种拍法的可能性。

## 剧本分析方法

### 导演的阅读层次

| 阅读遍数 | 关注点 | 工具 |
|----------|--------|------|
| 第 1 遍（裸读） | 直觉反应——"我感受到什么？" | 完全不分析，只记情绪笔记 |
| 第 2 遍（结构读） | 故事骨架——三幕/激励事件/中点/高潮 | 节拍表（Beat Sheet） |
| 第 3 遍（场景分解） | 每个场景的信息/情绪/角色目标 | 场景分解表 |
| 第 4 遍（视觉读） | 每个场景的视觉可能性 | 分镜/情绪板/参考片 |
| 第 5 遍（团队读） | 从执行角度评估难度/预算 | 拍摄计划草案 |

### 第一遍裸读的原则

- 不划线、不写笔记——只感受
- 读完问：*这个剧本想让我感受到什么？它在哪一刻真正抓住了我？在哪一刻我失去了兴趣？*
- 这是导演最接近"观众"的阅读——这是未来观众的反应预演

## 分解场景

### 场景分析框架

对每个场景问以下 6 个问题：

1. **叙事功能**：这个场景在故事中做了什么？（建立角色？推进情节？揭示信息？）
2. **情绪目标**：观众从这一场结束时应感受到什么？
3. **角色目标**：每个角色在场景中想要什么？谁赢谁输？
4. **核心冲突**：这场戏冲突的本质是什么？（意志冲突/信息冲突/情绪冲突）
5. **信息增量**：观众在这一场结束前知道了什么之前不知道的？
6. **视觉可能**：有什么方式是"仅通过画面"可以传达以上所有信息？

### 情绪目标 → 视觉策略

关键一步是把"情绪目标"翻译为具体的视觉策略：

| 情绪目标 | 视觉策略示例 |
|----------|-------------|
| 观众感到不安 | 荷兰角、蓝绿色调、慢推轨、背景杂音 |
| 观众感到亲近 | 过肩镜头、暖色、浅景深、同期环境声 |
| 观众感到渺小 | 高角度、广角、大空间、深焦 |
| 观众感到压迫 | 低角度、近景、摇晃、低光、空间压缩 |
| 观众感到困惑 | 跳切、碎片化剪辑、越轴、信息缺失 |
| 观众感到期待 | 延长时间（慢镜/长镜头）、声音渐强、POV 推轨 |

### 场景节拍表（Scene Beat Sheet）

一场戏通常有 3-7 个 beats（节拍），每个节拍是情绪/权力的微小转移。

| Beat # | 内容 | 角色 A 目标 | 角色 B 目标 | 情绪变化 |
|--------|------|------------|------------|----------|
| 1 | A 进入房间 | 获取信息 | 隐藏信息 | 悬疑建立 |
| 2 | 对话试探 | 试探 | 防御 | 紧张上升 |
| 3 | B 发现 A 的真实意图 | 说服 | 愤怒 | 冲突爆发 |
| ... | ... | ... | ... | ... |

### 冲突的三种层次

1. **表面冲突**：角色之间的直接对抗——对话中显示
2. **深层冲突**：角色价值体系/世界观的碰撞——潜文本中显示
3. **结构冲突**：角色命运与故事世界的对抗——全剧中显示

导演必须知道每个场景中三层冲突分别是什么，即使最终呈现只能让观众感受到其中两层。

## 修改剧本的原则

### 导演对剧本的三次介入

**第一次：分析性介入**

在信任作者的前提下，理解作者的意图。先问"这个剧本想成为什么？"再问"我们如何帮它更好地成为那个东西？"

**第二次：执行性介入**

用场景分析框架判断哪些场景在拍摄时可能出问题：

- **"讲太多"的场景**：用对话传递信息 → 看看能否改成视觉传递
- **"情绪盲点"场景**：导演无法理解这个场景的情绪目标 → 需要重写或重新定义
- **"功能重复"场景**：两个场景做同样的事 → 合并或删除一个
- **"执行难度 > 叙事回报"场景**：一个极复杂的场景但只提供少量信息 → 简化

**第三次：预算/资源介入**

- 把场景按"难度"标色（绿/黄/红灯）
- 红色场景（高风险）在剧本中是否可以通过修改降低难度？
- 哪些场景可以"在别的场地/用别的方式"拍而叙事效果不变？

### 修改尺度

| 修改尺度 | 适用范围 | 需要问的问题 |
|----------|----------|-------------|
| 微调 (Line Adjustment) | 单句对白/动作描述 | 这句是否可以用视觉替换？ |
| 场景调整 (Scene Tuning) | 缩短/重组场景内部 | 这场戏的核心 beat 是什么？ |
| 场景替换 (Scene Replacement) | 删一场补一场 | 删除这场后叙事链是否断裂？ |
| 结构修改 (Structural Change) | 重写段落/角色/结尾 | 这**还是**这个电影吗？ |

### 与编剧的合作原则

- **先理解，再建议**：不理解编剧意图之前不要提修改
- **"因为意义"而不是"因为懒得拍"**：一个场景如果因执行难度被删，它的**叙事功能**必须在其他场景中补充
- **修改不是赢**：导演和编剧的目标相同（最好可能的电影）而非"谁的剧本更对"

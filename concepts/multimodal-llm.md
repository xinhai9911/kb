# 多模态大模型

## 概述

多模态大模型 (Multimodal LLM) 是能够同时处理文本、图像、视频等多种模态信息的模型。通过视觉编码器与语言模型的结合，实现跨模态理解与生成。

---

## 多模态架构演进

```
2021: CLIP -> 图文对比学习奠基
2022: BLIP -> 统一视觉语言框架
2023: LLaVA -> 视觉指令微调范式
2023: GPT-4V -> 商用多模态里程碑
2024: Gemini -> 原生多模态（非拼接）
2024: Qwen-VL 2.5 -> 开源多模态追赶
2025: GPT-4o -> 原生全模态
```

### 关键里程碑

- **CLIP (2021)**: 对比学习对齐视觉和语言表示
- **LLaVA (2023)**: 视觉指令微调，用线性投影连接 ViT 和 LLM
- **GPT-4V (2023)**: 多模态能力质的飞跃
- **Gemini (2024)**: 从底层设计就是多模态的

## Vision Transformer (ViT) 原理

### 核心流程

```
输入图像 (224x224x3)
  -> 切分为 16x16 patch (196 个)
  -> 线性投影为 embedding
  -> 加入位置编码
  -> Transformer Encoder 处理
  -> [CLS] token 作为图像表示
```

### 关键参数

| 模型 | 分辨率 | Patch 大小 | Patch 数 | 输出维度 |
|------|--------|-----------|---------|---------|
| ViT-B/16 | 224x224 | 16x16 | 196 | 768 |
| ViT-L/14 | 224x224 | 14x14 | 256 | 1024 |
| ViT-G/14 | 224x224 | 14x14 | 256 | 1664 |
| SigLIP | 384x384 | 14x14 | 729 | 1152 |

### 分辨率扩展

- **动态分辨率**: 将图像切分为多个 tile，分别编码后拼接
- **AnyRes**: LLaVA-1.5 使用的动态分辨率策略
- **NativeResolution**: Gemini 直接支持原始分辨率

## 视觉-语言对齐方式

### 1. CLIP 对比学习

```
图像编码器 -> 图像特征
文本编码器 -> 文本特征
  -> 余弦相似度矩阵
  -> 对比损失 (InfoNCE)
```

- 学习图文之间的语义对齐
- 无需标注，海量图文对即可训练

### 2. 投影层 (Linear / MLP)

```
视觉特征 -> 投影层 -> 语言模型可接受的 token 嵌入
```

- LLaVA 使用线性投影
- LLaVA-1.5 使用两层 MLP
- 简单高效，但信息保留有限

### 3. Q-Former (BLIP-2)

```
视觉特征 -> Querying Transformer -> 固定数量的 query
  -> 与语言模型对齐
```

- 使用可学习 query 压缩视觉信息
- 减少视觉 token 数量（从数百降到 32-64）
- 计算效率更高

### 4. 原生多模态 (Gemini/GPT-4o)

- 从预训练就是多模态的
- 不需要显式的对齐模块
- 各模态 token 在同一空间处理

## 训练策略

### 三阶段训练

```
阶段1: 预训练对齐
  - 冻结视觉编码器和 LLM
  - 仅训练投影层
  - 数据: 大规模图文对 (数十亿)

阶段2: 多模态指令微调
  - 冻结视觉编码器
  - 微调 LLM + 投影层
  - 数据: 多模态指令数据 (数百万)

阶段3: 高质量对齐 (可选)
  - 解冻全部参数
  - 使用高质量偏好数据
  - RLHF/DPO 对齐
```

### 冻结策略权衡

| 策略 | 优势 | 劣势 |
|------|------|------|
| 冻结视觉+训练语言 | 训练快，成本低 | 视觉理解深度有限 |
| 冻结视觉+微调全模型 | 更好对齐 | 训练成本高 |
| 端到端联合训练 | 最优性能 | 需大量数据和计算 |

## 应用场景

### 1. 图像理解

- 图像描述 (Image Captioning)
- 视觉问答 (VQA)
- 图表/表格理解
- OCR 与文档分析

### 2. 视频分析

- 视频摘要
- 时间点定位
- 动作识别
- 视频问答

### 3. 文档处理

- PDF 文档解析
- 发票/票据识别
- 合同条款提取
- 多语言文档翻译

### 4. 创意应用

- 图像生成提示
- UI 设计稿解读
- 数据可视化分析
- 地图/遥感图像理解

## 常见挑战

### 1. 幻觉问题

- 多模态模型更容易产生视觉幻觉
- 描述图像中不存在的物体或细节
- 缓解: 引用 grounding, 后处理验证

### 2. 空间推理

- 对空间关系的理解较弱
- 左右、上下、相对位置判断不准
- 缓解: 更多空间标注数据训练

### 3. 细节遗漏

- 小字、远处物体、密集文本易遗漏
- 低分辨率图像信息丢失
- 缓解: 动态高分辨率支持

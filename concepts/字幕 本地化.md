# 字幕、图形与本地化

## 字幕类型

### 硬烧录 (Hard Burned / Open Caption)

字幕直接渲染到视频画面上，不可关闭。适用于：

- 社交媒体视频（TikTok/Instagram/YouTube Shorts）
- 公共场合播放（无法切换字幕）
- Pre-roll 广告平台限制软字幕
- 视频输出时已含字幕，交付单一文件

**优势**：兼容性 100%，无格式/编码问题

**劣势**：不可关闭，遮挡画面，修复需重新渲染

### 软字幕 (Soft Subtitle / Closed Caption)

字幕文件独立于视频流，观众可开关。适用于：

- 电影/电视剧（主流选择）
- 多语言版本（同一视频 + 不同语言字幕文件）
- 流媒体平台（Netflix/YouTube/Amazon Prime）

**优势**：可开关，多语言无需重新编码视频

**劣势**：对播放器兼容性有要求

## 字幕格式

| 格式 | 类型 | 特点 | 适用平台 |
|------|------|------|---------|
| **SRT** | 文本 | 最简单的基础格式，仅时间码+文本 | 通用，几乎所有播放器 |
| **ASS/SSA** | 文本+样式 | 支持字体/颜色/位置/动画/Karaoke | 动漫/高级字幕，VLC/mpv |
| **STL** | 二进制 | EBU 广播标准，支持多语言分页 | 广播电视 |
| **VTT** | 文本 | WebVTT，HTML5 标准，支持 CSS 样式 | HTML5 Video/YouTube |
| **SCC** | 二进制 | Scenarist Closed Caption，CEA-608/708 | 北美广播电视 |
| **CAP/MCC** | 二进制 | DVD/蓝光标准 | 光盘制作 |
| **XML** | 文本 | FCPXML/DaVinci 内部格式 | 时间线交换 |
| **TTML** | XML | W3C 标准，Netflix 要求 | Netflix/流媒体 |

### SRT 格式示例

```
1
00:00:01,000 --> 00:00:04,000
这是第一行字幕

2
00:00:05,000 --> 00:00:08,500
这是第二行字幕
可以换行
```

### ASS 核心特性

ASS（Advanced SubStation Alpha）是 SRT 的进化版：

- **样式定义**：字体名、字号、颜色、边框、阴影
- **位置控制**：屏幕任意位置，支持旋转
- **叠加模式**：多字幕同时显示（卡拉 OK 特效）
- **对话事件**：每句字幕可独立设置样式覆盖

### VTT 与 CSS

WebVTT 是 HTML5 的标准字幕格式：

```
WEBVTT

00:00:01.000 --> 00:00:04.000
<b>这是加粗字幕</b>

00:00:05.000 --> 00:00:08.000
<c.redText>这是红色字幕</c>
```

支持通过 `::cue` CSS 伪元素控制样式。

## 标题设计原则

### 字体选择

| 用途 | 推荐字型 | 原因 |
|------|---------|------|
| 电影正片字幕 | 无衬线（Helvetica/Arial/思源黑体） | 可读性优先 |
| 纪录片 Lower Third | 无衬线 + 轻量（Gotham/Proxima Nova） | 不干扰画面 |
| 片头标题 | 衬线/手写（Trajan/Minion/方正楷体） | 风格化表达 |
| 社交媒体 | 圆体/粗体（Montserrat/Poppins/阿里巴巴普惠体） | 移动端可读 |

### 位置

- **字幕**：屏幕底部安全区（下 10-15% 区域），留出边缘 5% 安全边界
- **Lower Thirds**：左下/中下区域，通常不超过画面下 1/3
- **片头标题**：中央/上三分区，视构图而定
- **安全区**：Title Safe（90% 画面），Action Safe（95% 画面）

### 持续时间

- 单行字幕：至少 1 秒，每多一词增加 0.3-0.5 秒
- 双行字幕：至少 2.5 秒，不超过 6 秒
- 最低阅读时间：每小时 140 词（约每 3 字/秒）

### 可读性

- 描边（Stroke）：1-2px 黑色描边显著提升和差背景的对比
- 背景条（Background Box/Banner）：半透明黑色底条，解决白底画面文字不可读
- 字幕对比度：与画面内容的对比度至少 4.5:1（WCAG AA）
- 中文建议：思源黑体 Bold + 1px 描边 + 半透明黑底

## Lower Thirds 设计

Lower Thirds 是视频中最重要的信息图形之一，用于标识说话人、地点、职务等。

### 设计原则

1. **简洁**：名字（大写）+ 职务/标题（小写），不超过两行
2. **入画/出画**：动画时间通常 0.5-1.0 秒，不可过快
3. **停留时间**：说话人首次出现后保持至少 3 秒
4. **品牌一致性**：颜色和字体与企业品牌一致

### 制作工具

- **AE MOGRT**：After Effects 中制作，导出为 .mogrt 文件在 Premiere 中使用
- **Premiere 基本图形**：内置，无需 AE
- **Apple Motion + FCP**：FCP 生态的动态图形方案
- **Resolve Fusion**：Fusion 页面制作，节点式流程

## 本地化工作流

### 标准流程

```
原始视频
  │
  ├── 1. 转录 (Transcription)
  │    └── 自动转写 (Whisper/Rev.ai) → 人工校对
  │
  ├── 2. 创建时间轴 (Timing/Spotting)
  │    └── 逐句对位时间码 → 断句规则
  │
  ├── 3. 翻译 (Translation)
  │    └── 源语言字幕 → 目标语言 → 长度约束
  │
  ├── 4. 时间轴调整 (Adaptation)
  │    └── 翻译后文本长度变化需要调整显示时间
  │
  ├── 5. 审校 (Review/QC)
  │    └── 语法/拼写/时间码/特殊字符检查
  │
  └── 6. 打包 (Export)
       └── 按平台要求输出格式（SRT/VTT/SCC/TTML）
```

### 转录工具

| 工具 | 精度 | 语言 | 费用 |
|------|------|------|------|
| OpenAI Whisper | 高 | 98+ 语言 | 免费/开源 |
| Rev.ai | 高 | 40+ 语言 | API 付费 |
| Premiere Text-Based Editing | 中高 | 16 语言 | Adobe CC 订阅 |
| Descript | 高 | 22 语言 | 订阅制 |

### 翻译约束

- **字符数**：每行不超过 42 个字符（英文）/ 16-20 字（中文）
- **断句**：在语法自然停顿处换行，不在形容词和名词之间断开
- **阅读速度**：英文 15-20 CPS（characters per second），中文 5-8 CPS
- **同步**：翻译后的长度变化必须重新调整时间码
- **多语言**：同一视频导出多套 SRT/VTT，文件命名 `Title_Lang.srt`

### Netflix 技术要求

Netflix 对字幕有严格的技术规范：

- 格式：TTML (Timed Text Markup Language)
- 帧率：必须精确匹配视频帧率
- 时间码精度：1 帧
- 最大行数：2 行
- 最大字符/行：42（英文），16（中文）
- 最小持续时间：5/6 秒（英文）/ 2 秒（中文）

## 各 NLE 的字幕工具

### Premiere Pro

- 旧版：Legacy Titler（已弃用）
- 当前：**基本图形面板 (Essential Graphics)**
- 字幕工作区：Window > Captions and Graphics
- 支持 SRT/VTT 导入导出
- 文字转字幕：Text-Based Editing 面板一键生成
- 动态图形模板：AEGP API，支持 MOGRT

### DaVinci Resolve

- **Fusion 字幕**：节点式标题设计，完全可定制
- **字幕轨道**：独立字幕轨 + Inspector 编辑
- **导出**：Fusion 合成可保存为 Templates
- **对白字幕**：Cut 页面的"生成字幕"基于语音转文字
- **格式**：导入/导出 SRT，支持 TTML 导出

### Final Cut Pro

- **字幕发生器**：内置多种字幕模板
- **角色 (Roles)**：字幕作为独立角色管理
- **格式**：SRT 导入导出
- **同步**：与 Compressor 集成批量添加字幕
- **第三方**：Subtitle Edit 集成

### Avid Media Composer

- **Marquee Title Tool**：基于 GPU 的实时字幕工具
- **Subtitle 插件**：第三方插件（如 Prodyssey Subtitle）
- **格式**：STM 格式，需转换到 SRT
- **工作流**：通常将字幕作为回套层叠加在视频上

## 与动态图形的关系

复杂标题动画和 Lower Thirds 通常在 [[concepts/进阶 运动 图形|After Effects]] 中设计制作后导出 MOGRT 模板，再在 NLE 中使用。这是[[entities/Adobe Premiere Pro|Premiere Pro]] 生态的核心优势。

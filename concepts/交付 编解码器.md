# 交付编解码器（Delivery Codec）

## 概述

Delivery Codec 是最终交付给观众/平台的压缩格式。与 [[concepts/夹层 编解码器|Mezzanine Codec]] 追求编辑性能不同，Delivery Codec 追求**最高压缩效率**——在最小文件体积内保留可接受画质。

## 主流交付编解码器

### H.264 (AVC / Advanced Video Coding)

- **标准**：MPEG-4 Part 10，2003 年发布
- **优势**：硬件解码最广泛、兼容性最好、自适应流媒体标准
- **局限**：8-bit 主、4:2:0 为主、高码率下效率落后于 H.265/AV1
- **典型用途**：在线视频（YouTube / Vimeo / 社交媒体）、蓝光、广播电视
- **Profile**：Baseline（视频会议）→ Main → High（最高质量）

### H.265 (HEVC / High Efficiency Video Coding)

- **标准**：ITU-T H.265 / MPEG-H Part 2，2013 年发布
- **优势**：比 H.264 节省约 50% 码率、支持 10-bit HDR 原生
- **局限**：专利许可复杂（多个专利池）、硬件解码不如 H.264 普及
- **典型用途**：4K 流媒体、HDR 内容、Apple 设备生态
- **HDR 必备**：10-bit Main Profile 是 HDR 交付的最低要求

### AV1

- **标准**：Alliance for Open Media (Google / Apple / Netflix / Meta / Amazon)，2018 年
- **优势**：开源免专利费、比 H.265 再省约 30% 码率
- **局限**：编码速度慢（SVT-AV1 / libaom）、硬件解码仅新设备支持
- **典型用途**：YouTube（AV1 为主推格式）、Netflix（部分 4K 流）、Chrome 浏览器

### ProRes / DNxHR（母版交付）

- **用途**：不是流媒体格式，用于**影院母版、电视台档、存档**
- **格式**：ProRes 4444 / ProRes 422 HQ / DNxHR 444
- **场景**：Netflix 原始母版规范要求 ProRes 4444 或 DNxHR 444

## 交付格式选择矩阵

| 场景 | Codec | 色深 | 分辨率 | 码率参考 |
|------|-------|------|--------|---------|
| YouTube / Vimeo | H.264 / AV1 | 8/10-bit | 最高 8K | 15–50 Mbps (4K) |
| Netflix / 流媒体母版 | ProRes 4444 | 12-bit | 最高 4K | ~800 Mbps |
| 广播电视 | H.264 / XDCAM | 8-bit | 1080p | 10–50 Mbps |
| 数字影院 | JPEG 2000 | 12-bit | 4K | ~250 Mbps |
| 社交媒体（竖屏） | H.264 | 8-bit | 1080p | 5–15 Mbps |
| HDR 流媒体 | H.265 / AV1 | 10-bit | 4K | 20–40 Mbps |

## 响应度标准

- **YouTube**：-14 LUFS（集成响度），-1 dB True Peak
- **广播电视**：-23 LUFS (+/- 0.5)，-2 dB True Peak
- **影院**：-27 LUFS，-3 dB True Peak
- **Netflix**：-27 LUFS + ProRes 4444 母版 + IMF 封装

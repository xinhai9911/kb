# 芯片资料 - 学术论文与培训零散资料蒸馏

> 本笔记收拢 `Q:\芯片资料` 中主题相对独立、不适合并入厂商主笔记的学术论文与培训资料：内存安全检测、安全 RDMA、沐创自研网卡培训、SDK 配置 CHM 帮助。RSS 相关论文（symRSS）因与网卡 RSS 强相关，已并入 [[50-reference/sources/chips/NIC DPDK]]。

## 1. AddressSanitizer（atc12-final39.pdf，Google，USENIX ATC'12）

- **是什么**：Google 出品的**快速内存错误检测器**，面向 C/C++。可发现**堆/栈/全局对象越界访问（out-of-bounds）**与**释放后使用（use-after-free）**两类最主要内存 bug。
- **原理要点**：
  - 采用**专用内存分配器** + **影子内存（shadow memory）** 映射：每 8 字节应用内存对应 1 字节影子内存，标记该区间状态（可寻址/红区/已释放）。
  - 在内存分配周围插入 **redzones（红区）**，越界访问会落到红区而被捕获；释放后内存标记为 poisoned，再次访问即报错并给出调用栈。
  - 插桩（instrumentation）在编译期插入内存访问检查，相比 Valgrind 等纯运行时工具**速度快得多**（论文实测开销约 2×，远低于同类工具）。
- **价值**：C/C++ 系统软件（含网卡驱动、SDK、内核模块）开发期内存安全兜底；与后续 **HWASan / MemoryTagging** 同源思路。
- **关联**：驱动/SDK 开发见 [[50-reference/sources/chips/Centec SDK]]、[[50-reference/sources/chips/Motorcomm 交换机]]。

## 2. Bedrock：安全 RDMA 的可编程网络支持（sec22summer_xing.pdf，USENIX Security'22）

- **背景**：RDMA 在云数据中心流行——客户端**绕过服务器 CPU 直接读写远端内存**。但 RDMA 暴露出包注入、拒绝服务、侧信道泄漏等漏洞，而防御滞后；由于数据面绕过 CPU 软件处理，**传统基于主机的防御难以插入且不引入性能惩罚**。
- **方案 Bedrock**：把 RDMA 安全能力**下沉到网络内部**，利用现代网络硬件的**可编程数据平面（P4/可编程交换芯片）** 实现：
  - 在网络层提供身份/授权校验、流量合法性检查，使 RDMA 读写在到达终点前即被策略管控。
  - 不修改 RDMA 协议本身，而是在交换机/智能网卡侧以线速实施安全策略。
- **价值**：为高性能 RDMA 场景（分布式存储、AI 训练集群）提供**线速、不损性能**的安全基座；思路与在 NIC/交换机侧做有状态处理（参见 [[50-reference/sources/chips/Centec CTC 7132]] 的 SCL/ACL）一脉相承。
- **关联**：网络设备 ACL/SCL 见 [[50-reference/sources/chips/Centec CTC 8180]]。

## 3. 沐创（MuChuang）自研网卡培训（沐创自研网卡培训-邱瑶.pptx，23 页）

> 提取自 PPTX（231 行文本）。讲者邱瑶（技术平台部·硬件技术开发组），介绍沐创自研网卡项目。

- **项目背景**：国外芯片大批量断货、在供芯片随时面临断货风险；为**降成本保供应**，需适配国产芯片与自研芯片。芯片设计由硬件工程师李华峰完成。
- **内容三块**：①项目背景（断供危机、国产替代动机）②网卡设计 ③网卡适配。
- **适配线索（来自幻灯片文本）**：
  - 驱动代码路径示例：`.../vendor_new/vendor/common/mucse/rnp-nic-mutiports-drv-0.1.5-rc33-.../rnpm`（印证 [[50-reference/sources/chips/NIC DPDK]] 中沐创 `rnp`/`rnpm`/`rnpgbe` 驱动体系）。
  - 运维命令片段：`--slot X`（get module info）、`--bypass runtime X-Y status`（旁路运行状态）；转发示例 `./l2fwd -l 1-3 --master-lcore 1 -n 2 -- -p0x`（DPDK l2fwd 多核转发）。
- **价值**：从厂商内部视角印证沐创 N 系列自研网卡的驱动架构与国产替代定位，与 [[50-reference/sources/chips/NIC DPDK]] §6 沐创产品矩阵互补。
- **关联**：沐创驱动/DPDK 适配见 [[50-reference/sources/chips/NIC DPDK]]。

## 4. SDK 典型配置应用 CHM（SDKTypicalConfiguration_APP_5.6.8RC.chm，~11.6 MB）

- **是什么**：盛科 SDK **典型配置应用帮助文档（CHM 编译格式）**，版本 5.6.8RC。提供 SDK 配置示例/API 用法的人读帮助。
- **提取状态**：⚠️ CHM 为二进制编译帮助格式，**未做文本提取**，此处仅登记元信息。可对照文本版 SDK 指南（[[50-reference/sources/chips/Centec SDK]]）使用；如需提取可用 `archmage` / `hh -decompile` 反编译后落入 `extract_out/chips/`。
- **关联**：SDK 开发指南见 [[50-reference/sources/chips/Centec SDK]]。

## 可提炼要点（实证）

- AddressSanitizer：编译期插桩 + 影子内存，C/C++ 内存 bug 高性能检测（约 2× 开销）。
- Bedrock：RDMA 安全下沉到可编程网络硬件，线速防御、不损 CPU 旁路收益。
- 沐创自研网卡：国产替代驱动路径 `mucse/rnp*/rnpm`，与 DPDK `l2fwd` 转发示例一致。
- CHM 帮助：仅登记元信息，未提取（二进制）。

## 深度提炼

> 来源：`H3C_SecPath_TAP8000-C32_CE54__CE54H__CE54L_流量可视化设备_Web配置指导_E6601_-5W101-整本手册.txt`（~70 KB，章节完整）。TAP8000 是旁路/镜像流量采集与可视化分发设备，Web 网管。型号差异：**C32 / CE54L 不支持高级分流与诊断监控**；**CE54 / CE54H 支持**（§4、§5 标注）。

### 1) 设备与登录

- 功能定位：对网络流量做**采集 → 分发/过滤/负载均衡 → 可视化**，把流量送到分析器（IDS/探针/存储）。
- 默认登录：用户名/密码 `admin/admin`，管理 IP `192.168.0.1`；用交叉线连 PC（PC 配 192.168.0.0/24 内地址如 192.168.0.100），浏览器 `https://192.168.0.1` 登录；**首次登录必须改默认密码**。
- WebUI 模块：系统状态 / 功能配置 / 高级分流配置 / 诊断与监控 / 流量趋势 / 设备管理 / 系统更新。

### 2) 系统状态与流量监控（§2）

- **系统状态**：运行时间、系统时间、序列号、型号、软件版本、温度、风扇、CPU/内存使用率。
- **端口状态**：前面板端口图，悬停显示模块信息、端口使能、速率、收发包数、描述。
- **流量监控指标**（可直接导出统计）：STATE、RX_OK/TX_OK、RX_BPS/TX_BPS、RX_PPS/TX_PPS、RX_bps/TX_bps、RX_BYTE/TX_BYTE、RX_UTIL/TX_UTIL、RX_MAX_bps/TX_MAX_bps、RX_ERR/TX_ERR、RX_DRP/TX_DRP、RX_OVR/TX_OVR（错包/丢包/过载丢包）。

### 3) 功能配置（§3，全型号支持）

- **端口配置**：物理端口使能/速率等基础属性。
- **分流组配置**：把端口/流量归入不同分发组。
- **组播组配置**：组播复制分发。
- **转发规则（核心）**：`3.5` 新建/批量新建/删除/批量删除规则；另含 **EGRESS 规则（3.6）**、**VLAN 规则（3.7）**、**隧道规则（3.8，如 GRE/VXLAN 等隧道识别）**。
- **端口 IP 配置 / 镜像配置**：管理面与端口镜像。

### 4) 高级分流配置（§4，仅 CE54 / CE54H）

- **工作模式**：基础/高级分流模式切换。
- **智能转发规则**：按多维特征精细分流。
- **智能去重**：报文级去重，降低后端分析负载。
- **应用识别与脱敏**：识别应用协议并对敏感字段脱敏（合规）。
- **视频识别配置**：针对视频流特征识别。
- **智能输出**：按策略输出到分析器。
- **Netflow 配置**：输出 NetFlow 流记录（对接 NetFlow 采集器）。

### 5) 诊断与监控（§5，仅 CE54 / CE54H）

- **流量捕获**：设备侧抓包，用于现场排障与协议分析。

### 6) 流量趋势（§6）

- 端口流量趋势、策略流量趋势：长期趋势图，辅助容量规划与异常发现。

### 7) 设备管理（§7）

- 带外网管配置、系统时间、用户权限管理、设备配置管理、系统日志管理。

### 8) 系统更新（§8）

- 系统升级管理（升级/重启/关机）。

### 与可观测体系的衔接

- TAP8000 处于"流量"侧：旁路采集 + 高级分流/去重/NetFlow，是日志/指标之外的**全量原始流量**来源；与 [[sources/books/elasticsearch-elk]] 的"日志+指标"可视化互补，构成"流量+日志"双视角可观测链路。后端分析器可接 ELK/抓包/NetFlow 采集。
- 型号选型：**只需基础镜像分发→C32/CE54L 够用**；需智能去重/应用识别/NetFlow/抓包→选 CE54/CE54H。

## 深度提炼

> 来源：`H3C_SecPath_TAP8000-C32_CE54__CE54H__CE54L_流量可视化设备_Web配置指导_E6601_-5W101-整本手册.txt`（~70 KB，章节完整）。TAP8000 是旁路/镜像流量采集与可视化分发设备，Web 网管。型号差异：**C32 / CE54L 不支持高级分流与诊断监控**；**CE54 / CE54H 支持**（§4、§5 标注）。

### 1) 设备与登录

- 功能定位：对网络流量做**采集 → 分发/过滤/负载均衡 → 可视化**，送到分析器（IDS/探针/存储）。
- 默认登录：用户名/密码 `admin/admin`，管理 IP `192.168.0.1`；PC 配 192.168.0.0/24 内地址（如 192.168.0.100），浏览器 `https://192.168.0.1` 登录；**首次登录必须改默认密码**。
- WebUI 模块：系统状态 / 功能配置 / 高级分流配置 / 诊断与监控 / 流量趋势 / 设备管理 / 系统更新。

### 2) 系统状态与流量监控（§2）

- **系统状态**：运行时间、系统时间、序列号、型号、软件版本、温度、风扇、CPU/内存使用率。
- **端口状态**：前面板端口图，悬停显示模块信息、端口使能、速率、收发包数、描述。
- **流量监控指标**（可导出统计）：STATE、RX_OK/TX_OK、RX_BPS/TX_BPS、RX_PPS/TX_PPS、RX_bps/TX_bps、RX_BYTE/TX_BYTE、RX_UTIL/TX_UTIL、RX_MAX_bps/TX_MAX_bps、RX_ERR/TX_ERR、RX_DRP/TX_DRP、RX_OVR/TX_OVR（错包/丢包/过载丢包）。

### 3) 功能配置（§3，全型号支持）

- **端口配置**：物理端口使能/速率等基础属性。
- **分流组配置（§3.3）**：将端口归入分发组。新建步骤：点击"分流组配置"→设"分流因子"→设"分流组ID"→设"备份端口"→选"哈希域"→选"分流组端口"→设"端口权重"→"新建"。分流因子 + 哈希域决定负载均衡散列。
- **组播组配置（§3.4）**：创建组播组（设组播组ID、选端口、绑定分流组ID），用于端口过滤中组播组选择。
- **转发规则（§3.5，核心）**：见下节。
- **EGRESS 规则（§3.6）**：基于输出接口的 drop 策略，匹配五元组/以太网类型/VLAN/报文特征。
- **VLAN 规则（§3.7）**：指定端口流量 VLAN 增删改，支持 2 层 VLAN 处理。单条规则字段：源端口 + 五元组/以太网类型/报文特征 + 外层 VLAN 动作(null/set/add/remove) + 外层 VLAN ID + 内层 VLAN 动作 + 内层 VLAN ID。
- **隧道规则（§3.8）**：与转发规则配合，对 GRE/VXLAN 等隧道封装报文按内层 IP/协议/port 做复制、汇聚、过滤、负载均衡；可终结隧道（去隧道头）。
- **端口 IP 配置 / 镜像配置（§3.10）**：管理面与端口镜像；镜像支持 RSPAN / ERSPAN 封装，需结合"端口 IP 配置"填封装 IP。

### 4) 转发规则详细（§3.5）

- **匹配组类型**：MAC / IP / IPV6 / Flexible / fullmatch，优先级 MAC < IP < IPV6 < Flexible < fullmatch。
- **新建单条过滤规则**：策略ID → 匹配组类型 → 源端口 → 过滤条件 → 动作 → 目的端口 → 确认。过滤条件可基于五元组（源IP/目的IP/源端口/目的端口/协议号）、以太网类型值、报文特征。
- **Action 动作（表 3-2）**：

  | 动作 | 说明 |
  |---|---|
  | Redirect to port | 复制到单输出口 |
  | Redirect to trunk group | 复制到分流组（多接口） |
  | Redirect to mc group | 复制到组播组 |
  | Mirror | 导入 CPU 做镜像（结合镜像配置） |
  | drop | 输入口直接丢弃 |
  | Intelligent process | 导入 CPU 高级分流（去重/脱敏/时间戳，需 §4 配置） |

- **常见协议类型（表 3-3）**：ICMP / IPinIP / TCP / FTP / HTTP / HTTPS / UDP / DNS / SNMP / GRE / SCTP。
- **批量新建**：起始规则ID + ID 间隔值 + 动作 + 源/目的端口 + 五元组批量配置。批量删除：起始/终止规则ID。

### 5) 高级分流配置（§4，仅 CE54 / CE54H）

- **工作模式**：基础/高级分流切换。
- **智能转发规则（§4.4）**：每条规则可叠加多个高级处理，字段依次为：规则ID → 匹配组类型 → 老化时间 → 五元组信息 → vlan 标记映射 → 开关项：
  - **自定义解封装**：开关 + 解封装偏移量 + 解封装长度。
  - **切片（slicing）**：开关 + 切片值（只截取前 N 字节送往分析器，降带宽）。
  - **去重**：开关。
  - **SSL 解密**：开关 + SSL 密钥索引值。
  - **NDPI 应用识别**：开关。
  - **脱敏**：开关（敏感字段脱敏，合规）。
  - **Netflow**：开关（输出 NetFlow 流记录）。
  - **VLAN 标记**：VLAN 标记值。
- **智能去重（§4.5）**：报文级去重（多采集源对比，规定时间内相同包去重）。字段：去重开关 + 去重时间 + Payload 开关 + Payload 长度 + IPV4 去重标识 + IPV6 去重标识；另可配 VLAN 标记映射。
- **应用识别与脱敏（§4.6）**：NDPI 与脱敏需在智能转发规则中 enable 对应开关。
- **视频识别配置**：针对视频流特征识别。
- **智能输出**：按策略输出到分析器。
- **Netflow 配置（§4.9）**：输出 NetFlow 流记录，对接 NetFlow 采集器。

### 6) 诊断与监控（§5，仅 CE54 / CE54H）

- **流量捕获**：设备侧抓包，用于现场排障与协议分析。

### 7) 流量趋势（§6）

- 端口流量趋势、策略流量趋势：长期趋势图，辅助容量规划与异常发现。

### 8) 设备管理（§7）与系统更新（§8）

- 设备管理：带外网管、系统时间、用户权限、设备配置管理、系统日志。
- 系统更新：升级/重启/关机。

### 与可观测体系的衔接

- TAP8000 处于"流量"侧：旁路采集 + 高级分流/去重/NetFlow，是日志/指标之外的**全量原始流量**来源；与 [[50-reference/sources/books/elasticsearch-elk]] 的"日志+指标"可视化互补。后端分析器可接 ELK/抓包/NetFlow 采集。
- 型号选型：**只需基础镜像分发→C32/CE54L**；需智能去重/应用识别/NetFlow/抓包→选 **CE54/CE54H**。

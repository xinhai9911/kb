> 配套：[[50-reference/director-intro]]（导演入门总纲）、[[50-reference/montage-techniques]]（蒙太奇手法）。提供 ASCII 示意图 + 可直接填写的分镜表。

## 一、轴线（180° 规则）示意图

### 1.1 什么是轴线
两人 A、B 面对面，连一条假想线 = 轴线。摄影机必须待在线的**同一侧**拍。

```
                轴线（A、B 的连线，假想竖线）
                          │
   【左半边】              │              【右半边】
   A 在左                  │                 B 在左
   B 在右                  │                 A 在右
                          │
   cam1 ●                 │                 ● cam3
   cam2 ●                 │
   (都在这边)              │                 (跑到这边 = 越轴)
```

### 1.1a 正确：机位都在左半边
```
   左半边拍到的画面（cam1、cam2）：
   ┌─────────────┐
   │  A ●    ● B  │   ← A 永远左，B 永远右
   └─────────────┘
   切来切去观众都不晕，因为左右关系没变
```

### 1.2 越轴（错误示范）：cam3 跑到右半边
```
   右半边拍到的画面（cam3）：
   ┌─────────────┐
   │  B ●    ● A  │   ← 反了！B 在左，A 在右
   └─────────────┘

   上一镜：A 在左  →  下一镜：A 在右
   观众："?? 刚才还面对面，怎么瞬间换位了"
```

**记法**：机位别过 A、B 中间的竖线。永远在线的同一侧拍，画面里的左右就不会翻。

## 二、镜头景别示意图（从远到近）

```
远景  ┌───────────────────────────┐
      │        山 河 大 地          │
      │             ●(人很小)        │  ← 看环境、显渺小
      └───────────────────────────┘

全景  ┌───────────────────────────┐
      │                           │
      │        ┌─────────┐        │
      │        │  全身   │        │  ← 人在哪、在干嘛
      │        └─────────┘        │
      └───────────────────────────┘

中景  ┌───────────────────────────┐
      │        ┌─────────┐        │
      │        │ 腰以上  │        │  ← 叙事主力（对话）
      │        └─────────┘        │
      └───────────────────────────┘

近景  ┌───────────────────────────┐
      │        ┌─────────┐        │
      │        │ 胸以上  │        │  ← 注意表情
      │        └─────────┘        │
      └───────────────────────────┘

特写  ┌───────────────────────────┐
      │      ┌─────────────┐      │
      │      │  脸 / 手    │      │  ← 情绪爆发、细节
      │      │  占满画面   │      │
      │      └─────────────┘      │
      └───────────────────────────┘
```

**用法口诀**：想让观众哭 → 切特写看眼睛；想显渺小 → 远景。

## 三、运镜示意图

```
推（靠近目标）       拉（远离目标）
●→ cam              cam → ●
 主体变大            主体变小
 强调/聚焦          揭示全貌/结束感

摇（机位不动，镜头转）
        ↑
   cam ──┤──> 左右环顾空间
        ↓

移（机位平移）
cam → → → 沿轨道横移，穿梭空间

跟（跟着主体走）
cam 跟着 ● 一起前进，观众"一起走"
```

## 四、分镜表模板（填完就能拍能剪）

直接复制下面表格，按行填。每一行 = 一个镜头。

| 镜头号 | 景别 | 运镜 | 秒数 | 内容 / 画面 | 声音 | 备注 |
|--------|------|------|------|-----------|------|------|
| 1  | 远景 | 固定 | 3s | 主角站在沙漠里 | 风声 | 片头，显渺小 |
| 2  | 中景 | 推   | 4s | 主角转身走向帐篷 | 脚步声渐强 | — |
| 3  | 近景 | 固定 | 2s | 主角表情疲惫 | 呼吸声 | — |
| 4  | 特写 | 固定 | 2s | 手握住水壶 | 水流声 | 强调渴 |
| 5  | 中景 | 拉   | 3s | 主角走远，环境收回 | 音乐起 | 结束感 |

### 填写说明
- **镜头号**：从 1 开始，剪的时候按顺序拼
- **景别**：远 / 全 / 中 / 近 / 特（写中文即可）
- **运镜**：固定 / 推 / 拉 / 摇 / 移 / 跟
- **秒数**：这个镜头时长，直接对应 ffmpeg 的 `trim=start=end=` 或 `-t`
- **内容**：这一秒观众看到什么
- **声音**：同期声 / 音乐 / 静音（声音占观感一半，别空着）
- **备注**：淡入淡出、水印、轴线侧等提醒

### 怎么从分镜表变成 ffmpeg 命令
每张表就是一个剪辑计划。例如上面 5 个镜头来自一个素材，时间点分别是：
- 镜头1：0–3s
- 镜头2：3–7s
- 镜头3：7–9s
- 镜头4：9–11s
- 镜头5：11–14s

用 trim 按顺序切并接：
```bash
ffmpeg -i in.mp4 -filter_complex \
"[0:v]trim=start=0:end=3,setpts=PTS-STARTPTS[s1];\
 [0:v]trim=start=3:end=7,setpts=PTS-STARTPTS[s2];\
 [0:v]trim=start=7:end=9,setpts=PTS-STARTPTS[s3];\
 [0:v]trim=start=9:end=11,setpts=PTS-STARTPTS[s4];\
 [0:v]trim=start=11:end=14,setpts=PTS-STARTPTS[s5];\
 [s1][s2][s3][s4][s5]concat=n=5:v=1[v]" \
-map "[v]" out.mp4
```
> 秒数那一列，就是这里的 start/end。分镜表填好，命令照抄即可。

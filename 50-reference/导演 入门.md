## 一、ffmpeg：如何明确"秒处理点"

核心思路：脑子里的"第几秒到第几秒要做什么" → 直接填进 ffmpeg 的时间参数或滤镜条件。

### 1.1 时间点的三种写法
- 秒：`10` 表示第 10 秒
- 时:分:秒：`00:00:12` 或 `00:01:30.5`（支持小数）
- 帧（配合帧率，少用）

### 1.2 两个最关键的位置参数
| 参数 | 作用 | 例子 |
|------|------|------|
| `-ss` | 起点 / 从第几秒开始 | `-ss 00:00:12` 从第 12 秒开始 |
| `-t`  | 持续时长（截多长） | `-t 8` 截取 8 秒 |
| `-to` | 结束点（绝对时间） | `-to 00:00:20` 到第 20 秒结束 |

例：只要视频第 12~20 秒这段
```bash
ffmpeg -i in.mp4 -ss 00:00:12 -to 00:00:20 -c copy out.mp4
```

### 1.3 场景 A：不同时间点切不同片段再拼起来
保留 `[0-5s]`、`[12-20s]`、`[40-45s]` 三段并合并（用 trim 一次完成）：
```bash
ffmpeg -i in.mp4 -filter_complex \
"[0:v]trim=start=0:end=5,setpts=PTS-STARTPTS[v1];\
 [0:v]trim=start=12:end=20,setpts=PTS-STARTPTS[v2];\
 [0:v]trim=start=40:end=45,setpts=PTS-STARTPTS[v3];\
 [v1][v2][v3]concat=n=3:v=1[v]" \
-map "[v]" out.mp4
```
> 音频同理加 `[0:a]atrim=...`，最后 concat 加 `:a=1`。
> `trim=start=X:end=Y` 就是"秒处理点"——把脑子里的数字直接填进去。

### 1.4 场景 B：在某个时间点开始/停止某个效果
用 `enable` 参数 + 时间条件，效果只在指定区间生效：
```bash
# 第 10~15 秒之间画面加模糊，其余时间正常
ffmpeg -i in.mp4 -vf "boxblur=10:enable='between(t,10,15)'" out.mp4
```
- `between(t,10,15)` → 10 秒到 15 秒之间
- `gt(t,10)` → 第 10 秒之后一直
- `lte(t,10)` → 第 10 秒之前

常用效果都能加 `enable`：
- 水印：`overlay=...:enable='between(t,5,30)'`
- 文字：`drawtext=text='xxx':enable='between(t,2,8)'`
- 淡入淡出：`fade=t=in:st=0:d=2`（st=起始秒，d=持续秒）

### 1.5 场景 C：固定时间点做转场 / 加片头片尾
片头 3 秒，正片从第 3 秒接上：
```bash
ffmpeg -i intro.mp4 -i main.mp4 -filter_complex \
"[0:v][1:v]concat=n=2:v=1[v]" -map "[v]" out.mp4
```
淡入：`fade=t=in:st=0:d=1.5`（开头 1.5 秒淡入）
淡出：`fade=t=out:st=58:d=2`（总时长 60 秒时，最后 2 秒淡出）

### 1.6 场景 D：按时间点抽帧 / 截图
```bash
ffmpeg -i in.mp4 -ss 00:00:12 -vframes 1 shot.jpg   # 第 12 秒截一张
ffmpeg -i in.mp4 -vf "fps=1/5" thumb_%03d.jpg        # 每 5 秒一张
```

### 1.7 把想法变成命令的套路
1. 记下时间点清单，例如：
   - 0–3s 片头淡入
   - 3–30s 正常
   - 30s 处加一个水印 5 秒
   - 58–60s 淡出
2. 每个时间点 → 对应一个 `between(t,a,b)` 或 `trim=start=a:end=b` 或一个 `-ss/-to`
3. 把数字填进模板

## 二、想当导演，需要哪些技能

### 2.1 核心：用画面讲故事的能力
- **视听语言**：镜头景别、运镜、轴线、蒙太奇——知道"这一秒该给观众看什么"
- **节奏感**：哪段快、哪段慢，什么时候静音比音乐更有力
- **叙事结构**：起承转合、三幕剧、钩子

### 2.2 和人说清楚的能力（最被低估）
- 给摄影讲"我要一种压抑的感觉"，给演员讲"你这时不是生气，是失望"
- 会看剧本、改剧本、和编剧沟通
- 现场控场

### 2.3 技术底子（不用精，但要懂）
- 拍摄：曝光、构图、光线基础
- 剪辑：Premiere / DaVinci / 剪映 / ffmpeg（前面练的就是剪辑思维）
- 声音：环境音、对白、配乐（占观感一半）
- 调色 / 后期流程

### 2.4 审美和输入量
- 大量看片且**拉片**（一帧帧拆别人怎么拍）
- 对美术、音乐、文学有判断力

### 2.5 现实起步路径
1. 先拍：手机就能拍，先完成 10 个 1 分钟短片
2. 自己剪：练时间点、节奏、转场
3. 学一个剪辑软件
4. 拉片 + 写分镜
5. 找人合作：编剧、摄影、演员

## 三、视听语言基础

### 3.1 镜头景别：摄影机离人多远，框住多少
决定观众"看什么、代入多深"。从远到近：

| 景别 | 框住范围 | 观众感受 | 例子 |
|------|---------|---------|------|
| 远景 | 人在画面很小，主要看环境 | 宏大、孤独、交代地点 | 人站沙漠里 |
| 全景 | 全身 + 一点周围 | 看清人在哪、在干嘛 | 人物全身 |
| 中景 | 腰以上 | 最常用，叙事主力 | 两人对话上半身 |
| 近景 | 胸以上 | 注意表情 | 人物说话表情 |
| 特写 | 脸/手/物体占满屏 | 情绪爆发、细节强调 | 流泪的眼睛、握紧的拳头 |

用法：想让观众哭 → 切特写看眼睛；想显渺小 → 远景。景别切换本身就有情绪。

### 3.2 运镜：摄影机怎么动
| 运镜 | 怎么动 | 效果 |
|------|--------|------|
| 推 | 镜头向目标靠近（或焦距拉长） | 强调、进入情绪、聚焦 |
| 拉 | 镜头远离目标 | 揭示全貌、疏离、结束感 |
| 摇 | 机位不动，镜头左右/上下转 | 环顾、展示空间、跟随视线 |
| 移 | 机位平移（轨/车/手持走） | 跟随人物、穿梭空间 |
| 跟 | 一直跟着运动主体走 | 代入感，观众"一起走" |

用法：主角决定离开，镜头慢慢"拉"开 → 观众感到失去。

### 3.3 轴线：180 度规则
两人 A、B 面对面，连一条线（轴线）。摄影机必须待在线**同一侧**拍。
- 正确：所有镜头都在线同侧 → A 永远在左、B 永远在右，方向不乱
- 越轴（跳到线另一侧）：A 突然跑到右边 → 观众迷失"谁在谁对面"

为什么重要：越轴让观众觉得空间碎了、人物关系乱了。拍对话戏死守此规则。

### 3.4 蒙太奇：把不挨着的镜头剪在一起，产生新意思
镜头并列产生 1+1>2 的含义，不是"快速剪辑"。

库里肖夫效应：同一张面无表情的脸，后面接：
- 一碗汤 → 观众觉得他"饿"
- 死去的孩子 → 观众觉得他"悲伤"
- 美女 → 观众觉得他"欲望"

脸没变，**接什么决定观众读出什么情绪**。意义在两面碰撞中间产生。

常见用法：
- 平行蒙太奇：同时两件事交叉剪（炸弹倒计时 + 拆弹专家）
- 积累蒙太奇：一堆相似镜头快速叠（城市清晨：闹钟、地铁、咖啡）
- 对比蒙太奇：富人桌 vs 穷人桌，不说话已说完

## 四、串起来：前面练的就是导演内核
- 切景别（远→特写）是剪辑点
- 蒙太奇就是决定"第几秒接哪个画面"
- 轴线决定剪的时候两段能不能挨着不跳

技术为表达服务——越懂剪辑工具，脑子里的画面越能精确落地。

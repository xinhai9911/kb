# 蒙太奇手法用法详解

> 配套：[[50-reference/导演 入门]]（导演入门总纲）、[[50-reference/镜头 尺寸 轴线 分镜]]（分镜模板）。
> 蒙太奇 = 把不挨着的镜头剪在一起，让它们碰撞出单独不存在的意思。
> 本文展开三种核心用法：平行 / 积累 / 对比，并给出拍摄思路与 ffmpeg 落法。

---

## 〇、核心原理：库里肖夫效应

同一张**面无表情**的脸，后面接不同的画面，观众读出完全不同的情绪：
- 接「一碗汤」→ 观众觉得他"饿"
- 接「死去的孩子」→ 观众觉得他"悲伤"
- 接「美女」→ 观众觉得他"欲望"

脸没变，**接什么决定观众读出什么情绪**。意义不在单个镜头里，而在"两个画面挨着"这个动作中间产生。

> 所以蒙太奇不是"快速剪辑"的代名词，而是**你决定观众先看什么、后看什么、让哪两个画面挨着**。

---

## 一、平行蒙太奇：两条线同时跑，交叉剪

### 原理
两条（或多条）**时间上同时在进行**的故事线，来回切换着剪。观众自动把它们拼成"同一时刻发生"，于是产生紧张、等待、比较。

### 经典公式
- 线 A：炸弹倒计时 `50 → 49 → 48…`
- 线 B：拆弹专家满头大汗剪线

单看 A 只是个数字，单看 B 只是个人干活——都没张力。一交叉，"时间压力"和"人的努力"撞出**悬念**。

### 为什么有效
"同时性"让观众开始**等**——等两件事撞上、等结果揭晓。"等待 + 不知结局" = 悬念。

### 电影例子
《盗梦空间》多层梦境同时坍塌；《教父》洗礼戏 + 屠杀戏同剪；《谍影重重》追踪线 + 逃亡线。

### 你拍的时候怎么用
- 考试倒计时 + 考生答题
- 妈妈做饭 + 孩子放学往家走（将在饭桌汇合）
- 任何"两件事将在某刻相遇/相撞"的题材

### ffmpeg 落法（交叉拼两段）
分镜：A1(0-2s) B1(2-4s) A2(4-6s) B2(6-8s) … 按序 concat：
```bash
ffmpeg -i bomb.mp4 -i defuse.mp4 -filter_complex \
"[0:v]trim=start=0:end=2,setpts=PTS-STARTPTS[a1];\
 [1:v]trim=start=0:end=2,setpts=PTS-STARTPTS[b1];\
 [0:v]trim=start=2:end=4,setpts=PTS-STARTPTS[a2];\
 [1:v]trim=start=2:end=4,setpts=PTS-STARTPTS[b2];\
 [a1][b1][a2][b2]concat=n=4:v=1[v]" -map "[v]" out.mp4
```

### 判断该不该用
问自己："我是不是有两件事在同一时刻发生，而且它们快撞上了 / 有因果关系？"
- 是 → 平行蒙太奇，制造紧张
- 否 → 看是积累（规模）还是对比（反差）

## 二、积累蒙太奇：一堆同类镜头快速叠

### 原理
放**一堆同一类**的镜头，一个接一个飞快闪过。没有两条线对撞，而是**用数量堆出规模感 / 氛围感 / 时间流逝**。单个镜头没啥，10 个叠一起观众就懂了"这是一个普遍现象 / 一段时间过去了 / 一种情绪弥漫"。

### 例子：城市清晨
闹钟响 → 地铁进站 → 咖啡机出咖啡 → 路人打哈欠 → 电梯门关 → 太阳升起…
每个 1 秒，连放 10 个。不用旁白，观众懂："这座城市醒来了。"

### 作用（四件事）
1. **交代时间流逝**：8 秒顶替 8 小时（闹钟→出门→打卡 = 一上午）
2. **营造氛围**：同类画面攒多溢出成情绪场（清晨串 → "城醒了"）
3. **显示规模/普遍**：一人加班是个人，十人快剪 = "全公司在拼"，数量即论据
4. **建立节奏感**：快速积累天然带节拍，训练/备战/狂欢最带感

### 电影例子
《超人》成长过程快闪；《莫扎特传》鼓掌的手一个接一个；《饿狼传说》训练镜头快叠。

### 你拍的时候怎么用
- 主角练琴：一个音符→一个音符→一个音符快剪 = "练了很久"
- 城市夜生活：霓虹、酒杯、车流、笑脸 = "这座城不睡"
- 战争前奏：磨刀、上膛、列队、马蹄 = "大战将至"

### ffmpeg 落法（每个镜头 trim 成 1 秒再 concat）
```bash
ffmpeg -i city.mp4 -filter_complex \
"[0:v]trim=start=0:end=1,setpts=PTS-STARTPTS[s1];\
 [0:v]trim=start=1:end=2,setpts=PTS-STARTPTS[s2];\
 [0:v]trim=start=2:end=3,setpts=PTS-STARTPTS[s3];\
 [s1][s2][s3]concat=n=3:v=1[v]" -map "[v]" out.mp4
```

## 三、对比蒙太奇：两个相反的镜头并列，不说话也说完

### 原理
拿**两个对立/反差极大**的镜头并列，让观众自己得出批判、讽刺或情绪结论。不需要台词，反差本身就是台词。

### 例子：富人的桌 vs 穷人的桌
- 镜头1：长桌、银烛台、牛排、红酒、仆人斟酒
- 镜头2：破桌、半块面包、凉水、孩子盯着空碗

不写"贫富差距大"，观众已经愤怒/心酸。**意义由反差自动产生。**

### 为什么有效
人脑天生爱找对比。两个极端摆一起，观众立刻做判断，而且比你说出来更有力（说教让人烦，对比让人自己悟）。

### 电影例子
《巴黎圣母院》丑王 vs 权贵；《辛德勒名单》红衣小女孩在黑白屠杀中；《上帝之城》富人区俯瞰 vs 贫民窟。

### 你拍的时候怎么用
- 老板坐豪车 vs 工人挤公交
- 婚礼笑脸 vs 同一人离婚后空房
- 健康肺 vs 烟民肺（公益广告经典）

### ffmpeg 落法（两段顺序接，或用 xfade 强调反差）
```bash
ffmpeg -i rich.mp4 -i poor.mp4 -filter_complex \
"[0:v][1:v]concat=n=2:v=1[v]" -map "[v]" out.mp4
# 想要过渡感：加 xfade=transition=fade:duration=1
```

## 四、三种蒙太奇一图记住

| 类型 | 镜头关系 | 撞出什么 | 关键词 | 观众心里话 |
|------|---------|---------|--------|-----------|
| 平行蒙太奇 | 两条线**同时**进行，交叉剪 | 悬念、紧张、等待 | 同时 + 交叉 | "来得及吗！" |
| 积累蒙太奇 | 一堆**同类**镜头快叠 | 规模、氛围、时间流逝 | 同类 + 数量 | "练了很久" |
| 对比蒙太奇 | 两个**相反**镜头并列 | 批判、讽刺、情绪 | 对立 + 反差 | "太不公平了" |

**总纲**：蒙太奇 = 你决定观众先看什么、后看什么、让哪两个画面挨着——意义就在"挨着"这个动作里诞生。
